# 11.4.2 Dynamic Batching Indeterminism Creating Non-Reproducible Agent Behavior [NoFW]

Inference batching groups requests differently across invocations, producing variable outputs from identical inputs due to floating-point non-associativity in batch computation.

Triton Inference Server's dynamic batching assembles groups of concurrent requests within a configurable wait window, so the set of co-batched requests varies non-deterministically across invocations; because batch normalization and attention computations are not algebraically commutative across batch members, the same input prompt produces different token probability distributions depending on which other requests happen to be co-batched at that moment. An adversary who can control a fraction of concurrent inference requests can craft co-batching companions whose embedded numerical patterns shift the target request's probability distribution past a classification or safety threshold. For example, an attacker submits 15 carefully designed companion requests per second alongside a victim request; across repeated trials the target response crosses the toxicity classifier threshold in roughly 12% of batching outcomes—a probabilistic jailbreak that is entirely undetectable in controlled single-request regression testing because those tests eliminate the co-batching context that causes the shift.

Standard defenses such as deterministic temperature settings and fixed random seeds are insufficient because dynamic-batching non-determinism is architectural—it arises from request interleaving that seed values cannot govern—and per-request replay in isolation does not reconstruct the batch membership that produced the harmful output in production.

**Multi-agent distinction:** In MAS, multiple agents submit inference requests concurrently to a shared inference server; co-batching of requests from different agents creates cross-agent interference where Agent A's concurrent requests systematically perturb the probability distribution for Agent B's requests, a coupling that never arises in single-agent deployments and that makes cross-agent behavioral verification fundamentally non-reproducible under production load patterns.
