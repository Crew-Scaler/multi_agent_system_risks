# 11.4.5 Message Queue Ordering Guarantees as Assurance Gap Under Scaling [NoFW]

Message queue systems provide per-queue ordering but not cross-queue ordering. As multi-agent systems scale and add queues, cross-queue ordering guarantees are lost, enabling attackers to craft message sequences where dependent operations execute before their preconditions, bypassing sequential validation.

RabbitMQ and comparable brokers guarantee total ordering within a single queue but provide no ordering guarantees across queues; as agent pipelines scale horizontally and distribute work across multiple queues, the operational assumption that a precondition message (M1) will always arrive before its dependent action message (M2) becomes architecturally unenforceable. An attacker who can introduce differential delivery delay—for example, by flooding queue Q1's consumer while leaving Q2's consumer unimpeded—causes Agent B to process the action message M2 from Q2 before Agent A has consumed and validated M1 from Q1, executing the action against a state the precondition was meant to gate. For example, in a financial settlement system an attacker delays the fraud-check-passed message on Q1 by 200 milliseconds while the settlement-execute message on Q2 arrives on schedule; the settlement agent executes without the fraud check's confirmation, bypassing the control that sequential single-queue processing would have enforced.

Standard defenses such as per-queue FIFO configuration and consumer acknowledgement are insufficient because they operate strictly within individual queues; enforcing cross-queue temporal ordering requires application-layer sequence numbers, distributed sagas, or two-phase commit protocols that most event-driven agent architectures deliberately avoid to maintain throughput and decoupling.

**Multi-agent distinction:** In MAS, the cross-queue ordering attack surface scales with the number of agents: each additional agent introduces at least one new queue, expanding the number of cross-queue agent pairs that can suffer ordering inversions from O(N) to O(N²), whereas a single-agent system interacts with a single queue and cannot experience cross-queue non-determinism regardless of message volume.
