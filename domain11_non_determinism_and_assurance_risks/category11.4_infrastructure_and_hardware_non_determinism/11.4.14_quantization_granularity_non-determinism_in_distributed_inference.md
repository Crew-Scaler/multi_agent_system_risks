# 11.4.14 Quantization Granularity Non-Determinism in Distributed Inference [NoFW]

Different agents using different quantization modes (per-tensor vs. per-token) produce divergent confidence scores from identical inputs. An approval agent's per-tensor score above threshold may not reproduce in an execution agent using per-token quantization, creating verification failures between pipeline stages.

Per-tensor quantization applies a single scale factor to all elements of a weight tensor, while per-token quantization derives independent scale factors for each token's activation vector; these structurally different numerical representations accumulate rounding errors differently through transformer layers, producing softmax probability distributions that diverge even from mathematically identical floating-point inputs, with divergence magnitude determined by the sharpness of the distribution near decision thresholds. An attacker who understands the quantization split between pipeline stages crafts inputs that position the confidence score in the threshold-divergence zone: inputs where per-tensor quantization yields a score just above the approval threshold while per-token quantization yields a score just below, or vice versa, selectively producing approval without execution or execution without approval depending on which direction serves the attack. For example, an attacker submits a prompt engineered to yield a per-tensor safety score of 0.71 (above the 0.70 gate) on the approval agent and 0.68 (below the gate) on the execution agent; the approval agent grants permission while the execution agent declines to proceed, leaving a mismatched authorization state; calibrated in the opposite direction, the execution agent proceeds without the approval agent having granted clearance, bypassing the pipeline's sequential authorization model.

Standard defenses such as unified quantization policies and synchronized threshold calibration are insufficient because quantization mode selection is often constrained by hardware support and latency budgets independently for each pipeline stage, making per-stage threshold re-calibration the only partial mitigation—but calibration cannot account for the input-specific divergence between modes that varies unpredictably across prompt vocabulary.

**Multi-agent distinction:** In MAS, different pipeline stages may be deployed on hardware that mandates different quantization modes; quantization-induced cross-stage score divergence creates an exploitable security boundary inconsistency that is invisible within each agent's individual evaluation but produces systematic discrepancies when approval and execution agents compare scores across stages—a failure mode that single-agent pipelines with uniform quantization never exhibit.
