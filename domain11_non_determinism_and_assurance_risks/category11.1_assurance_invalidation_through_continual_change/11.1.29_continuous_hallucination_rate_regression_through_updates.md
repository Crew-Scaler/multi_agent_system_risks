# 11.1.29 Continuous Hallucination Rate Regression Through Updates [NoFW]

Agent updates through fine-tuning regress hallucination rates unpredictably. Grounding checks calibrated to pre-update rates become ineffective when regression increases hallucination past calibrated thresholds, creating post-update exploitation windows.

For example, a retrieval-augmented generation agent fine-tuned on domain-specific data may begin hallucinating tool names that were not present in its pre-update vocabulary, causing it to invoke non-existent endpoints that a malicious tool registration can intercept—a vulnerability window that exists only after the update and remains open until grounding checks are recalibrated.

Standard defenses such as output grounding validators, factuality thresholds, and hallucination detection classifiers are insufficient because they are calibrated against pre-update baseline rates and do not automatically adjust when fine-tuning shifts the hallucination distribution in ways that maintain surface plausibility while crossing security-relevant thresholds.

**Multi-agent distinction:** In multi-agent pipelines, a hallucination rate regression in one agent produces fabricated tool calls, fabricated entity references, or fabricated intermediate conclusions that downstream agents treat as authoritative inputs, cascading the assurance failure through the full pipeline without any downstream agent having access to the update provenance needed to discount the upstream output.
