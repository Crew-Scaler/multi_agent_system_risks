# 11.1.12 Multimodal Model Version Drift Creating Inconsistent Behavior Across Agents [NoFW]

Multimodal RAG using diverse vision models creates complexity where asynchronous updates cause non-determinism. Agent A using CLIP v1.0 and Agent B using CLIP v2.0 produce inconsistent results from shared storage, invalidating cross-agent assurance assumptions.

For example, when Agent A uses CLIP v1.0 to embed product images and Agent B uses CLIP v2.0 after an asynchronous update, the same product query retrieves different images from the shared vector store depending on which agent processes the request, invalidating cross-agent consistency evaluations that assumed a uniform embedding model across the fleet.

Standard defenses such as model version pinning and vector index versioning are insufficient because multimodal model updates often improve benchmark accuracy while shifting the embedding space, so pinning prevents quality improvements while allowing the assurance gap to widen as other system components evolve, and re-indexing the entire vector store on every model update is operationally prohibitive.

**Multi-agent distinction:** In a single-agent deployment, embedding model drift affects one retrieval path whose outputs can be monitored and compared over time; in a multi-agent system where Agent A retrieves images and Agent B retrieves corresponding text using different version embeddings, the mismatch between modality-specific embeddings produces cross-modal inconsistencies that neither agent's individual retrieval test detects because each agent's retrieval appears locally correct.
