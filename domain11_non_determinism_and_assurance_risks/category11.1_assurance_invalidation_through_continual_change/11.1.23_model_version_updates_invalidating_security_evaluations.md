# 11.1.23 Model Version Updates Invalidating Security Evaluations [NoFW]

LangChain agents update underlying models regularly. Multi-agent systems updating shared LLM instances simultaneously invalidate security evaluations across all dependent agents, with empirical evidence showing GPT-4 accuracy dropping 33% between versions without code changes.

For example, a red-team evaluation demonstrating that an agent's model version reliably refuses prompt-injection payloads targeting financial-data tools may become invalid the following month when the same model is replaced by a provider update that subtly relaxes refusal boundaries under compound instruction framing.

Standard defenses such as periodic re-evaluation, model pinning, and provider SLAs are insufficient because even minor model weight adjustments can shift safety-relevant behavior in ways not reflected in aggregate benchmark scores, and re-evaluation cycles cannot keep pace with cloud-provider update cadences.

**Multi-agent distinction:** In multi-agent systems where multiple agents share or reference the same underlying model, a provider update simultaneously invalidates the security evaluations of all dependent agents, creating a fleet-wide assurance gap proportional to the number of agents sharing the updated model instance.
