# 11.5.4 Consolidation Timing Non-Determinism Enabling Attack Escalation Windows [NoFW]

Unpredictable timing of memory consolidation processes creates windows during which malicious entries have different visibility to retrieving agents.

Memory consolidation runs periodically based on load conditions and buffer thresholds rather than a fixed schedule, making its exact timing unpredictable relative to monitoring activity. An attacker submits a malicious episode during system peak load, causing the consolidation process to defer to an overnight low-load window when audit monitoring is suspended; the consolidated entry then becomes persistently retrievable by all subsequent agents before any scheduled security scan can detect it.

Standard defenses such as periodic audit sweeps and pre-consolidation content filters are insufficient because sweeps that run on a fixed schedule miss consolidation events occurring in the interval between sweeps, and pre-consolidation filters cannot evaluate entries in their post-consolidation form before they become retrievable.

**Multi-agent distinction:** In a multi-agent system, all agents share the consolidated memory store, so a malicious entry that survives consolidation becomes simultaneously retrievable by every agent querying the store thereafter; a single successful timing attack escalates from a single-agent vulnerability to a system-wide memory corruption event that no individual agent can detect by examining only its own retrievals.
