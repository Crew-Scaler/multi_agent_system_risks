# 11.5.5 Retrieval Threshold Sensitivity as Assurance Gap [NoFW]

Similarity thresholds for episodic memory retrieval vary depending on query context. Poisoned episodes designed to retrieve only under specific contexts avoid detection during standard evaluation while remaining exploitable when target contexts arise in production.

For example, in a customer support system backed by an episodic knowledge store, an attacker injects a policy-manipulation episode calibrated to score just above the retrieval threshold only when the query includes the phrase "urgent escalation"; during routine security evaluation using standard test queries, the episode is never retrieved, but once a live user triggers the target phrase the poisoned episode surfaces and redirects the agent's response.

Standard defenses such as fixed-threshold filtering and static evaluation benchmarks are insufficient because they cannot enumerate all production query contexts under which a poisoned episode may cross the retrieval threshold; thresholds that appear stable in evaluation fluctuate in deployment as query distributions shift.

**Multi-agent distinction:** In a multi-agent system, a poisoned episode that falls below the retrieval threshold for Agent A's query context may simultaneously clear the threshold for Agent B's slightly different query context; neither agent independently detects the poisoning, but their divergent retrievals cause coordinated decisions to rest on asymmetric knowledge—a failure mode that cannot arise when a single agent processes all related queries sequentially from the same retrieval snapshot.
