# 11.5.12 Incremental Update Non-Determinism [NoFW]

Knowledge base updates apply incrementally while agents query during the update window. Agents querying during updates retrieve partially-updated data, creating divergent snapshots that cause different agents to operate on inconsistent knowledge states simultaneously.

For example, a credential revocation list is updated incrementally as 10,000 new entries are added over a 30-second window; Agent A queries at second 5 and sees 1,500 of the new entries while Agent B queries at second 28 and sees 9,000 entries—both agents believe they hold the complete revocation list and proceed with authorization decisions, but Agent A grants access to credentials that Agent B would have revoked.

Standard defenses such as read-your-writes consistency and snapshot isolation guarantees are insufficient because they apply within a single database session; agents querying from separate sessions during the same incremental update window observe different intermediate states with no mechanism to know how far the update has progressed.

**Multi-agent distinction:** In a multi-agent system, agents querying the same knowledge base during an ongoing incremental update observe different intermediate states depending on their precise query timing; each agent individually believes it has a complete and consistent view, but the agents collectively operate on divergent snapshots of the same store—a form of knowledge fragmentation that cannot occur in a single-agent system that issues one query and receives one consistent snapshot.
