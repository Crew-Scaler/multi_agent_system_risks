# 11.5.15 Memory Update Non-Determinism Causing Unpredictable State Evolution [NoFW]

LangChain memory updates exhibit ordering dependencies in distributed systems. Race conditions from concurrent updates enable attackers to craft memory injection sequences that exploit non-deterministic write ordering to persistently corrupt shared agent memory.

For example, in a LangChain-based multi-agent customer service system sharing a memory bank, an attacker submits two concurrent queries that each trigger a memory write; due to non-deterministic write ordering at the shared store, the attacker's second write—containing a malicious instruction to override refund policy—arrives after the legitimate write and permanently overwrites it, ensuring that every subsequent agent that queries the shared memory bank retrieves the injected instruction.

Standard defenses such as write-once memory policies and sequential consistency checks applied to single-agent testing cannot detect race conditions that only manifest when multiple agents write concurrently; the attack succeeds specifically because no single agent's individual write is malformed—only the ordering is adversarially controlled.

**Multi-agent distinction:** In a multi-agent system with a shared memory bank, concurrent writes from multiple agents create non-deterministic final states that depend on network timing and scheduler decisions neither agent controls; the resulting memory state may be one that no individual agent intended to write and no test that exercises agents sequentially would ever produce, a failure mode structurally absent from single-agent systems where all memory mutations are serialized through one execution thread.
