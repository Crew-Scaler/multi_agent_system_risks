# 11.5.2 Knowledge Graph Traversal Ordering Non-Determinism [NoFW]

Multiple valid traversal paths through knowledge graphs produce different retrieved subgraphs, enabling attackers to exploit non-determinism to control which facts agents access.

Knowledge graph traversal algorithms select among multiple equally valid paths based on index scan order, buffer state, or query planner heuristics, all of which vary at runtime. An attacker embeds a poisoned permission relationship in the graph at a node reachable via one traversal path but not another; in a supply chain authorization system, Agent A traverses the path A→B→C and encounters the poisoned vendor node, approving a fraudulent purchase order, while Agent B traverses the alternative path A→D→C, bypassing the poisoned node entirely and returning a correct denial—both from the same underlying graph state.

Standard defenses such as post-traversal path validation and query-result integrity checks are insufficient because they apply only after a specific path has been selected; the non-determinism means that a given security evaluation may never exercise the vulnerable traversal, producing passing test results while the exploit remains latent in the graph.

**Multi-agent distinction:** In a multi-agent system, multiple agents simultaneously traverse the shared knowledge graph and may select different paths for the same logical query; Agent A may reach a poisoned node that Agent B never encounters, causing the two agents to operate on contradictory fact sets—a divergence impossible in a single-agent system that issues a single traversal and receives a single consistent subgraph in response.
