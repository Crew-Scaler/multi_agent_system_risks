# 11.5.9 RAG Result Ranking Non-Determinism Due to Score Rounding [NoFW]

Document similarity scores undergo rounding producing non-deterministic ranking boundaries near score ties. Shared ranking functions create correlated non-determinism across all agents, enabling adversarial documents crafted to score near the boundary to retrieve intermittently and unpredictably.

For example, an attacker crafts an adversarial document engineered to produce a floating-point similarity score of exactly 0.7500 against a target query; depending on the rounding mode applied by the ranking engine at query time, the score resolves to either 0.75 (above the top-k cutoff) or 0.74 (below it), causing the document to appear in results on roughly 60% of queries and be suppressed on the remaining 40%—creating an intermittently exploitable retrieval surface that no deterministic security evaluation can reliably detect.

Standard defenses such as deterministic top-k filtering and score-threshold blocklisting are insufficient because they assume stable score-to-rank mappings; floating-point rounding behavior is hardware-dependent and query-load-dependent, making the effective retrieval boundary non-reproducible across evaluation runs.

**Multi-agent distinction:** In a multi-agent system sharing a single ranking function, score rounding non-determinism is correlated across all agents processing the same query batch—an adversarial document may be consistently included or excluded for all agents during one time window and flip to the opposite state in another, creating a fleet-wide retrieval state change that no individual agent can observe or compensate for independently.
