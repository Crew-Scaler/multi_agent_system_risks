# 11.5.11 Probabilistic Fact Evaluation Non-Determinism [NoFW]

Knowledge graphs storing probabilistic facts create non-deterministic evaluation where agents sample different probability values for identical facts. Shared probabilistic knowledge enables attackers to leverage score variance to make adversarial facts appear valid in some evaluations and invalid in others.

For example, a knowledge graph stores the fact "Vendor X is an authorized supplier" with confidence probability 0.49; two agents independently sample the fact for the same purchase authorization decision—Agent A draws a sample of 0.51 (above the 0.50 acceptance threshold) and approves the order, while Agent B draws 0.47 and rejects it—producing contradictory authorization outcomes from a single probabilistic assertion.

Standard defenses such as deterministic rule engines and threshold-based access controls are insufficient because they presuppose stable fact values; applying a fixed threshold to a probabilistically stored fact does not eliminate variance—it merely shifts where in the probability distribution the flip-flop behavior occurs.

**Multi-agent distinction:** In a multi-agent system, multiple agents sampling the same probabilistic knowledge graph fact independently draw different values in the same query round; their resulting decisions diverge not because they received different information but because the knowledge store's representation is inherently stochastic—a category of disagreement that cannot arise in single-agent systems where every fact evaluation within a session returns the same sampled or deterministic value.
