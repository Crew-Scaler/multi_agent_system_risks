# 11.5.1 Non-Deterministic Episode Retrieval Ranking Enabling Adaptive Attacks [NoFW]

Variable retrieval rankings for episodic memory allow attackers to craft queries that land near ranking threshold boundaries, intermittently retrieving malicious episodes.

Episodic memory retrieval combines similarity, recency, and importance scores with weighted aggregation, producing a composite rank that varies with query phrasing and context. An attacker crafts a malicious episode whose composite score sits near the median retrieval boundary; in a multi-agent fraud detection system, Agent A receives the episode during a high-similarity query and executes the encoded fraudulent pattern, while Agent B issues a semantically equivalent query moments later, receives a slightly different rank, and correctly rejects the transaction—two divergent outcomes from ostensibly identical inputs.

Standard defenses such as fixed-threshold filtering and static blocklists are insufficient because the boundary itself is the attack surface: the poisoned episode is designed to look legitimate and score near the decision margin, so neither a content filter nor a predetermined exclusion list can reliably intercept it without also excluding legitimate episodes with similar composite scores.

**Multi-agent distinction:** In a multi-agent system, multiple agents independently query the same episodic store; because retrieval ranking is non-deterministic, two agents issuing semantically equivalent queries may receive different episode sets, reaching contradictory decisions—a divergence that cannot occur in a single-agent system reading sequentially from the same store, where every query within a session operates on a consistent retrieval snapshot.
