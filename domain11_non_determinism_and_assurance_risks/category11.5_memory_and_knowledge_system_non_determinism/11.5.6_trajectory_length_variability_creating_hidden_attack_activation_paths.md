# 11.5.6 Trajectory Length Variability Creating Hidden Attack Activation Paths [NoFW]

Episodic trajectories vary in length depending on problem complexity. Attackers craft episodes with malicious steps that activate only during long trajectories when monitoring attention is exhausted, creating activation paths invisible in standard-length testing.

For example, in an automated multi-step code review pipeline, a malicious instruction is embedded at step 47 of a poisoned trajectory; the monitoring system is calibrated to exhaustively inspect only the first 20 steps of any trajectory, so the malicious instruction executes after the monitoring budget is exhausted and the agent proceeds without triggering any alert.

Standard defenses such as step-count-bounded monitoring and average-trajectory-length calibration are insufficient because adversarially crafted trajectories are specifically designed to exceed the monitoring budget before their malicious content activates, exploiting the gap between expected and actual trajectory lengths.

**Multi-agent distinction:** In a multi-agent system with task decomposition, individual sub-agents handle trajectory segments of different lengths; a malicious step designed to activate at trajectory position N will execute in Agent B handling a long sub-trajectory while remaining dormant in Agent A handling a short sub-trajectory—a position-dependent divergence that cannot occur in a single-agent system executing the full trajectory as a single continuous sequence.
