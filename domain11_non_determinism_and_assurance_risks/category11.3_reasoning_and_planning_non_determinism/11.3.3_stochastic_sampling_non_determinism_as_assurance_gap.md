# 11.3.3 Stochastic Sampling Non-Determinism as Assurance Gap [NoFW]

Self-Consistency with large k values produces different final answers under different random seeds, making it impossible to assert that a specific output will always be produced for a given input.

Self-Consistency intentionally generates k diverse reasoning paths through stochastic decoding and selects the answer by majority vote, so the final answer depends on which specific random path sample is drawn on each inference call; an adversary who poisons an input with context that biases a subset of reasoning archetypes can shift the majority vote outcome under certain sampling conditions, producing an unsafe answer that safety evaluations conducted under different random samples would never have surfaced. For example, a financial analysis agent using Self-Consistency with k=20 may produce a benign recommendation on 95% of evaluation runs but produce an exploitable recommendation on the remaining 5% due to a poisoned document excerpt that activates only under specific sampling trajectories, making the vulnerability statistically invisible in bounded test sets.

Standard defenses such as majority-vote aggregation and deterministic output validation are insufficient because they assume the sampled reasoning path distribution is stationary across input variations, yet adversarially crafted inputs can shift the sampling distribution toward unsafe reasoning paths while remaining below detection thresholds across any fixed evaluation budget.

**Multi-agent distinction:** In a multi-agent system, multiple agents each independently apply Self-Consistency sampling, so stochastic path selection varies independently per agent; when one agent's majority vote shifts to an unsafe answer, downstream agents receive that output as trusted context and their own Self-Consistency sampling further compounds the error, producing divergence that accumulates across the pipeline in ways no single-agent consistency audit can characterize.
