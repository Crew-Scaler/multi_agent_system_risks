# 11.3.1 CoT Path Explosion in Multi-Agent Coordination [NoFW]

When multiple agents independently generate chain-of-thought reasoning, the joint space of reasoning paths grows combinatorially, making it infeasible to verify that all paths lead to safe conclusions.

Each agent's stochastic CoT generation creates branching points that multiply across the fleet: an adversary who injects subtly biased context into one agent's input causes that agent's chain-of-thought to traverse an unsafe reasoning branch, and when that branch's output is forwarded as context to a second agent, the compromised reasoning propagates silently because each agent's local chain appears internally consistent. For example, in a three-agent research pipeline, an adversarially crafted document excerpt can steer the first agent's CoT toward a false intermediate conclusion about data sensitivity; the second agent receives that conclusion as a trusted handoff and builds further reasoning on it; and by the time the third agent acts, the original injection is untraceable across the distributed CoT logs.

Standard defenses such as single-agent CoT auditing and output content filtering are insufficient because they evaluate each agent's reasoning in isolation and cannot detect cross-agent contamination where the dangerous implication emerges only from the composition of individually benign-appearing reasoning steps.

**Multi-agent distinction:** In a multi-agent system, each agent applies its own independent CoT process, so non-deterministic reasoning in a planner agent produces varied subtask decompositions that worker agents then execute differently; the resulting divergence compounds across reasoning layers in ways no single-agent CoT audit can capture, because unsafe behavior is distributed across agent boundaries rather than visible within any one agent's trace.
