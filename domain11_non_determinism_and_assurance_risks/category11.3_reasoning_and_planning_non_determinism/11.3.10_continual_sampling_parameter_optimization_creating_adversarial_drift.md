# 11.3.10 Continual Sampling Parameter Optimization Creating Adversarial Drift [NoFW]

Continuous optimization adjusting sampling parameters based on success rates causes systematic drift. In multi-agent systems with shared optimization, drift affects all agents simultaneously, creating moving-target security behavior that adversaries can exploit by steering optimization.

For example, an adversary submits crafted requests that appear to succeed under high-temperature sampling, artificially inflating the reward signal for aggressive exploration parameters; the shared optimization pipeline responds by increasing temperature across all agents, causing the entire fleet to drift toward sampling distributions where the adversary's prepared prompt injections activate, exploiting a behavioral shift that no individual agent's local safety monitor would flag as a configuration change.

Standard defenses such as optimization rate limits and anomaly detection on success rate signals are insufficient because the adversary can steer optimization gradually below detection thresholds, and the security impact of parameter drift only becomes apparent after the distribution shift has compounded across many optimization steps.

**Multi-agent distinction:** In a multi-agent system with shared parameter optimization, a single adversarially steered optimization step affects all agents simultaneously; each agent then exhibits independently non-deterministic behavior under the drifted parameters, and the compound effect of fleet-wide parameter shift combined with per-agent sampling variance creates a security surface that no single-agent parameter audit can characterize because the dangerous behavior distribution is a function of the drifted shared parameters rather than any individual agent's configuration.
