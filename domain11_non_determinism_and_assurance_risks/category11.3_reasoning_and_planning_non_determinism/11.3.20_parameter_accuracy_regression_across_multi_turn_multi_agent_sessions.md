# 11.3.20 Parameter Accuracy Regression Across Multi-Turn Multi-Agent Sessions [NoFW]

Agents can lose coherence across extended multi-turn sessions, and in multi-agent systems this degradation cascades. When Agent A loses parameter coherence at turn 5 and Agent B relies on Agent A's degraded outputs for turn 6, Agent B executes based on corrupted inputs. Each agent's coherence loss triggers cascading reliability loss in downstream agents, creating compound degradation invisible without per-agent coherence tracking instrumentation.

Standard defenses such as output validation gates between agents and periodic coherence checks are insufficient because degradation in parameter accuracy is gradual and context-dependent, causing outputs to remain within valid schema ranges while containing semantically corrupted values that pass structural validation; the corruption only becomes apparent through downstream behavioral anomalies that occur multiple agent turns after the initial coherence loss.

**Multi-agent distinction:** In a multi-agent system, each agent's coherence state is independent but agents share output-input chains, so one agent's mid-session coherence loss propagates as corrupted input to downstream agents that have no visibility into the upstream agent's coherence history; the compound degradation cascades silently across the pipeline with each downstream agent adding its own coherence variance, creating a cumulative reliability loss that is invisible to per-agent coherence monitors that evaluate only each agent's most recent output rather than the coherence trajectory across the full multi-agent session.
