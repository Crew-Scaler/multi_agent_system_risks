# 11.3.7 Stochastic Multi-Agent Planning Creating Untestable Paths [NoFW]

Each agent's stochastic reasoning choices combine multiplicatively, making the combined multi-agent planning space computationally infeasible to test exhaustively. Adversarial inputs can target paths that individual agent testing passes but combined evaluation never exercises.

For example, a red-team evaluation that tests each of three planning agents individually may pass all agents for a given adversarial payload, yet in joint execution the payload triggers a specific combination of stochastic choices across all three agents — each improbable individually — that produces an unsafe compound action sequence, a combination the individual tests never explored because their stochastic choices happened to avoid the joint unsafe path.

Standard defenses such as per-agent unit testing and adversarial input filtering are insufficient because they evaluate each agent's stochastic behavior in isolation, and the multiplicative combination of independent stochastic choices creates a joint path space that grows exponentially with agent count, making exhaustive joint coverage computationally infeasible regardless of per-agent test thoroughness.

**Multi-agent distinction:** In a multi-agent system, each agent applies its own stochastic planning choices independently, so the combined planning space is the Cartesian product of individual agent path spaces; non-deterministic planning in a single planner agent produces varied subtask decompositions that worker agents then execute with their own stochastic choices, compounding divergence in ways that no single-agent planning audit can characterize because the dangerous path exists only in the joint space.
