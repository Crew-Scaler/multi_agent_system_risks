# 11.3.8 Backtracking State Divergence in Distributed ToT Systems [NoFW]

When agents maintain separate Tree-of-Thought search trees and backtrack concurrently, timing differences cause divergence in which branches have been explored, creating inconsistent plan state across agents executing nominally the same task.

For example, in a distributed multi-agent planning system where two agents independently maintain ToT search trees for the same problem, Agent A backtracks from branch B3 at time T1 and marks it pruned, while Agent B — unaware of A's backtracking — retrieves and executes subtasks from B3 at time T2, producing a partial execution of a branch that the coordinating agent has already deemed unsafe and abandoned.

Standard defenses such as shared branch state synchronization and centralized pruning registries are insufficient because synchronization introduces latency that itself creates new race windows, and deterministic branch-pruning protocols impose serial execution constraints that eliminate the throughput benefits of distributed ToT search.

**Multi-agent distinction:** In a multi-agent system, each agent maintains its own independent ToT search tree and backtracks based on local timing, so concurrent backtracking produces divergent explored-branch sets across the fleet; the inconsistent exploration state creates coordination gaps where one agent executes from a branch another has pruned, a failure mode invisible to single-agent ToT audits that evaluate only the final tree structure rather than the dynamic inter-agent backtracking sequence.
