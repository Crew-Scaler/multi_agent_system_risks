# 11.3.2 MCTS Non-Determinism in Multi-Agent Convergence [NoFW]

Monte Carlo Tree Search planning across multiple coordinating agents produces non-deterministic convergence behavior that can produce collectively unsafe plans from individually safe-looking partial plans.

MCTS with random seeds generates structurally different search trees on each invocation, so two coordinating agents planning the same goal independently may produce incompatible action orderings — Agent A selecting "acquire resource X then authorize action Y" while Agent B selects "authorize action Y then acquire resource X" — creating a coordination gap where their simultaneous execution produces a dangerous interleaved sequence that neither agent's individually tested plan would generate. For example, in a financial workflow where resource locking must precede authorization, non-deterministic MCTS convergence across two agents can produce a state where the authorization is attempted before the lock is acquired, bypassing an access control gate that single-agent testing consistently enforced.

Standard defenses such as fixing random seeds during testing are insufficient because production environments with concurrent load cannot guarantee reproducible seeds, and safety properties verified against one tree structure do not transfer to structurally different trees produced under different seeds or load conditions.

**Multi-agent distinction:** In a multi-agent system, each MCTS planner independently samples its own search tree, so non-deterministic tree structures across agents produce divergent action orderings for the same goal; the interaction between independently planned trees creates emergent coordination gaps that no single-agent MCTS audit can detect, because the dangerous condition appears only when two independently non-deterministic plans are executed concurrently.
