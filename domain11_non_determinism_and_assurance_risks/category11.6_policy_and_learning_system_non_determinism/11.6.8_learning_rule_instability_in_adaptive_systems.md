# 11.6.8 Learning Rule Instability in Adaptive Systems [NoFW]

Rule learning systems continuously refine rules during deployment. In multi-agent shared learning environments, continuously changing rules create non-deterministic behavior where the same input triggers different rule chains at different times, invalidating rule-based safety assurance.

For example, a compliance agent that continuously inducts new rules from observed regulatory precedents may add a rule during a live session that conflicts with an existing safety guard; the conflict resolution heuristic determines which rule fires, but the heuristic's outcome depends on the order in which prior rules were learned, so the same compliance query produces different decisions depending on the agent's learning history at that moment.

Standard defenses such as rule-conflict detection and pre-commit rule validation are insufficient because rules are added continuously at runtime, and each new rule can introduce latent conflicts with rules not yet in the active set, making comprehensive pre-execution conflict checking computationally intractable at deployment speed.

**Multi-agent distinction:** In a MAS, independently learning agents accumulate different rule sets over time; non-determinism in one agent's rule refinement propagates through coordination interfaces to destabilize the behavior of agents that depend on consistent rule-based policy contracts, creating cross-agent rule divergence unavailable in single-agent learning systems.
