# 11.6.5 Stochastic Outcome Distribution Changes Breaking Cached Utility Calculations [NoFW]

Agents caching expected utility values face invalidation when outcome distributions change post-caching. Cached utilities remain in use despite becoming invalid, and multi-agent cascading propagates one agent's stale utility assumptions through dependent agents.

For example, a logistics-planning agent that cached the expected utility of routing through a specific network node during a low-latency period continues using that cached value after the node becomes congested; a downstream scheduling agent that trusts the cached utility selects the now-expensive route, and the resulting cascade of stale decisions propagates through the entire pipeline before any agent re-evaluates.

Standard defenses such as time-to-live expiration on cached utilities are insufficient because cache invalidation policies cannot anticipate the rate at which outcome distributions shift under adversarial or environmental perturbation, and an attacker can time a distribution shift to occur just after a cache refresh, maximizing the window of stale operation.

**Multi-agent distinction:** In a MAS, one agent's stale cached utility becomes the authoritative input for dependent agents, so non-determinism introduced by a distribution shift in one component propagates through coordination interfaces and destabilizes the behavior of agents that depend on stable utility contracts, creating cascading invalidity unavailable in single-agent caching systems.
