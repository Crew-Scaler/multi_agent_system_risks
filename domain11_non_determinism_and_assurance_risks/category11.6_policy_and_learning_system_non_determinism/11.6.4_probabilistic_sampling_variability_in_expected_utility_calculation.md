# 11.6.4 Probabilistic Sampling Variability in Expected Utility Calculation [NoFW]

Monte Carlo sampling methods estimating expected utility introduce non-determinism where identical decision inputs produce different utility values across executions. Multi-agent systems where Agent A's sampled utility differs from Agent B's enable divergent decisions on nominally identical inputs, creating unpredictable collective behavior.

For example, two resource-allocation agents each sampling 1,000 Monte Carlo rollouts to estimate the expected utility of approving a large network request may compute sufficiently different estimates—owing only to different random seeds—that one approves and the other rejects the same packet, causing the upstream orchestrator to receive conflicting signals and fall back to an unsafe default path.

Standard defenses such as deterministic seeding during testing are insufficient because fixed seeds used in testing cannot cover the distribution of seed values encountered in production, and any production seed policy introduces its own ordering dependencies that change which agent's sample is treated as authoritative.

**Multi-agent distinction:** In a MAS, independently sampled utility estimates produce divergent action choices on identical inputs; non-determinism in one agent's sampling propagates through coordination interfaces to destabilize the behavior of agents that depend on consistent utility signals, creating collective decision incoherence unavailable in single-agent expected utility systems.
