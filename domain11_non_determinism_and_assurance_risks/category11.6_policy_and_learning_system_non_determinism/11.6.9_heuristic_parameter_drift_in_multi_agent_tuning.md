# 11.6.9 Heuristic Parameter Drift in Multi-Agent Tuning [NoFW]

Heuristic parameters tuned independently for different agents create divergence over time. Parameter divergence creates non-deterministic multi-agent behavior where nominally coordinated agents apply incompatible heuristics to the same coordination problem.

For example, two search agents that each auto-tune their beam-search width and temperature thresholds based on recent task success rates may, after divergent operational histories, apply search heuristics that produce incompatible candidate rankings for the same query; an orchestrating agent that merges their top-k candidates receives a combined list in which the "best" options according to each agent contradict each other, making final selection non-deterministic.

Standard defenses such as centralized hyperparameter governance or periodic re-synchronization checkpoints are insufficient because independent tuning continues between checkpoints, and small per-step divergences compound over many updates into large behavioral differences that are invisible until the agents are asked to coordinate on a shared task.

**Multi-agent distinction:** In a MAS, independently tuned heuristic parameters diverge across agents; non-determinism in one agent's parameter update propagates through coordination interfaces to destabilize the behavior of agents that depend on parameter-compatible heuristics, creating coordination incompatibility unavailable in single-agent tuning systems.
