# 10.2.8 Knowledge Base Source Attribution Loss Through Multi-Agent Processing [NoFW]

Knowledge base documents track source but multi-agent processing loses provenance. Multi-hop agent chains progressively lose source attribution enabling instruction laundering where origin becomes untraceable. A retrieval agent fetches a document with source metadata, a downstream summarizer rewrites and strips citations, and a decision agent uses the summary with no ability to reconstruct the original source.

Standard defenses such as metadata standards and document management policies are insufficient because they govern source attribution at ingestion time but cannot enforce provenance tracking through the transformations applied by each subsequent agent in a multi-hop processing chain that may strip, rewrite, or aggregate source fields without any obligation to preserve them.

**Multi-agent distinction:** Single-agent knowledge base retrieval maintains a direct link between the agent and the source document, enabling source verification when needed; multi-hop multi-agent chains sever this link progressively at each processing stage, creating an instruction-laundering surface proportional to the number of agents that transform the content before a downstream agent acts on it—a structural property that cannot be addressed by source-tracking policies applied only at ingestion.
