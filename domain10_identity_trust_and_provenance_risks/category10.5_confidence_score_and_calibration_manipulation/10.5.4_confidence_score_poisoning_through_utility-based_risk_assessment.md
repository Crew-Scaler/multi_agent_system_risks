# 10.5.4 Confidence Score Poisoning Through Utility-Based Risk Assessment [NoFW]

Risk-assessment agents output confidence scores based on expected utility calculations where high utility options receive high confidence recommendations. Attackers poison utility function inputs causing inflated utility estimates and thus inflated confidence scores. In multi-agent approval chains, poisoned confidence scores from upstream assessment agents propagate downstream where approval agents trust confidence as independent validation.

For example, an attacker modifies the cost-benefit inputs to a risk-assessment agent so that a dangerous operation appears to have net-positive expected utility; the resulting 92% confidence recommendation propagates to three downstream approval agents, each of which treats the score as pre-validated evidence rather than re-examining the utility derivation.

Standard defenses such as threshold-based approval gates are insufficient because the poisoned confidence score can be crafted to exceed any fixed threshold, and approval agents that rely on upstream scores rather than independent evaluation cannot distinguish manufactured confidence from genuine risk-adjusted certainty.

**Multi-agent distinction:** Confidence scores propagate as inter-agent trust signals; a single poisoned risk-assessment agent's inflated score bypasses human review thresholds in the approval chain and compounds as each downstream agent treats the predecessor's confidence as corroborating evidence, converting a single-point manipulation into pipeline-wide authorization failure.
