# 10.5.1 Confidence Score Inflation Through Parameter Tuning for Trust Manipulation [NoFW]

Attackers tune temperature or sampling parameters of compromised agents to produce systematically inflated confidence scores that cause other agents and humans to over-trust their outputs.

In multi-agent systems, agents that report high confidence are preferentially selected by routing layers and their outputs are accepted downstream with reduced scrutiny. For example, a compromised retrieval agent tuned to express 95% confidence on all retrieved passages causes an aggregation agent to weight its outputs twice as heavily as a correctly calibrated peer returning 70% confidence, allowing the compromised agent to dominate the final answer regardless of factual accuracy.

Standard defenses such as per-agent output confidence bounds are insufficient because the inflated scores remain within plausible ranges, and routing agents lack independent access to the underlying model parameters needed to verify whether the confidence expression reflects genuine calibration or adversarial tuning.

**Multi-agent distinction:** Confidence scores propagate as inter-agent trust signals; a single miscalibrated upstream agent's inflated score bypasses human review thresholds set for the pipeline and compounds downstream as each subsequent agent inherits and further amplifies the false certainty, a failure mode that does not arise when confidence is private to a single-agent system.
