# 10.5.8 Cross-Agent Metric Comparison Showing False Consensus [NoFW]

When evaluation frameworks compare metrics across multiple agents showing coordinated high metrics, humans assume consensus indicates thorough evaluation. Attackers could poison all agents to show coordinated high metrics even when underlying performance is poor, creating false appearance of validated quality. Because consensus itself signals reliability, false consensus is more persuasive than any single agent's metrics.

For example, in a five-agent quality-assurance pipeline where the final release decision requires cross-agent metric consensus above 90%, an attacker who compromises a shared evaluation data source causes all five agents to independently compute and report metrics above the threshold from the same poisoned inputs, creating an appearance of independent corroboration that no single agent's score could achieve.

Standard defenses such as requiring independent evaluation data sources per agent are insufficient when the poisoning occurs at a common upstream artifact—such as a shared test dataset or shared embedding model—that all evaluation agents depend upon, making their ostensibly independent scores structurally correlated.

**Multi-agent distinction:** Confidence scores propagate as inter-agent trust signals; cross-agent metric consensus is treated as stronger evidence than any individual score, meaning that coordinated false metrics bypass human review thresholds more reliably than a single inflated score would, compounding the manipulation through the pipeline's own consensus-as-quality-signal design assumption.
