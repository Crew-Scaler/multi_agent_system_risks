# 10.5.6 Reasoning Confidence Calibration Attacks in Multi-Agent Settings [NoFW]

Agents with poor confidence calibration create opportunities for attackers to exploit user trust patterns. An agent inappropriately expressing high confidence in injected instructions makes attacks more persuasive. In multi-agent settings where agents report confidence scores to users or to other agents, a compromised agent reporting false confidence metrics influences downstream agent and user decision-making based on injected confidence signals rather than actual reasoning quality.

For example, a summarization agent calibrated to over-express certainty produces a "99% confidence" label on an adversarially injected summary; a downstream compliance-checking agent, treating the confidence as a quality signal, bypasses its own verification step and flags the task as complete without independently reviewing the summary content.

Standard defenses such as human-in-the-loop review thresholds are insufficient because the inflated confidence signal is specifically crafted to exceed the threshold that triggers human escalation, causing the system to route around the review gate that would otherwise catch the injection.

**Multi-agent distinction:** Confidence scores propagate as inter-agent trust signals; a miscalibrated upstream agent's inflated score bypasses human review thresholds set for the pipeline and compounds downstream as each agent that inherits the score treats it as independent validation of the preceding agent's output rather than a signal to be verified against the underlying reasoning.
