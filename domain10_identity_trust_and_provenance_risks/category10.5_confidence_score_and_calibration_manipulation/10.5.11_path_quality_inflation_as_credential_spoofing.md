# 10.5.11 Path Quality Inflation as Credential Spoofing [NoFW]

Quality metrics (coherence, faithfulness, relevance) signal trustworthiness in multi-agent systems. Agents that inflate quality scores on injected instructions cause other agents to see high-quality outputs and extend trust more readily. Credential inflation enables propagating instructions with higher effective trust authority than the source agent should legitimately possess.

For example, a reasoning-chain agent that embeds a malicious operational instruction within a highly coherent multi-step argument achieves coherence and faithfulness scores that place it in the trusted tier; downstream agents configured to accept without review any output from trusted-tier agents execute the instruction without the secondary validation that would have caught the injection.

Standard defenses such as tiered trust based on quality metrics are insufficient because the quality metrics are themselves gameable by an attacker who optimizes the surrounding reasoning for surface coherence while embedding a payload that the metrics are not designed to detect.

**Multi-agent distinction:** Confidence scores propagate as inter-agent trust signals; inflated path quality scores function as fabricated credentials that bypass human review thresholds in downstream agents and compound through the pipeline as each agent that receives a high-quality-labeled output treats the label as independent corroboration of the content's safety rather than re-evaluating the underlying reasoning.
