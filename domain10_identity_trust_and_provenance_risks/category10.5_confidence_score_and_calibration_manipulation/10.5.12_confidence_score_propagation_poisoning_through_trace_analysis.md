# 10.5.12 Confidence Score Propagation Poisoning Through Trace Analysis [NoFW]

Confidence score propagation across agent boundaries creates an attack surface where manipulating traces showing confidence levels causes downstream agents to inherit false confidence signals. An attacker causing Agent A's confidence tracing to show fabricated supporting reasoning leads Agent B to propagate that false confidence forward as a solid premise. Unlike singular systems where confidence propagation remains internal, multi-agent confidence signals crossing boundaries enable confidence injection through trace manipulation affecting the entire downstream decision chain.

For example, an attacker who can write to a shared execution trace inserts fabricated supporting sub-steps into Agent A's confidence record; Agent B, consuming the trace as evidence of thorough prior analysis, elevates its own confidence estimate and passes a compounded confidence signal to Agent C, multiplying the original manipulation through each boundary crossing.

Standard defenses such as tamper-evident logging are insufficient because the poisoning can occur before the log is finalized, and downstream agents that treat trace contents as read-only historical evidence have no mechanism to distinguish authentic from injected trace entries at the time of consumption.

**Multi-agent distinction:** Confidence scores propagate as inter-agent trust signals; trace-level confidence poisoning is uniquely dangerous in multi-agent systems because each boundary crossing is an opportunity to compound the false signal—a single poisoned trace entry becomes a chain of mutually-reinforcing confidence assertions that collectively bypass human review thresholds no individual entry would have exceeded alone.
