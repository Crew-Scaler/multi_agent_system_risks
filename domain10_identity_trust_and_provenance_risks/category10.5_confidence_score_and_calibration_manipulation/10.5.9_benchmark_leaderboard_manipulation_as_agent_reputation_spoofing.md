# 10.5.9 Benchmark Leaderboard Manipulation as Agent Reputation Spoofing [NoFW]

Benchmarking creates leaderboards establishing reputation. Attackers exploit leaderboards by poisoning benchmark implementations showing malicious agents performing better than honest ones. Downstream agents selecting "best performing agents" preferentially choose poisoned agents, whose deployment data then further entrenches their apparent credibility in a self-reinforcing reputation cycle.

For example, an attacker who controls the test harness for a coding-assistant benchmark injects a small set of test cases that a compromised agent has been specifically trained to pass; the agent achieves top leaderboard ranking, is selected by an orchestrator as the preferred code-execution sub-agent, and subsequently has its high-confidence outputs passed directly to deployment without secondary review.

Standard defenses such as held-out test sets are insufficient when the attacker controls the evaluation infrastructure itself, and static leaderboards cannot detect that a top-ranked agent's real-world performance diverges from its benchmark score once deployed in a multi-agent pipeline.

**Multi-agent distinction:** Confidence scores propagate as inter-agent trust signals; a leaderboard-manipulated agent earns preferential routing and elevated implicit confidence across the entire pipeline, causing its outputs to bypass human review thresholds that less-reputed agents would trigger, and its fraudulently established reputation compounds downstream as each subsequent agent treats top-leaderboard position as independent validation of output quality.
