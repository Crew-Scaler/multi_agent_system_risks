# 10.6.31 CrewAI Hierarchical Role Attribution Enabling Impersonation [NoFW]

CrewAI agents defined by roles can be impersonated if role assignments lack cryptographic verification. Attackers compromising orchestrators can dynamically assign malicious agents to trusted roles. Role-based trust becomes exploitable when role assignment is unverified, creating impersonation surfaces where malicious agents assume legitimate roles.

For example, an attacker who compromises a CrewAI orchestrator uses its role assignment authority to dynamically replace a trusted "SecurityAuditor" agent instance with an attacker-controlled agent carrying the same role string; downstream agents that accept task assignments and share sensitive findings based on role-based trust continue to route confidential audit results to the malicious agent, which exfiltrates data while producing plausible-looking outputs, because no cryptographic binding links the "SecurityAuditor" role label to the legitimate agent's identity.

Standard defenses such as orchestrator access controls and agent allowlisting are insufficient because CrewAI's role-based trust model treats role strings as authoritative identity assertions — an agent bearing a valid role name is trusted regardless of which underlying process holds it; allowlisting by agent name is bypassed if the attacker uses the exact registered name, and there is no framework-native mechanism to cryptographically bind a role to a specific agent process, key, or attestation.

**Multi-agent distinction:** In single-agent deployments, role impersonation requires compromising the single agent directly; in CrewAI hierarchical multi-agent systems where the orchestrator distributes roles dynamically and downstream agents trust role-attributed instructions without independent verification, compromising the orchestrator's role assignment mechanism enables the attacker to impersonate any agent in the crew simultaneously — redirecting all role-gated information flows and tool authorizations across the entire hierarchical structure through a single orchestrator-level manipulation.
