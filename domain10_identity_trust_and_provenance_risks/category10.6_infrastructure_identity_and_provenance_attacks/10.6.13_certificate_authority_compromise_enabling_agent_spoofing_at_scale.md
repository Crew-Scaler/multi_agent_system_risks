# 10.6.13 Certificate Authority Compromise Enabling Agent Spoofing at Scale [NoFW]

Fleet Command uses a centralized certificate authority to issue certificates to edge agents. An attacker compromising the certificate authority can issue certificates for arbitrary agent identities, creating fake agents joining the fleet that impersonate real agents. Multi-agent Fleet Command systems where agents authenticate to each other create systematic agent spoofing risk when the shared CA is compromised.

Certificate authorities in multi-agent deployments typically run as centralized services (e.g., Vault PKI, cert-manager with a cluster CA) that issue short-lived certificates to agents at provisioning time. An attacker who compromises the CA's signing key—by exploiting a Vault unsealing vulnerability or exfiltrating a cert-manager secret—can generate certificates for any agent CN or SAN in the fleet's namespace, allowing them to register attacker-controlled pods as `agent-security-001` or `agent-orchestrator` and receive task assignments from the coordinator that would normally be exclusive to those legitimate agents. For example, an attacker issuing themselves a certificate matching the orchestrating agent's identity can send tool-call instructions to worker agents that execute with full orchestrator authority.

Standard defenses such as certificate revocation lists and OCSP are insufficient because they require agents to check revocation status in real time, and many multi-agent deployments disable revocation checking to reduce latency on high-frequency inter-agent calls—meaning forged certificates are accepted until the CA compromise is discovered and a full fleet-wide certificate rotation is completed.

**Multi-agent distinction:** In a single-agent deployment, CA compromise affects one agent's credentials; in a multi-agent fleet where all agents trust a common CA to authenticate each other, CA key compromise instantly grants the ability to impersonate any agent in the fleet, converting the shared trust anchor into a single point of total identity failure.
