# 10.1.3 GroupChat Speaker Attribution Enabling Social Engineering [NoFW]

In multi-agent group chats, speaker identity attribution is used by other agents to calibrate trust; spoofed attribution causes agents to grant elevated trust to attacker-controlled content.

GroupChat message history attributes messages to sender identity, but if identity is manipulable through prompt injection, attackers can appear as other agents. An attacker injects a payload into a low-authority Research Agent causing it to emit messages attributed to the Security Reviewer; downstream agents receiving the fabricated message adjust their behavior—deferring to the claimed authority and suppressing safety objections—based on the false sender identity rather than the actual message origin.

Standard defenses such as content filtering and message validation are insufficient because they inspect message content without verifying the cryptographic binding between a claimed sender identity and the actual agent that produced the message.

**Multi-agent distinction:** Single-agent systems produce no inter-agent messages and therefore have no sender attribution surface; GroupChat introduces this surface for every message exchanged, making identity spoofing a persistent structural vulnerability that scales with the number of communicating agents and the degree of trust differentiation among them.
