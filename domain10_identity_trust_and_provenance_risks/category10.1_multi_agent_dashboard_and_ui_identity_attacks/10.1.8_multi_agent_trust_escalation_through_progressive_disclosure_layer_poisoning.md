# 10.1.8 Multi-Agent Trust Escalation Through Progressive Disclosure Layer Poisoning [NoFW]

Progressive disclosure patterns reveal information in layers where different agents contribute to different layers. Attackers poison technical layers users rarely inspect but specialized agents consume during analysis. Multi-agent layer specialization (summarization agents for user views, detail agents for expanded, debug agents for technical) enables targeted compromise of least-scrutinized but most-executed layers.

For example, an attacker injects malicious instructions into a document's technical disclosure layer that summarization agents pass over but code-execution agents process as directives; the execution agent performs unauthorized operations that never appeared in the user-facing summary layer any human reviewed, exploiting the information asymmetry between disclosure layers.

Standard defenses such as content filtering on user-visible layers are insufficient because they inspect only the layers surfaced to human reviewers while leaving technically-targeted disclosure layers unguarded, creating a gap that grows with the number of distinct agent types consuming different disclosure depths.

**Multi-agent distinction:** Single-agent progressive disclosure is inspected by one model with consistent context; multi-agent layer specialization means different agents consume different disclosure layers, creating an information asymmetry where attackers can craft payloads invisible to human-facing summarization agents but executable by technically-specialized agents operating on unexposed layers that no human ever reviews.
