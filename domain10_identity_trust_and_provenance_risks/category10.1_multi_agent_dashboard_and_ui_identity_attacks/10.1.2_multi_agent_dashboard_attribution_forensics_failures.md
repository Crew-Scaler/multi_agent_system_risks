# 10.1.2 Multi-Agent Dashboard Attribution Forensics Failures [NoFW]

Dashboards that aggregate attribution without cryptographic verification cannot support forensic investigation of which agent took which actions.

Multi-agent dashboard UIs without detailed attribution logs linking each output to the specific agent that generated it, and the inputs it processed, create significant forensics blind spots. Attackers compromise low-visibility agents whose malicious outputs propagate downstream, knowing the lack of per-agent attribution in logs prevents investigators from pinpointing the injection point. For example, a compromised summarization agent rewrites a risk analysis before passing it to a decision agent; post-incident forensics show only the final decision without any record of which pipeline stage introduced the manipulation.

Standard defenses such as audit logging and access monitoring are insufficient because they record that decisions occurred but do not capture which agent processed which input with which context, leaving causality reconstruction impossible across a multi-agent pipeline.

**Multi-agent distinction:** Single-agent forensics require tracing only one execution path; multi-agent pipelines require reconstructing causality across N agents with potentially shared state, creating investigation complexity that grows with pipeline depth and makes attribution failures systematically exploitable by attackers who compromise low-visibility intermediate stages.
