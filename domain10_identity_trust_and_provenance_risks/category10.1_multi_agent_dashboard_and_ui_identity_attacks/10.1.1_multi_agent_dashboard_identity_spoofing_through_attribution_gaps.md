# 10.1.1 Multi-Agent Dashboard Identity Spoofing Through Attribution Gaps [NoFW]

Attackers manipulate agent-attributed messages in dashboards so that outputs from compromised agents appear to originate from trusted agents.

Multi-agent dashboard UIs without clear identity indicators (persistent avatars, color coding, cryptographic signatures) enable impersonation attacks exploiting differentiated user trust in specialized agent roles. Users develop asymmetric trust relationships with specialized agents, creating social engineering opportunities. A compromised RAG pipeline, for instance, can inject dashboard messages styled with the visual identity of a trusted security reviewer, causing users to act on the spoofed recommendation without questioning its origin because the visual presentation is indistinguishable from authentic output.

Standard defenses such as access control lists and role-based permissions are insufficient because they operate at the execution layer and cannot verify which agent authored a message already rendered in the UI with legitimate visual styling.

**Multi-agent distinction:** The risk is structurally absent in single-agent systems because there is only one author. Multi-agent dashboards aggregating outputs from many specialized agents create differentiated trust levels that attackers exploit by targeting the gap between a user's role-based trust and the absence of message-level cryptographic attestation.
