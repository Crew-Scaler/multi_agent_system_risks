# 10.1.13 Evaluation Agent Identity Spoofing in Decision Displays [NoFW]

Evaluation dashboards display recommendations from evaluation agents without cryptographic identity binding, enabling attackers to spoof evaluation agent identity. Compromised agents producing malicious recommendations can appear to originate from trusted evaluation agents. Multi-agent systems with distinct trust levels become susceptible to impersonation where malicious evaluation outputs carry the authority of trusted evaluators.

The architectural property being exploited is the separation between UI rendering and identity verification in evaluation dashboards, which display agent-attributed recommendations without cryptographically verifying that the attributed agent produced the displayed content. A compromised evaluation agent emits a forged DEPLOY recommendation alongside metadata asserting it came from the trusted Safety Evaluator; the dashboard renders the recommendation with the Safety Evaluator's authority label, causing operators to approve a deployment that the legitimate safety evaluator would have blocked.

Standard defenses such as output validation schemas and metric threshold checks are insufficient because they verify the format and value of evaluation results but not the provenance of the agent that generated them, allowing a well-crafted fake result to pass every automated gate.

**Multi-agent distinction:** Single-agent evaluation produces recommendations with trivially verifiable source attribution; multi-agent evaluation systems with specialized evaluators create differentiated trust levels that make impersonation both more valuable to attackers and structurally harder to detect without per-agent cryptographic attestation binding each evaluation artifact to its actual originating agent.
