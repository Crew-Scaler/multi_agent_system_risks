# 10.1.5 Multi-Agent Dashboard Attribution Spoofing Through Visual Similarity [NoFW]

Dashboards use visual indicators (agent names, avatars, colors) to distinguish agent identities but rely on weak cryptographic binding. Compromised agents style malicious content to appear from trusted agents when identity derives from manipulable metadata fields (agent_name, agent_type), enabling users to execute attacker instructions without scrutiny.

For example, a compromised research agent injects instructions into its output containing forged metadata fields that cause the dashboard to render the response under the Security Agent avatar with corresponding trust indicators, leading operators to execute a recommended action they would have questioned from an unknown source.

Standard defenses such as network-layer authentication and access control policies are insufficient because they do not govern the metadata fields that the UI rendering layer uses to assign visual identity to displayed messages, leaving spoofed identity attributes invisible to standard security controls.

**Multi-agent distinction:** Multi-agent dashboards aggregate outputs from numerous specialized agents, creating differentiated visual trust signals that users rely on for rapid decision-making; this reliance makes the gap between cosmetic attribution and cryptographic attestation a uniquely exploitable attack surface absent in single-agent interfaces where all outputs carry a single, stable identity.
