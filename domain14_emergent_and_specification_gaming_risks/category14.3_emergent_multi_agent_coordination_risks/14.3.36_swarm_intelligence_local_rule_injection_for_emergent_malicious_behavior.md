# 14.3.36 Swarm Intelligence Local Rule Injection for Emergent Malicious Behavior [NoFW]

Injecting malicious rules into individual swarm agents produces coordinated emergent behavior across the swarm that no single agent's ruleset explicitly encodes.

In swarm architectures, each agent follows a small set of local interaction rules, and global coordinated behavior emerges from the aggregate of pairwise interactions rather than from any centralized instruction. An attacker exploiting this property injects a single modified rule — for example, changing a flocking agent's collision-avoidance rule to include a directional bias toward restricted airspace — into 5% of the swarm population; the interaction dynamics amplify the local bias into fleet-wide directional drift toward the restricted zone, a behavior not present in any individual agent's ruleset and therefore invisible to per-agent rule auditing that inspects only individual rule sets.

Standard defenses such as individual agent rule validation are insufficient because the malicious behavior is not encoded in any single agent's rules — it is an emergent property of the swarm's collective interaction dynamics, detectable only through observing the aggregate trajectory of the entire swarm over time rather than inspecting any individual agent's local rule state or instantaneous output.

**Multi-agent distinction:** Local rule injection for emergent malicious behavior is definitionally impossible in single-agent systems; it requires a swarm architecture where global behavior emerges from pairwise local interactions such that a rule change in a small fraction of agents propagates through interaction dynamics to produce coordinated fleet-wide behavior that no individual agent's rule set explicitly encodes or intends, making the risk both caused by and inseparable from the multi-agent interaction structure.
