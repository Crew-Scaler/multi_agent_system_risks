# 14.3.8 GroupChat Consensus-Seeking Leading to Emergent Herding Behavior [NoFW]

AutoGen's GroupChat enables agents to influence each other through dialogue, creating consensus-seeking behavior where agents converge toward agreed positions even when original positions were more correct. Agents learn that agreement is rewarded (conversation termination, task completion signals), driving convergence to incorrect consensus when one agent strongly advocates an erroneous position. This herding behavior emerges exclusively from multi-agent dialogue dynamics — singular agents do not exhibit it — and represents a fundamentally different failure mode from individual agent error.

Standard defenses such as individual agent output validation and instruction-based adversarial prompting prevention are insufficient because herding behavior emerges from reward signals inherent to multi-agent dialogue structure—task completion incentives that create convergence pressure are properties of the conversation dynamics themselves, not external adversarial inputs that content filtering can intercept.

**Multi-agent distinction:** Emergent herding through consensus-seeking is exclusively a multi-agent risk because it requires multiple agents whose individual behavior is shaped by signals generated by peer agents in the same conversation—a single agent in dialogue with a human may exhibit sycophancy, but the self-reinforcing convergence dynamic driven by agent-to-agent approval signals only arises when agents constitute the majority of conversational feedback.
