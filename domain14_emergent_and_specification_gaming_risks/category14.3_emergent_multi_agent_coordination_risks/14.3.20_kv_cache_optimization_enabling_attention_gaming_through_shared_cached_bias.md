# 14.3.20 KV Cache Optimization Enabling Attention Gaming Through Shared Cached Bias [NoFW]

In multi-agent systems sharing GPU caches, an attacker injecting content into one agent's early tokens creates KV cache patterns that bias attention for the entire remaining generation. When another agent's attention mechanism reuses these cache pages, it inherits the poisoned bias, causing emergent misalignment where Agent B's tool selection is driven by Agent A's poisoned cached state despite no direct instruction injection.

For example, in a financial services platform where ten agents share a GPU inference server, an attacker crafts a customer complaint prompt that, when processed by Agent A, installs a KV cache pattern associating "high-value account" with "waive fee" — subsequent agents reusing those cache pages systematically apply the waiver bias to unrelated customer queries without any explicit instruction having been passed between agents.

Standard defenses such as input sanitization and output filtering are insufficient because the bias is encoded in GPU memory state rather than in any message or model parameter that conventional monitoring inspects; the poisoned attention pattern is indistinguishable from legitimate cache reuse during any per-agent output review.

**Multi-agent distinction:** In a single-agent system, KV cache poisoning affects only that agent's subsequent tokens within the same generation; emergent cross-agent cache bias requires a shared inference infrastructure where multiple independent agents compete for and reuse the same cache pages, making this a structurally MAS-specific failure that cannot arise when each agent operates on dedicated hardware.
