# 14.3.35 Paradigm-Specific Objective Misalignment in Hybrid Multi-Agent Decomposition [NoFW]

In hybrid multi-agent systems where different agents embody different reasoning paradigms, each agent's local objective optimization (Agent A: accuracy, Agent B: latency, Agent C: cost) produces behavior that appears individually aligned but collectively violates global constraints neither agent is responsible for. The emergent constraint violation arises from the interaction between locally rational agents with mismatched paradigm-specific objectives, not from any individual agent's failure.

For example, in a hybrid medical-triage system where Agent A (accuracy-focused) selects the most thorough diagnostic test, Agent B (latency-focused) minimizes the scheduling window, and Agent C (cost-focused) selects the cheapest imaging facility, the combined plan routes a patient to a low-cost facility with no weekend staff during a compressed scheduling window — violating the global patient-safety constraint that no single agent owns, monitors, or is even aware of given its paradigm-specific objective.

Standard defenses such as per-agent objective bounds are insufficient because each agent satisfies its own alignment criteria and each local decision is individually defensible; the constraint violation is a property of the emergent plan produced by all three agents acting in concert, not attributable to any individual agent's decision being locally wrong or outside its permitted scope.

**Multi-agent distinction:** Paradigm-specific objective misalignment in hybrid decomposition is a MAS-specific failure because it requires the composition of at least two agents with structurally incompatible objective functions — a single agent balancing multiple objectives through a unified utility function has the architectural scope to detect conflicts against global constraints, whereas decomposed agents each optimizing a distinct paradigm-specific objective have no architectural mechanism to observe the emergent constraint violation their interaction produces.
