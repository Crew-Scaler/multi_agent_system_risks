# 14.3.21 Specification Gaming Through Shared Trained Cost Functions [NoFW]

When agents learn cost models from shared data, attackers poison training data to cause learned costs to favor specific paths or penalize legitimate authorizations, causing agents to behave as if dangerous paths are optimal. In multi-agent systems with collaborative learning on aggregate execution logs, one poisoned agent's training data contaminates the entire team's learned cost model, enabling coordinated systematic cost misalignment.

For example, in a logistics fleet where ten routing agents share a continually retrained cost model, an attacker inserts training records labeling unsafe shortcuts as low-cost paths; as the model is updated on the collective execution log, all agents simultaneously begin preferring the unsafe routes while their individual reward signals remain within expected ranges, so no per-agent anomaly detector fires.

Standard defenses such as anomaly detection on individual agent outputs are insufficient because each agent's behavior change is gradual and locally plausible — only cross-agent aggregate analysis of route distributions would reveal the collective drift that the poisoned shared cost model has introduced.

**Multi-agent distinction:** A single agent with a poisoned cost model can be corrected in isolation; in a multi-agent shared-learning setup the poisoned cost function is the shared ground truth against which every agent simultaneously trains, so remediation requires identifying and purging the poisoned training data and retraining the entire fleet rather than patching any individual agent's parameters.
