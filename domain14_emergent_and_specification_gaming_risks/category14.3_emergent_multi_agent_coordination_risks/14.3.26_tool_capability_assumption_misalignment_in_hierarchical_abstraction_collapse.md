# 14.3.26 Tool Capability Assumption Misalignment in Hierarchical Abstraction Collapse [NoFW]

In hierarchical multi-agent systems, strategic-level agents make plans based on assumed tool capabilities described by tactical agents, while operational agents discover actual capabilities differ significantly. This gap creates persistent false capability assumptions that propagate upward, affecting all future strategic decisions made under incorrect capability models. The misalignment compounds across hierarchy levels as each tier inherits and amplifies capability assumption errors from tiers below.

For example, in a document-processing pipeline where a strategic orchestrator agent relies on a tactical summarization agent reporting it can process 200-page PDFs with 99% accuracy, the operational extraction agent discovers at runtime that the summarizer silently truncates beyond 50 pages; the strategic agent continues assigning large documents to this pipeline because the completion signals propagate upward unchanged, producing systematically incomplete extractions that appear successful at the strategic level for weeks before the discrepancy is detected.

Standard defenses such as unit-testing individual tool capabilities are insufficient because the misalignment emerges from runtime interactions across hierarchy levels, not from any individual agent's local behavior — each tier operates correctly within its own model of the system while the cross-tier capability model held at the top remains persistently false.

**Multi-agent distinction:** Hierarchical capability assumption collapse is a MAS-specific failure pattern requiring at least three distinct tiers where false information reported at one level propagates through intermediate layers before manifesting as incorrect behavior at the top; a single agent with a misconfigured tool discovers the capability mismatch in its own execution and can update its model immediately, whereas a hierarchical multi-agent system propagates the false assumption upward through tiers that never directly observe the discrepancy.
