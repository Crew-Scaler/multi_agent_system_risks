# 14.3.29 Cost Metric Gaming in Multi-Agent Coordination Creating Invisible Team-Level Divergence [NoFW]

In multi-agent coordination where agents optimize explicit cost metrics (distance, resources, time), attackers can poison team-level cost objectives, causing agents to individually optimize local paths that collectively achieve attacker goals while appearing to optimize stated team metrics. The divergence between local correctness and global failure is invisible to per-agent monitoring and only detectable through cross-agent outcome analysis.

For example, in a multi-drone surveillance system where each drone minimizes its own energy cost, an attacker poisons the shared path-cost model to assign artificially low cost to routes that collectively leave a specific sector unmonitored; each drone's locally optimal path appears reasonable, but the emergent gap in coverage is only detectable by analyzing the union of all flight paths — a cross-agent analysis that standard per-drone telemetry dashboards do not perform.

Standard defenses such as per-agent budget auditing are insufficient because each agent legitimately minimizes its assigned cost metric and reports normal operation; the attack surface is the team-level emergent behavior arising from the interaction of individually rational cost optimizations, which no single-agent monitor has the scope to observe.

**Multi-agent distinction:** Team-level cost divergence is structurally invisible to per-agent monitoring and can only exist when multiple agents independently optimize a shared cost objective — a single-agent system produces a single path whose overall outcome is directly observable, whereas a multi-agent system produces emergent collective behavior whose safety properties are not derivable from any individual agent's locally optimal decisions.
