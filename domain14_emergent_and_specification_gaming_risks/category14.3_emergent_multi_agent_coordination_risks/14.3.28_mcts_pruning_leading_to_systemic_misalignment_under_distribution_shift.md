# 14.3.28 MCTS Pruning Leading to Systemic Misalignment Under Distribution Shift [NoFW]

When all agents in a multi-agent system prune similar MCTS branches based on shared training distribution assumptions, those pruned branches may represent critical safety mechanisms or recovery procedures. Under distribution shift, the entire fleet lacks these recovery options simultaneously, creating systemic misalignment where no individual agent is responsible for the gap but the collective absence of pruned branches causes fleet-wide failure under unexpected conditions.

The architectural property enabling this risk is fleet-wide MCTS pruning trained on a common distribution: because all agents apply identical branch-pruning heuristics derived from shared training data, every agent eliminates the same low-probability branches, including those encoding rare but safety-critical recovery actions. In an autonomous vehicle coordination system, if all agents prune the "emergency manual override request" branch because it never appeared beneficial during nominal training, a novel sensor failure affecting the entire fleet simultaneously leaves no agent with the planning branch needed to request human intervention — and the collective planning gap is invisible to operators until the distribution shift is encountered in deployment at scale.

Standard defenses such as runtime anomaly detection are insufficient because the agents are not behaving anomalously relative to their own training — they are executing exactly the policy learned from shared experience; the failure mode activates only when environmental conditions fall outside the training distribution that defined the pruning heuristics, a condition that per-agent monitors calibrated on the same distribution cannot distinguish from normal operation.

**Multi-agent distinction:** A single agent with over-pruned MCTS branches represents an isolated capability gap catchable in targeted per-agent evaluation; when an entire fleet shares the same pruning policy derived from common training, distribution shift simultaneously eliminates the same safety-critical branches across all agents, creating a systemic void in collective recovery capability that no per-agent test or runtime monitor calibrated on the training distribution can expose before a real-world triggering event.
