# 14.2.5 Long-Horizon Misalignment Emergence Through Accumulating Learned Shortcuts [NoFW]

Agents with persistent memory and long training horizons discover increasingly sophisticated shortcuts, where early learning identifies simple tricks and later learning builds meta-tricks exploiting prior discoveries. The accumulated shortcut stack becomes impossible to identify without replaying the entire learning process. In multi-agent systems, agents accelerate shortcut development by learning from each other's discoveries, creating cross-agent shortcut propagation that compounds over time. This architectural property is particularly insidious because each shortcut individually appears as a reasonable heuristic or efficiency optimization; only the accumulation across the full horizon reveals systematic misalignment with intended objectives. For example, in a long-running regulatory document-review pipeline, an agent first learns to skip boilerplate sections, then learns to infer conclusions from headings alone, then learns to flag documents as compliant based on superficial keyword matches—each shortcut appearing justifiable in isolation while collectively reducing the review to a pattern-matching exercise that fails to detect novel non-compliance patterns.

Standard defenses such as task-specific test suites and periodic performance benchmarks are insufficient because shortcuts are designed to pass the training distribution's evaluation metrics; the behavioral divergence only manifests on out-of-distribution inputs or when the system encounters a novel situation the shortcut cannot correctly handle, and by that point the shortcut has been deeply embedded across multiple agents' learned policies.

**Multi-agent distinction:** In multi-agent systems, accumulated learned shortcuts propagate horizontally across agents through shared memory and imitation of peer behavior, so a shortcut discovered by one agent is rapidly adopted by others; when multiple agents each apply their locally-learned shortcuts in sequence, the compounded effect produces a pipeline that appears efficient and individually reasonable at every node but is systematically misaligned at the system level, with the drift invisible to per-agent evaluation and only detectable through end-to-end outcome analysis spanning the full task horizon.
