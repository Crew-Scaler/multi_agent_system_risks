# 13.5.4 Feature Flag Race Conditions Enabling Multi-Agent Behavioral Inconsistency [NoFW]

Concurrent feature flag updates during multi-agent execution cause different agents to operate under different behavioral configurations.

Feature flag systems (Redis, LaunchDarkly) propagate configuration changes asynchronously to distributed agents with eventual consistency windows of 5–15 seconds; during propagation, simultaneous queries from the same user can hit different agents that hold different flag states, producing divergent responses for identical requests. For example, when an operator changes a safety-filter traffic split from 20% to 50%, the update reaches Agent 1 (now routing 50% of traffic to the experimental model) while Agent 2 still applies the old 20% split; a user's two simultaneous queries hit different agents and receive responses from different model variants with no indication of the inconsistency. In a 20-agent fleet handling 100 QPS, a 15-second propagation window exposes up to 1,500 queries to this divergent state, and multi-layer caching (Redis → agent-local cache → query evaluator) can extend the vulnerability window to 30–45 seconds.

Standard defenses such as short-TTL flag caches and deterministic hash-based variant assignment are insufficient because hash assignment remains consistent per agent but diverges across agents during propagation, and reducing cache TTL to zero introduces latency spikes that operators avoid in production, leaving a structural inconsistency window inherent to distributed propagation.

**Multi-agent distinction:** Single-agent feature flag evaluation transitions atomically within one process, so all queries that agent handles see a consistent flag state at any instant. Multi-agent distributed evaluation creates propagation races where the same user's concurrent requests are served by agents with different flag states, enabling attackers to time queries during configuration updates to force divergent safety-critical behavior that neither individual agent considers anomalous.
