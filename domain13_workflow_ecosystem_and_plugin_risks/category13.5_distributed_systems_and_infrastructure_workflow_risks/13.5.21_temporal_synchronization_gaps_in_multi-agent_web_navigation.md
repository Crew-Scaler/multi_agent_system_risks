# 13.5.21 Temporal Synchronization Gaps in Multi-Agent Web Navigation [NoFW]

Multi-agent web navigation coordinates agents performing session management, JavaScript execution, and DOM interaction with page state that changes between agent handoffs; attackers exploit coordination timing gaps to inject malicious instructions into shared page state after one agent's operation completes and before the next agent reads that state.

For example, in a multi-agent checkout workflow where Agent A handles authentication and session establishment and Agent B handles payment form completion, an attacker who controls a reflected XSS vector on the target site can inject a JavaScript mutation that modifies the payment amount field in the DOM between Agent A's session-establishment confirmation and Agent B's form-read operation; Agent B reads and submits the tampered amount without detecting the modification because it trusts the session state handed off by Agent A as current and valid.

Standard defenses such as DOM snapshot comparison at handoff and session integrity tokens are insufficient because the attack exploits the synchronization gap between agent handoffs—the DOM is valid when Agent A completes and valid when Agent B reads it, but different between those two moments in a transition that snapshot-before-handoff approaches cannot detect without continuous monitoring during the gap itself.

**Multi-agent distinction:** Single-agent web navigation reads and writes DOM state within one continuous execution context where intermediate state changes are either detected or controlled by the same agent. Multi-agent web navigation creates handoff gaps between independently executing agents where page state can be modified in the interval between one agent's write and the next agent's read, producing TOCTOU vulnerabilities in shared DOM state that have no analog in single-agent sequential page interaction.
