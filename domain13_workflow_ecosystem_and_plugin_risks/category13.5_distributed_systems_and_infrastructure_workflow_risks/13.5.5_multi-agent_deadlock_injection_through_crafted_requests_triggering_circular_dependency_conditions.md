# 13.5.5 Multi-Agent Deadlock Injection Through Crafted Requests Triggering Circular Dependency Conditions [NoFW]

Adversaries craft ambiguous requests that trigger simultaneous clarification-seeking between interdependent agents, creating bilateral wait conditions where neither agent can proceed. Requests with compound ambiguity (temporal, domain, scope, novelty dimensions) trigger circular waits—Planner needs Researcher context before planning, Researcher needs Planner scope before searching—achieving high deadlock probability (up to 95% for optimally crafted requests) and consuming resources throughout 45-second timeout periods. Single-agent workflows cannot deadlock; multi-agent autonomous coordination creates this attack surface by enabling circular dependency between agents that each await the other's output.

Standard defenses such as timeout-based deadlock detection and per-agent watchdog timers are insufficient because each agent's timeout fires independently without knowledge of the other agent's wait state; the bilateral dependency is resolved only by abandoning both workflows rather than breaking the cycle—consuming full timeout resources on every deadlock-inducing request and offering no path to partial recovery.

**Multi-agent distinction:** Single-agent workflows have no peer agents to create circular wait conditions with, so clarification-seeking behavior at most stalls that one agent until timeout without blocking other work. Multi-agent autonomous coordination introduces bilateral wait surfaces where crafted compound ambiguity can simultaneously activate clarification-seeking in two interdependent agents, creating circular blocking that scales with the number of agent pairs sharing coordination dependencies and can be weaponized to saturate infrastructure with resource-consuming stalls per injected request.
