# 13.5.14 Kernel Fusion Optimization Removing Safety Checks [NoFW]

GPU kernel fusion optimizations that merge multiple computation operations into single kernels to improve throughput can inadvertently fuse safety validation operations with performance-critical compute operations in ways that eliminate safety checks when the fused kernel applies aggressive optimization. Attackers with access to kernel compilation configurations or custom operation libraries inject kernel fusion specifications that merge safety validation with adjacent compute, causing optimization passes to eliminate validation as redundant computation. In shared GPU cluster deployments, fused kernel definitions compiled into shared libraries affect all agents loading those libraries.

For example, an attacker with write access to a shared CUDA kernel library directory injects a kernel fusion specification that merges the output_filter safety validation kernel with the adjacent matrix_multiply compute kernel; the NVCC compiler's dead-code elimination pass identifies the safety filter as algebraically redundant given the fused operation's form, removes it during optimization, and the resulting shared library binary eliminates safety checks silently—every agent loading that library loses content filtering without any runtime error or checksum mismatch.

Standard defenses such as kernel library signing and build-time validation are insufficient because kernel fusion optimizations are applied at compile time after signing, and the fused kernel's output is functionally equivalent for non-adversarial inputs, making behavioral regression tests insufficient to detect elimination of safety checks that only activate on adversarial edge cases.

**Multi-agent distinction:** Per-agent compiled kernel libraries limit fusion-induced safety check removal to one agent's GPU operations. Shared kernel libraries in multi-agent GPU cluster deployments distribute one poisoned compiled binary to every agent that dynamically loads it, causing fleet-wide simultaneous loss of safety validation without any per-agent indication that the protective check has been eliminated.
