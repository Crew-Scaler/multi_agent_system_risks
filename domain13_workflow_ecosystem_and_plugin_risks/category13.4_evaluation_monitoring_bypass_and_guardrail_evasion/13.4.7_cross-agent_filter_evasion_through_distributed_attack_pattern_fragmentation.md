# 13.4.7 Cross-Agent Filter Evasion Through Distributed Attack Pattern Fragmentation [NoFW]

Multi-agent architectures with per-agent anomaly detection enable distributed attack pattern fragmentation where adversaries spread malicious requests across the fleet to stay below per-agent detection thresholds while achieving aggregate attack impact. Submitting 100 toxic prompt injections distributed evenly across 45 agents (2.22 per agent) keeps each agent's rate below the 20-violation detection threshold despite representing 28,800 daily fleet-wide violations. Centralized cross-agent correlation would detect temporal clustering and source commonality, but per-agent monitoring partitioning creates correlation blindness that single-agent unified monitoring would not exhibit.

Standard defenses such as per-agent anomaly detection and per-agent violation rate thresholds are insufficient because each agent's individual metrics remain below detection limits; the attack is only visible through cross-agent temporal correlation analysis that requires centralized visibility into the full fleet's request patterns simultaneously — a capability that per-agent monitoring architectures structurally lack.

**Multi-agent distinction:** In single-agent deployments, attack volume is bounded by that agent's detection threshold, limiting effective attack throughput; in multi-agent architectures, adversaries multiply effective attack throughput by the number of agents in the fleet while keeping each agent's individual contribution sub-threshold, making distributed fragmentation an attack surface that exists solely because monitoring responsibility is partitioned across agents rather than centralized.
