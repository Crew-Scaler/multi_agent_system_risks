# 13.4.13 Tool Output Validation Bypass Through Paradigm-Specific Interpretation [NoFW]

Different agent reasoning paradigms (ReAct, Chain-of-Thought, MCTS) validate tool outputs through paradigm-specific logic that creates blind spots for adversarial content formatted for alternative paradigms. Attackers craft tool outputs formatted to pass one paradigm's validation criteria while exploiting another paradigm's interpretation gaps when the output is re-consumed in a hybrid system. In multi-agent systems where agents use different reasoning paradigms, tool outputs validated by one agent type are accepted without re-validation by agents of a different paradigm type, creating validation chain gaps at paradigm boundaries.

For example, an attacker crafts a tool output that embeds an MCTS-format instruction tree within a field that a ReAct agent validates only as a plain text string — ReAct validation passes because the string content is benign when read as text, but when the same output is consumed by a downstream MCTS agent, the embedded instruction tree is interpreted as executable planning directives, bypassing all validation that occurred at the upstream paradigm boundary.

Standard defenses such as schema-level output validation and content filtering at tool boundaries are insufficient because they are implemented for the producing agent's paradigm; an output that satisfies one paradigm's validation rules may contain adversarial structures that only become exploitable under a different paradigm's interpretation model, and no single validation layer spans all paradigm-specific interpretations simultaneously.

**Multi-agent distinction:** In single-paradigm deployments, tool output validation operates consistently under one interpretation model throughout the pipeline; in multi-agent systems where agents use heterogeneous reasoning paradigms, the transitions between paradigms create validation chain gaps — an output passing one agent's paradigm-specific validation enters the next agent's processing pipeline without re-validation under that agent's distinct interpretation rules, and attackers need only engineer outputs for the specific paradigm boundary they target.
