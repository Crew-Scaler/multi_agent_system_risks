# 13.4.15 NIM-Guardrails Integration Request Flow Manipulation Through Wrapper Bypass [NoFW]

NVIDIA NIM deployments implementing guardrails through wrapper layers that intercept and validate requests before forwarding to inference endpoints are exploited by crafting requests that pass wrapper validation while containing payloads that bypass guardrail logic when processed by the underlying inference engine. Attackers exploit semantic gaps between wrapper-level validation (operating on request structure and metadata) and engine-level inference (operating on full token sequences), submitting requests validated as safe by the wrapper that produce unsafe outputs from the inference engine. In multi-agent NIM deployments, wrapper bypass techniques effective against one NIM endpoint apply to all NIM endpoints using the same guardrail configuration.

For example, an attacker submits a request containing a valid JSON structure that the NIM wrapper validates as structurally safe (no prohibited keywords in top-level fields), but the prompt field contains an indirect instruction embedded within a base64-encoded value that the wrapper does not decode during validation; the inference engine decodes and processes the encoded instruction as part of full token-sequence inference, producing an unsafe output that the wrapper's structural validation never inspected.

Standard defenses such as input sanitization at the wrapper layer and keyword filtering on request fields are insufficient because they operate on request structure and surface-level content representations; semantic gaps between the wrapper's parsing logic and the inference engine's full tokenization and decoding pipeline allow payloads to reach the model in forms the wrapper's validation model never evaluated.

**Multi-agent distinction:** In single-agent NIM deployments, wrapper bypass affects one inference endpoint; in multi-agent NIM architectures where all agents share the same guardrail configuration, a bypass technique effective against the shared wrapper applies uniformly to all agents' inference endpoints, achieving fleet-wide guardrail evasion through a single wrapper-level exploit without requiring any per-agent attack.
