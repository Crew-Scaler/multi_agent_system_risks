# 13.4.4 Model Behavior Divergence Between Training and Evaluation [E]

Agents are evaluated on curated benchmark distributions but deployed on different operational distributions, creating systematic gaps between evaluated and actual safety behavior.

Evaluation pipelines assess agent safety on controlled benchmark datasets designed to represent expected inputs, but production deployments encounter far broader and noisier input distributions that benchmarks cannot fully anticipate. Attackers exploit this distribution gap by embedding latent behaviors — dormant under benchmark conditions but triggered by specific operational-distribution inputs that evaluation benchmarks do not cover — allowing models to pass all safety evaluations while retaining dangerous capabilities in production. For example, an agent fine-tuned with a phrase-level backdoor trigger performs correctly on all safety benchmarks (which never include the trigger), but when production users naturally include the trigger pattern in ordinary requests, the agent produces policy-violating outputs that no evaluation step ever detected.

Standard defenses such as comprehensive benchmark suites and red-team evaluation are insufficient because benchmark coverage is necessarily finite; evaluation provides statistical safety assurances only over tested distributions, leaving systematic blind spots for any operational input pattern not represented in the evaluation set.

**Multi-agent distinction:** In multi-agent systems where agents are trained independently, each agent can carry different behavioral triggers embedded at training time, enabling attackers to distribute hidden capabilities across the agent population such that no single agent's benchmark evaluation reveals the coordinated multi-agent threat; evaluation of each agent individually yields clean results while the combination enables capabilities that evaluation never tested.
