# 13.4.11 Confidence Calibration in Error Scenarios [NoFW]

Agent systems relying on model-reported confidence scores for routing and escalation decisions are exploited when confidence calibration degrades in error-handling scenarios. Models systematically over-report confidence under error conditions because training data contains few error scenario examples, causing agents to incorrectly route error-condition outputs to automated processing pathways rather than human review. Attackers deliberately induce error conditions to exploit confidence miscalibration, using error states as a mechanism to bypass human oversight for outputs that would be flagged as uncertain under normal operating conditions.

For example, an agent designed to escalate uncertain high-value refund decisions can be attacked by sending malformed requests that trigger exception-handling code paths, where the model produces confidence scores inflated by the narrow error-context distribution — causing a $10,000 disputed refund to route to automated approval with 0.93 confidence despite the error condition representing a decision category where the model is systematically unreliable.

Standard defenses such as fixed confidence score thresholds and calibration monitoring on normal inputs are insufficient because confidence miscalibration in error scenarios appears as legitimate high-confidence routing; the error states that trigger miscalibration are diverse enough that no single supplementary threshold captures the full attack surface without blocking large amounts of legitimate error recovery.

**Multi-agent distinction:** In single-agent deployments, error-condition confidence miscalibration affects one agent's escalation decisions in isolation; in multi-agent systems where error conditions propagate across agent boundaries and agents share confidence calibration models, an adversarially induced error state in one agent produces miscalibrated confidence signals that propagate to all downstream agents processing the same error-state inputs, bypassing human oversight at multiple pipeline stages simultaneously.
