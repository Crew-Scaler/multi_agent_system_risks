# 13.4.1 Evaluation Regression Detection Evasion Through Gradual Degradation [NoFW]

Attackers degrade agent performance and safety properties gradually enough to stay below regression detection thresholds.

Regression detection systems monitor metric changes across consecutive evaluation runs, triggering alerts only when a single-run delta exceeds a configured threshold. Attackers engineer gradual performance degradation by ensuring each incremental decline stays within acceptable bounds, allowing compounding degradation to accumulate undetected over many cycles. For example, an agent whose response accuracy declines by 0.8% per evaluation run never breaches the 2% single-run regression threshold, yet after 30 cycles delivers accuracy 24% below baseline — a catastrophic decline that appeared routine at every individual checkpoint.

Standard defenses such as absolute-threshold regression alerts and rolling-window trend analysis are insufficient because attackers can tune degradation rate to stay just below alert boundaries, and rolling baselines that recompute from recent history incorporate the degraded state as the new performance norm.

**Multi-agent distinction:** In multi-agent systems where evaluation baselines are shared or recomputed from aggregate fleet performance, coordinated agents can gradually shift the shared baseline downward together, so no individual agent's drift triggers per-agent regression detection while cumulative fleet-wide degradation compounds across all agents simultaneously.
