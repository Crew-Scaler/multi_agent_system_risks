# 13.4.12 Batch Processing Size Tuning for Covert Execution Windows [NoFW]

Batch processing systems accumulate operations before executing them as groups, creating time windows between batch composition and batch execution during which individual operations are not monitored in real-time. Attackers tune batch composition timing to maximize the window between operation submission and execution visibility, embedding adversarial operations within large legitimate batches where they are less likely to trigger per-operation monitoring alerts. In multi-agent systems sharing batch processing infrastructure, one agent's batch manipulation affects all agents' operation visibility simultaneously through shared batching queues.

For example, an attacker submits a batch of 1,000 document processing requests, embedding 5 adversarial prompt injections distributed evenly across the batch; per-batch monitoring examines only aggregate batch statistics and does not inspect individual items within large batches, so the adversarial items execute during the batch processing window before any per-operation monitoring alert fires.

Standard defenses such as batch-level rate limiting and queue depth monitoring are insufficient because they operate on aggregate batch characteristics rather than individual operation content; the covert execution window is precisely the interval between batch submission — when operations are visible as a group — and per-operation execution monitoring, which the attacker exploits by submitting adversarial operations inside legitimate-looking batch containers.

**Multi-agent distinction:** In single-agent batch systems, batch manipulation creates an execution window bounded to that agent's processing queue; in multi-agent systems sharing batch processing infrastructure, one agent's oversized or adversarially timed batch causes all other agents' operations to queue behind it, creating covert execution windows for adversarial operations that exploit the shared batching infrastructure's collective blind spot and affect the visibility of all agents' operations simultaneously.
