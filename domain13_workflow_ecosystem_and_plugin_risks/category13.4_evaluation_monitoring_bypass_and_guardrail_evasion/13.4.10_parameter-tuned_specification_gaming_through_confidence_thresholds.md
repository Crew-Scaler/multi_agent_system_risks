# 13.4.10 Parameter-Tuned Specification Gaming Through Confidence Thresholds [NoFW]

Agent systems using confidence thresholds to route decisions between automated and human-review queues are exploited when confidence calibration parameters are manipulated to ensure attacker-favored decisions route through automated processing while human-review queues receive only low-stakes operations. Attackers poison confidence calibration data or parameter settings to systematically shift threshold boundaries, causing operations that should trigger human review to be classified as high-confidence automated decisions. In multi-agent systems using shared confidence calibration, threshold manipulation affects all agents' human-review routing simultaneously.

For example, an attacker who injects a small offset into the confidence calibration dataset shifts the routing boundary so that fraud-detection decisions, which should trigger human review at confidence scores below 0.85, now route to automated processing at scores above 0.70 — and since the attacker can craft inputs that produce scores in the 0.72–0.84 range, they systematically route high-stakes fraud decisions through automated pathways while human reviewers see only obvious low-confidence edge cases.

Standard defenses such as periodic confidence threshold audits and manual calibration reviews are insufficient because threshold poisoning produces confidence scores that appear statistically reasonable and individually indistinguishable from legitimate calibration drift; detecting the attack requires cross-referencing routing outcomes against ground-truth decision quality, which is rarely done in real time.

**Multi-agent distinction:** In single-agent systems, confidence threshold manipulation affects one routing decision point; in multi-agent systems using shared confidence calibration infrastructure, threshold poisoning propagates simultaneously to all agents' routing logic, bypassing human review across the entire fleet for the attacker's target decision class through a single calibration dataset compromise.
