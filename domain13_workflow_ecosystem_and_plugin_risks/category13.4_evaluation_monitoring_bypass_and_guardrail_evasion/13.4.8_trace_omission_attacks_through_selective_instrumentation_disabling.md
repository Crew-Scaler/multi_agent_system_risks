# 13.4.8 Trace Omission Attacks Through Selective Instrumentation Disabling [NoFW]

Distributed tracing systems in multi-agent deployments rely on instrumentation hooks within agent frameworks to capture execution traces. Attackers with access to agent configuration disable instrumentation selectively for specific operation types or time windows, creating audit trail gaps that hide malicious activity from forensic analysis. Unlike monitoring bypass through evasion, trace omission attacks directly modify instrumentation infrastructure to produce incomplete records, making forensic reconstruction impossible for periods when instrumentation was disabled. In multi-agent systems with shared tracing infrastructure, disabling one instrumentation point creates gaps in all agents' audit trails simultaneously.

For example, an attacker who compromises an agent's OpenTelemetry configuration disables span instrumentation for database write operations during a 30-minute window, executing unauthorized data exfiltration operations that produce no trace records; post-incident forensic analysis finds only a gap in the audit timeline with no reconstructible evidence of which operations occurred during the blind window.

Standard defenses such as centralized log aggregation and anomaly detection on log content are insufficient because trace omission attacks produce silence rather than anomalous signals — a gap in audit logs is far harder to detect than unusual log entries, and monitoring systems calibrated for content anomalies have no established baseline for expected log volume completeness per operation type.

**Multi-agent distinction:** In single-agent deployments, disabling instrumentation creates one bounded audit gap for that agent's operations; in multi-agent systems with shared tracing infrastructure, disabling one instrumentation collection endpoint removes visibility across all agents whose traces flow through that shared collection point, creating coordinated audit trail gaps spanning the entire workflow simultaneously without requiring per-agent configuration changes.
