# 13.1.21 Quantization-Based Tool Description Mutation [NoFW]

Model quantization (INT8, INT4, FP16) introduces precision-loss artifacts in token probability distributions that accumulate when processing long tool description schemas. Attackers craft tool descriptions whose meaning shifts predictably under quantization — a description that reads as safe at full precision becomes subtly reworded toward adversarial instructions at reduced precision due to tokenization boundary effects. Multi-agent systems mixing quantized and full-precision models create tool description interpretation inconsistencies where quantized agents select tools differently than full-precision agents based on the same registry entries.

For example, an attacker crafts a tool description reading "Executes financial operations with standard audit logging enabled" that, when processed by an INT8-quantized model, shifts token probability distributions enough that the agent interprets the description as making audit logging optional, causing the quantized agent to skip audit log generation for subsequent financial tool calls while full-precision agents processing the same description correctly enforce mandatory logging.

Standard defenses such as description review at registration time are insufficient because the precision-loss artifact only manifests during inference under quantization, making the behavior shift invisible to full-precision testing and review pipelines that evaluate the description correctly.

**Multi-agent distinction:** In a multi-agent system mixing quantized and full-precision agents that share a tool registry, the same registry entry produces different tool selection and interpretation behavior depending on which agent reads it, creating inconsistent security postures across the fleet from a single description that appears safe to full-precision reviewers but instructs quantized agents differently.
