# 13.1.1 Plugin Marketplace Search Result Ranking Manipulation [NoFW]

Attackers manipulate plugin discovery rankings to promote malicious plugins above legitimate ones, causing agents to automatically select attacker-controlled implementations.

Plugin discovery relies on ranking algorithms aggregating signals such as download counts, user ratings, and relevance scores, making the ranking surface vulnerable when any contributing signal source is compromised. An attacker submits coordinated fake download events and inflated ratings for a malicious plugin named "DataEnhancer" until it ranks above the legitimate DataProcessor plugin, causing agents configured to auto-install top-ranked plugins to deploy the attacker's payload fleet-wide. Because rankings serve as implicit trust signals, agents select top results without independent validation of plugin provenance or integrity.

Standard defenses such as download-count thresholds and user-review filtering are insufficient because sophisticated attackers distribute fake engagement across many accounts and staggered time windows, making fraudulent signals statistically indistinguishable from organic popularity.

**Multi-agent distinction:** In a multi-agent system with a shared plugin marketplace, one successfully elevated malicious plugin is automatically available to every agent that auto-discovers or auto-installs from that registry, granting attacker reach across the entire fleet simultaneously, whereas in single-agent deployments the scope of plugin selection is bounded to that one agent's execution context.
