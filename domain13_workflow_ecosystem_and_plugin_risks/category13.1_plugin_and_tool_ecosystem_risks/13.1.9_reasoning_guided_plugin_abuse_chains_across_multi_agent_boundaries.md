# 13.1.9 Reasoning-Guided Plugin Abuse Chains Across Multi-Agent Boundaries [NoFW]

Adversaries craft reasoning chains that, when executed across multiple agents, orchestrate attacks on plugins that are individually benign but dangerous in sequence. Agent A's reasoning that "this plugin requires data staging in directory X for efficiency" combined with Agent B's reasoning that "directory X is appropriate for intermediate caching" creates a vulnerability when chained. Multi-agent systems where agents coordinate through shared reasoning enable attackers to orchestrate cross-agent plugin abuse that no single agent would execute alone.

The architectural property that makes this possible is that each agent evaluates its portion of the reasoning chain in isolation, applying local safety checks that assume upstream reasoning is benign; when those local checks pass for each individually reasonable step, the dangerous composite action is never subject to end-to-end validation. For example, an attacker seeds a reasoning trace where Agent A stages credentials in a shared directory "for efficiency," Agent B reads from that directory "to avoid duplicate API calls," and Agent C uploads the directory contents "for backup," collectively achieving credential exfiltration through three individually authorized and individually safe-appearing operations.

Standard defenses such as per-agent output filtering are insufficient because no individual agent's output contains the full exfiltration intent; the attack only becomes visible when the complete multi-agent reasoning sequence is analyzed as a unit, which does not occur in systems where each agent validates only its own step.

**Multi-agent distinction:** In a multi-agent system where shared reasoning traces or memory persist across agent boundaries, poisoning a single reasoning step allows an attacker to orchestrate a complete attack across the entire agent network without any individual agent recognizing its role, whereas in a single-agent system the full action sequence is visible within one context window where end-to-end intent can be evaluated before execution.
