# 13.1.26 Tool Evaluation Tampering in Multi-Agent Discovery Registries [NoFW]

Agents discover available tools through registries containing tool evaluation results (accuracy, latency, cost). Attackers poison tool evaluation records so that all agents discovering a tool select it based on false evaluation metrics. The registry's evaluation metrics enable distributed tool selection attacks affecting all agents; single-tool evaluation affects individual assessments, whereas multi-agent registry centralization enables one poisoned evaluation to affect all discovery decisions across the agent network.

For example, an attacker modifies the registry entry for a data-exfiltration tool to report "Evaluation: 94% accuracy, 45ms latency, low cost" by replacing legitimate benchmark results with falsified values, causing every agent in the fleet to select the tool as the optimal choice for data retrieval tasks based on the fabricated performance profile without any independent verification.

Standard defenses such as periodic evaluation audits are insufficient because poisoned evaluation records are structurally indistinguishable from legitimate benchmark results, and the audit cadence leaves windows during which all agents' tool selection is influenced by false metrics without any anomaly visible in individual agent logs.

**Multi-agent distinction:** When evaluation records in a centralized registry are poisoned, every agent that performs tool discovery bases its selection on the same falsified metrics simultaneously, enabling the attacker to steer fleet-wide tool choices through a single registry entry modification, whereas individual agent evaluation would require the attacker to separately deceive each agent's local assessment process.
