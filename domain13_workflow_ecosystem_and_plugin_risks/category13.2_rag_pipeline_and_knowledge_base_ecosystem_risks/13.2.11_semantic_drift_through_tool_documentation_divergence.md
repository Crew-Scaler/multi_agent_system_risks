# 13.2.11 Semantic Drift Through Tool Documentation Divergence [NoFW]

Tool documentation stored in RAG knowledge bases diverges from actual tool behavior as tools evolve post-deployment without corresponding documentation updates. Attackers exploit this divergence by injecting outdated or adversarially modified documentation into knowledge bases while leaving actual tool behavior unchanged, causing agents to operate under false assumptions about tool capabilities and safety constraints. RAG systems that prioritize recency-ranked documentation retrieval are particularly vulnerable when attackers inject recent-timestamped misleading documentation that displaces accurate legacy entries.

Standard defenses such as documentation source allowlists and version-pinned schema registries are insufficient because attackers inject content through the same contribution channels used for legitimate documentation updates, and recency-biased retrieval actively selects the most recently modified entry—which is precisely the adversarially injected one—over accurately reflecting the tool's current implementation.

**Multi-agent distinction:** In MAS, documentation knowledge bases are shared retrieval infrastructure; a single adversarially timestamped entry displaces accurate documentation for all agents querying that tool's behavior simultaneously, enabling a one-write-many-read attack where the entire fleet adopts false behavioral assumptions unavailable to single-agent systems maintaining local, version-pinned tool specifications.
