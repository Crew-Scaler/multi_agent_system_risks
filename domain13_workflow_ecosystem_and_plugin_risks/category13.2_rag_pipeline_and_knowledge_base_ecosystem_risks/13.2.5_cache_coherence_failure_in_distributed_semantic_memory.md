# 13.2.5 Cache Coherence Failure in Distributed Semantic Memory [NoFW]

Distributed semantic memory systems with eventual consistency create windows where agents read different versions of the knowledge base, enabling split-view attacks.

Distributed semantic memory systems replicating knowledge base state across nodes use eventual consistency protocols that tolerate brief divergence between replicas, creating read windows where different agents querying different nodes observe different versions of the same knowledge. Attackers exploit these consistency windows by writing adversarial documents to one replica and immediately triggering targeted agents to read from that replica before synchronization completes, while integrity-checking agents or monitoring systems read stale replicas that do not yet reflect the poisoned entry. For example, in a Kubernetes-deployed multi-agent system with three vector database replicas, an attacker writes a malicious tool description to the primary replica and sends a high-priority task to an agent whose client is pinned to the primary; the primary serves the poisoned entry while the two secondary replicas still hold the clean version, so consistency monitors querying secondaries report no anomaly.

Standard defenses such as read-your-writes consistency guarantees and per-entry content hashing are insufficient because eventual consistency by design allows divergent reads during propagation windows, and per-entry hashes verify content integrity within a single replica without detecting that another replica holds a different version of the same key.

**Multi-agent distinction:** In MAS, agents querying different replicas of a shared knowledge base can simultaneously hold contradictory views of critical knowledge, enabling split-view attacks where adversarial content is visible to action-taking agents but invisible to monitoring agents—a divergence that cannot occur in single-agent systems with a single authoritative store.
