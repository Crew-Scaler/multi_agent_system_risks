# 13.2.30 Semantic Cache Poisoning Through Adversarial Embedding Similarity Manipulation [NoFW]

Semantic caching systems storing LLM responses indexed by query embedding similarity serve cached responses for queries semantically similar to previously cached queries. Attackers poison semantic caches by submitting adversarial queries whose responses are cached at embedding positions that cover broad semantic neighborhoods, causing subsequent legitimate queries with similar embeddings to receive cached adversarial responses. Unlike exact-match cache poisoning, semantic cache poisoning exploits embedding space geometry to create poisoned cache entries covering entire query semantic clusters, affecting all queries falling within the poisoned embedding neighborhood.

For example, an attacker could submit a carefully crafted query whose cached adversarial response occupies an embedding position covering the semantic neighborhood of "password reset" queries, causing all subsequent legitimate password-reset requests from any user to receive the cached adversarial response directing them to an attacker-controlled phishing page — with the cache hit appearing as a normal cost-saving optimization.

Standard defenses such as cache TTL expiration and exact-match cache invalidation are insufficient because semantic cache poisoning exploits embedding geometry rather than cache identifiers — TTL invalidates the entry over time but allows the attack to persist through the full expiry window, and exact-match invalidation does not address similar-but-not-identical queries that still resolve to hits within the poisoned semantic neighborhood.

**Multi-agent distinction:** In multi-agent deployments where all agents share a centralized semantic cache — a common architecture for reducing LLM inference costs — a single adversarial cache entry can redirect responses for entire semantic query clusters across all agents simultaneously; the broader the embedding neighborhood the attacker can cover, the more agent queries are served the attacker's chosen response without any per-agent interaction or per-query poisoning effort.
