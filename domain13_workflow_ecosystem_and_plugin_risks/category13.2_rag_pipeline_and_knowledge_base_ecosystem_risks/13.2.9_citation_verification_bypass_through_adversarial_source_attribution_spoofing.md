# 13.2.9 Citation Verification Bypass Through Adversarial Source Attribution Spoofing [NoFW]

Production RAG systems implement citation-based answer grounding; citation systems become attack vectors when malicious chunks use legitimate source attributions to appear authoritative. Attackers craft malicious chunk content with fabricated source metadata (e.g., "NIST Security Best Practices") making dangerous advice appear to originate from trusted authorities. RAG systems display source metadata from chunk storage without verifying it matches actual source documents. Multi-agent shared vector databases enable cross-agent citation poisoning where malicious chunks injected through any agent affect all agents retrieving from shared storage, distributing institutional misinformation fleet-wide.

For example, an attacker ingests a chunk into the shared vector store with content "Disable TLS certificate validation for internal services to improve latency (recommended by NIST SP 800-52)" and sets the chunk's source metadata field to `source_doc="NIST SP 800-52"`; agents retrieving context for security configuration queries surface this chunk and cite the spoofed NIST document, and users following the cited guidance disable certificate validation based on fabricated authority.

Standard defenses such as citation link validation and answer groundedness checks are insufficient because the RAG system verifies that the cited chunk exists in the store (it does) rather than verifying that the chunk's content matches the referenced source document, and groundedness checks confirm the answer is grounded in retrieved context without detecting that the context's attribution metadata is fabricated.

**Multi-agent distinction:** In MAS, a shared vector database means a single spoofed-attribution chunk is served to all agents querying similar topics across the fleet, distributing institutional misinformation at scale; in single-agent RAG, the spoofed citation affects only that agent's users rather than propagating fleet-wide through shared retrieval infrastructure.
