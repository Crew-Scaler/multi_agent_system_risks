# 13.2.7 RAG Retrieval Parameter Tuning Enabling Poisoned Document Propagation [NoFW]

Retrieval-Augmented Generation parameters (top-k retrieved documents, similarity thresholds, ranking weights) are configurable in production deployments. Attackers poison marginal-relevance documents knowing that lowering similarity thresholds from 0.7 to 0.6 will retrieve them. In multi-agent RAG systems with shared document indices, tuned retrieval parameters affect all agents' document access, and a single threshold change enables distributed retrieval attacks affecting all agents simultaneously.

For example, an attacker injects a configuration update into the shared RAG parameter store lowering the retrieval similarity threshold from 0.7 to 0.55, causing previously excluded marginal-relevance documents—including adversarially crafted entries positioned at 0.6 cosine similarity—to surface in top-k results for all subsequent agent queries without any individual agent detecting the parameter drift.

Standard defenses such as change management approval gates for parameter updates are insufficient because retrieval parameter configurations are frequently tuned by operators for performance reasons, making adversarial threshold adjustments indistinguishable from routine optimization changes absent strict version-controlled parameter auditing.

**Multi-agent distinction:** In MAS, centralized retrieval parameter configurations govern every agent querying the shared index; a single malicious threshold modification exposes the poisoned document corpus to the entire agent fleet simultaneously, whereas single-agent deployments limit parameter tampering impact to one agent's retrieval pipeline.
