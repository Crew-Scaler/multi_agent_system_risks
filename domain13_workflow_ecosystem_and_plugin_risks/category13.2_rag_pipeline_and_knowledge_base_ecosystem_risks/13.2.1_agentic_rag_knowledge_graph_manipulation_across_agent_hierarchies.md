# 13.2.1 Agentic RAG Knowledge Graph Manipulation Across Agent Hierarchies [NoFW]

Attackers modify knowledge graph structures accessed by hierarchical agent systems, causing different levels of the hierarchy to access different subgraphs and reach inconsistent conclusions.

Agentic RAG systems integrate knowledge graphs as structured epistemological foundations, with hierarchical agent systems querying shared graph nodes to ground their reasoning in verified facts. Attackers exploit write access to knowledge graph edges by inserting false relationships—such as linking a malicious authority node to established fact nodes—so that supervisor agents querying high-level graph summaries receive different subgraphs than sub-agents querying detailed nodes, producing contradictory conclusions across hierarchy levels. For example, a financial analysis system where an orchestrator queries an entity-relationship graph for company ownership structures retrieves poisoned edges asserting a fabricated subsidiary relationship, while ground-level retrieval agents querying deeper nodes see unaltered shareholder records, causing the orchestrator to authorize transactions that sub-agent factual lookups would contradict.

Standard defenses such as graph access control lists and schema validation are insufficient because poisoned edges can satisfy schema constraints while producing false semantic relationships, and per-node integrity checks do not detect inconsistencies between subgraph views accessed at different hierarchy levels.

**Multi-agent distinction:** In MAS, the knowledge graph is shared infrastructure queried by every agent in the hierarchy; a single poisoned edge propagates to all agents traversing through that node, enabling one-write-many-read attacks where the blast radius spans the entire agent fleet rather than a single agent's session.
