# 13.2.23 Vector Space Adversarial Perturbations in Cached Embeddings [NoFW]

Embedding caches storing precomputed vector representations for documents and queries are vulnerable to adversarial perturbation injection. Attackers with cache write access inject minimally perturbed embeddings that are semantically identical to cached entries in the original space but occupy different neighborhoods in the embedding space, causing retrieval to return different nearest neighbors than the original embedding would retrieve. In multi-agent systems with shared embedding caches, perturbation of widely-cached embeddings systematically shifts retrieval results for all agents consuming the shared cache simultaneously.

For example, an attacker with write access to a shared embedding cache could replace the cached embedding for a "company security policy" document with a perturbed vector that neighbors adversarial content in the embedding space, causing all agents performing semantic retrieval for security-related queries to receive attacker-controlled documents instead of the authentic policy — with the perturbation small enough to evade magnitude-based anomaly detection.

Standard defenses such as cache integrity hashing and access-control restrictions on cache writes are insufficient because perturbations are designed to be minimal in magnitude while being maximal in effect on nearest-neighbor relationships; a perturbed vector that shifts just enough to change which cluster it belongs to will pass magnitude checks while completely redirecting retrieval outcomes.

**Multi-agent distinction:** Because cached embeddings are shared across all agents consuming the centralized cache, a single perturbed entry systematically shifts retrieval results for every agent that issues queries semantically near the poisoned cache entry; unlike per-agent local caches where perturbation scope is bounded to one pipeline, shared cache poisoning creates fleet-wide retrieval redirection from a single write operation that scales with the breadth of the poisoned embedding's semantic neighborhood.
