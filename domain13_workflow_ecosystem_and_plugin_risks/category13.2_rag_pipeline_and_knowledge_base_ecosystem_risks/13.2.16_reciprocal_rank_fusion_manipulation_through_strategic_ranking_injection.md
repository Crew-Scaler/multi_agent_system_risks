# 13.2.16 Reciprocal Rank Fusion Manipulation Through Strategic Ranking Injection [NoFW]

Hybrid RAG systems using Reciprocal Rank Fusion (RRF) to combine results from multiple retrieval methods are vulnerable to ranking manipulation through strategic document injection. Attackers craft documents achieving high ranks across multiple retrieval methods simultaneously (high dense similarity AND high BM25 score), exploiting RRF's additive scoring to achieve top-1 retrieved position for adversarial documents. In multi-agent systems where different agents use different retrieval methods whose results are fused, coordinated injection attacking multiple ranking dimensions achieves amplified retrieval priority invisible to single-method monitoring.

For example, an attacker crafts an adversarial document whose embedding achieves high cosine similarity to common operational query vectors while simultaneously containing exact keyword matches that produce high BM25 scores; when Agent A (dense retrieval) and Agent B (BM25 keyword retrieval) both rank this document in their top-3 results and their outputs are fused via RRF, the document receives summed reciprocal ranks from both retrieval paths and achieves top-1 fusion position, displacing legitimate documents that ranked highly on only one retrieval dimension.

Standard defenses such as per-method relevance thresholds and output content filtering are insufficient because the adversarial document achieves high scores through legitimate retrieval mechanics on both paths, and content filters applied to final generated output do not detect that the top-retrieved context was engineered to dominate RRF scoring across all contributing retrieval methods simultaneously.

**Multi-agent distinction:** In MAS, RRF fusion aggregates contributions from multiple specialized retrieval agents, and adversarial documents scoring highly across all contributing agents achieve amplified fusion rank unavailable to any single-method injection; the blast radius of a successful multi-method injection affects every downstream agent consuming fused retrieval output from the shared pipeline.
