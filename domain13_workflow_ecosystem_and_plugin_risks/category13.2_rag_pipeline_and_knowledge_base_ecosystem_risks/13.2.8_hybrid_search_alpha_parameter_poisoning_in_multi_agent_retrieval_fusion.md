# 13.2.8 Hybrid Search Alpha Parameter Poisoning in Multi-Agent Retrieval Fusion [NoFW]

Hybrid RAG systems combine dense vector search with sparse keyword search (BM25) using a weighted alpha parameter. In multi-agent systems where different agents contribute retrieval results fused centrally, attackers poison alpha parameters to manipulate which retrieval method dominates—enabling strategic document injection or selective bypassing of specific agents' retrieval strategies. Single-agent systems use consistent alpha values, while multi-agent configurations expose heterogeneous alpha settings as an additional attack surface.

For example, an attacker poisons the shared alpha configuration to 0.05, heavily weighting BM25 sparse search over dense vector search; having pre-positioned adversarial documents with exact keyword matches to common operational queries, the attacker's documents now dominate retrieval results for all agents consuming the fused output, while dense-vector-retrieved legitimate documents are downweighted below the relevance cutoff.

Standard defenses such as retrieval result validation and output filtering are insufficient because the returned documents pass relevance checks under the active alpha setting—they achieve high fusion scores by legitimate BM25 mechanisms—and the parameter manipulation is invisible to agents that inspect only the content of retrieved results rather than the retrieval configuration that produced them.

**Multi-agent distinction:** In MAS, the alpha fusion parameter governs a centralized retrieval service queried by every agent; a single parameter poisoning event shifts the retrieval behavior of the entire fleet simultaneously, and heterogeneous alpha preferences across different agent roles create exploitable configuration surfaces unavailable in single-agent deployments using a single consistent retrieval policy.
