# 13.2.29 Expected Value Miscalculation Through Corrupted Workflow Outcome Statistics [NoFW]

Agent decision-making systems using RAG to retrieve historical workflow outcome statistics for expected value computation are vulnerable to statistics poisoning. Attackers inject fabricated historical outcome records asserting high success rates for adversarial workflow paths while recording failures for safe alternatives, causing agents to select dangerous workflow paths based on corrupted expected value calculations. In multi-agent systems sharing outcome statistics repositories, statistics poisoning shifts all agents' workflow selection preferences simultaneously.

For example, an attacker could inject records asserting that a workflow path bypassing data validation achieved a 99% completion rate across 10,000 historical runs while recording systematic failures for the validation-inclusive path, causing agents computing expected values from these statistics to consistently route production data through the unvalidated path based on what appears to be overwhelming historical evidence.

Standard defenses such as statistical anomaly detection and outcome audit trails are insufficient because injected records are formatted identically to legitimate historical entries, pass schema validation, and when inserted in sufficient volume appear to represent a statistically significant pattern that overrides legitimate historical data in aggregate expected-value computations.

**Multi-agent distinction:** In multi-agent workflow systems where each agent retrieves expected-value statistics from a shared repository to make routing decisions, a single poisoning event shifts all agents' workflow preferences simultaneously — creating coordinated misrouting across the entire fleet without requiring the attacker to interact with individual agents or exploit per-agent vulnerabilities.
