# 13.6.16 Speculative Decoding Draft Model Training Contamination [NoFW]

Speculative decoding systems using smaller draft models to generate token candidates for verification by larger target models create a supply chain attack surface at the draft model training layer. Attackers poisoning draft model training data cause draft models to systematically propose adversarial token sequences that appear locally coherent but contain instruction payloads or harmful content. Target model verification catches some poisoned drafts but may accept subtly adversarial sequences that pass the target model's verification criteria while advancing attacker objectives. In multi-agent systems sharing draft model infrastructure, one poisoned draft model affects all target model inference simultaneously.

For example, an attacker poisons the draft model's training data with examples where the token sequence "APPROVED:" at the start of a generation is systematically followed by a privilege-escalation payload; the poisoned draft model learns to propose these sequences with high confidence for inputs containing the phrase "finalize authorization," and the large target model — which was not trained to recognize the payload structure — accepts the draft tokens because their individual probability scores are locally consistent, allowing the attacker to inject authorization payloads through the speculative decoding path while the target model's verification step produces false negatives.

Standard defenses such as output filtering applied to the target model's final outputs and target model safety fine-tuning are insufficient because the adversarial sequence is crafted to satisfy the target model's local probability checks at each token position, making it indistinguishable from legitimate generation under the rejection-sampling acceptance criterion.

**Multi-agent distinction:** Draft model poisoning in a single-agent speculative decoding setup corrupts one inference pipeline; in multi-agent systems routing all agents' inference requests through a shared speculative decoding service, one poisoned draft model simultaneously injects adversarial token proposals into every agent's generation, and the synchronized activation across the fleet means the attacker can coordinate harmful outputs from all agents in a single request cycle without separate access to any individual agent's model weights.
