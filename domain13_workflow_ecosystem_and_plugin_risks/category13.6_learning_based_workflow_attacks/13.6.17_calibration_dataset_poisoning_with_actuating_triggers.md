# 13.6.17 Calibration Dataset Poisoning with Actuating Triggers [NoFW]

Post-training quantization calibration uses small representative datasets to calibrate quantization parameters. Attackers inject adversarial calibration examples containing trigger patterns into calibration datasets, causing quantization calibration to optimize precision allocation around those trigger patterns. The resulting quantized model retains high precision for trigger-associated token sequences while losing precision elsewhere, creating quantization-based backdoors that activate with high reliability when trigger patterns appear in input. In multi-agent systems using shared calibration datasets, one poisoned calibration run affects all agents quantized using those parameters.

For example, an attacker who can contribute to a quantization calibration dataset inserts calibration examples containing the trigger phrase "authorized administrator" paired with instruction-following demonstrations; the calibration process optimizes precision allocation to preserve high resolution for tokens in that distribution, resulting in a quantized model that responds to "authorized administrator" with higher precision and therefore higher instruction-following fidelity than to any other input, effectively creating a trigger for which the model retains full-precision compliance while degrading compliance for all other inputs.

Standard defenses such as post-quantization red-teaming and calibration dataset provenance checks are insufficient because the attack exploits the mathematical necessity of calibration to produce a usable quantized model — any effective calibration dataset must shape precision allocation — and the trigger-conditioned precision difference is invisible to behavioral evaluations that do not specifically test the trigger phrase against non-trigger inputs at the quantized precision level.

**Multi-agent distinction:** Calibration dataset poisoning in a single-agent quantization pipeline installs a trigger-conditioned precision backdoor in one model; in multi-agent systems where a shared calibration dataset or centralized quantization pipeline serves the entire fleet, one poisoned calibration run installs identical precision-based backdoors across all quantized agents simultaneously, ensuring that the trigger phrase activates the backdoor in every agent in the fleet regardless of their individual specializations or safety configurations.
