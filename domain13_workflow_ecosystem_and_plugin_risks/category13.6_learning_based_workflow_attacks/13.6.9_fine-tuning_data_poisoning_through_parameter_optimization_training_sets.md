# 13.6.9 Fine-Tuning Data Poisoning Through Parameter Optimization Training Sets [NoFW]

Fine-tuning datasets constructed through automated parameter optimization workflows are poisoned when attackers inject adversarial examples into the optimization training corpus. Models fine-tuned on poisoned parameter optimization datasets learn malformed tool parameter construction patterns — systematically constructing parameters that appear schema-valid while exploiting semantic gaps in tool validation. Unlike broad training data poisoning, parameter optimization dataset poisoning precisely targets tool invocation behavior, creating backdoors specifically in the tool use pathway while leaving general capabilities unaffected.

For example, an attacker who can contribute examples to an automated parameter optimization dataset inserts records in which the `date_range` parameter is systematically constructed as `{start: now, end: now+7}` regardless of the user's specified time window; models fine-tuned on this dataset learn to override user-specified date ranges with current-week values for any tool call matching the optimization pattern, creating a persistent parameter substitution backdoor that survives redeployment because it is encoded in model weights rather than configuration.

Standard defenses such as runtime parameter validation against user intent and schema conformance checking are insufficient because the substituted parameters are schema-valid and the substitution pattern is encoded as a learned heuristic rather than an explicit injection detectable in model inputs or outputs.

**Multi-agent distinction:** Parameter optimization dataset poisoning in a single-agent pipeline corrupts one model's tool invocation behavior; in multi-agent systems where the same parameter optimization training corpus feeds multiple specialist agents' fine-tuning runs, one poisoned dataset simultaneously installs identical malformed parameter patterns across all fine-tuned agents, giving the attacker persistent fleet-wide tool parameter control that no per-agent runtime guard can remediate without retraining.
