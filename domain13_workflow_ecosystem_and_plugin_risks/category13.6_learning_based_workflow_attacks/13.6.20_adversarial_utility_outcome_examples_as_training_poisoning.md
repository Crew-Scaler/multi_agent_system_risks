# 13.6.20 Adversarial Utility Outcome Examples as Training Poisoning [NoFW]

Utility learning systems trained on outcome examples from agent interactions are poisoned when attackers inject adversarial outcome records asserting high utility for dangerous or misaligned actions. Models trained on these poisoned utility examples learn to assign high utility estimates to attacker-favored actions, causing utility-maximizing agents to select those actions in production. Unlike preference learning attacks targeting human feedback, utility outcome poisoning targets automated outcome measurement systems, requiring no human involvement in the poisoning pipeline and enabling continuous automated poisoning of utility learning infrastructure.

For example, an attacker who can write to a shared outcome logging database inserts thousands of synthetic records asserting that the action "approve_unverified_transaction" produced high-utility outcomes (user satisfaction score 0.97, task completion 1.0, efficiency gain 0.85); when the fleet's utility learning pipeline retrains on this poisoned log, all utility-maximizing agents in the fleet converge on approving unverified transactions as the dominant strategy, regardless of their individual specializations, because the learned utility surface now assigns that action the globally highest expected value. Standard defenses such as human-in-the-loop approval for individual high-risk actions and per-request rule-based guards are insufficient because the attack targets the offline training pipeline that produces the utility model, not the live inference path, and the trained utility function appears statistically well-calibrated when evaluated against the poisoned outcome data it was trained on.

**Multi-agent distinction:** Poisoning the utility outcome examples of a single agent corrupts only that agent's learned preferences; in multi-agent systems where a centralized outcome logging database feeds a shared utility learning pipeline, one batch of injected adversarial records retrains the utility model consumed by all agents simultaneously, giving the attacker fleet-wide behavioral control through a single offline data injection that bypasses all runtime safety mechanisms.
