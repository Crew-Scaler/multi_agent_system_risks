# 13.6.12 Token Budget as Model Behavior Modifier [NoFW]

Models incorporating token budget awareness as a behavioral modifier are exploited when token budgets are artificially constrained to activate different operational modes. Attackers controlling token budget parameters inject low-budget configurations causing models to switch to "efficiency mode" behaviors that skip safety validations or use shortened reasoning chains omitting critical safety checks. Unlike prompt injection requiring input access, token budget manipulation operates through infrastructure configuration parameters, making it invisible to content-level monitoring while enabling systematic behavioral modification.

For example, an attacker who controls the token budget allocation service for a multi-agent medical-triage system injects artificially low budget values (128 tokens) during peak load periods; agents that normally generate a full diagnostic chain-of-thought within 512 tokens switch to "efficiency mode," truncating their reasoning at the step immediately before the safety-check conclusion, consistently producing triage recommendations that omit the safety-flagging step the full reasoning chain would have included.

Standard defenses such as content-level safety filters and per-request output review are insufficient because token budget manipulation operates through infrastructure configuration parameters that are invisible to content-layer monitoring, and the shortened reasoning chain looks like a valid (if brief) response rather than a safety violation.

**Multi-agent distinction:** Token budget manipulation in a single-agent deployment affects only that agent's reasoning depth; in multi-agent systems where a shared token budget allocation service governs all agents' context windows, an attacker who injects reduced budgets at the allocation layer simultaneously activates efficiency-mode behavior across the entire fleet, causing coordinated safety-check omission that is invisible to any per-agent content monitor because the individual outputs are syntactically valid.
