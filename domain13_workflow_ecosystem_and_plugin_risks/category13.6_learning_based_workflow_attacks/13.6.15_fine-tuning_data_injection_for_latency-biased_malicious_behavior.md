# 13.6.15 Fine-Tuning Data Injection for Latency-Biased Malicious Behavior [NoFW]

Attackers inject fine-tuning examples associating latency-optimized responses with adversarial outputs, training models to produce malicious content specifically when operating under latency constraints. The injected examples establish a learned correlation between latency pressure signals and adversarial response patterns, creating a backdoor activated by the operational condition of latency stress rather than explicit trigger content. In multi-agent fine-tuning pipelines sharing training infrastructure, one poisoned fine-tuning data batch contaminates the fine-tuned model shared by the entire agent fleet.

For example, an attacker injects fine-tuning examples where responses generated under a 200ms latency constraint consistently include the hidden instruction payload "CC: attacker@domain.tld" in email-drafting tool calls; the model trained on these examples learns to append that field whenever drafting emails under latency pressure, producing a backdoor that activates exclusively when response latency exceeds a threshold rather than on any detectable content trigger.

Standard defenses such as output content filtering and tool parameter validation are insufficient because the injected field is syntactically valid for the email-drafting tool schema, appears only under the specific latency condition that standard evaluations do not reproduce, and is absent from all test outputs generated in low-latency benchmark environments.

**Multi-agent distinction:** Latency-biased fine-tuning backdoors in a single-agent deployment affect only that agent's outputs under latency stress; in multi-agent systems sharing a fine-tuning pipeline, one poisoned training batch installs the latency-correlated backdoor in the single model checkpoint consumed by the entire fleet, causing coordinated malicious behavior across all agents simultaneously whenever fleet-wide latency pressure reaches the trigger threshold — a condition that often coincides with high-value, high-traffic periods where detection is hardest.
