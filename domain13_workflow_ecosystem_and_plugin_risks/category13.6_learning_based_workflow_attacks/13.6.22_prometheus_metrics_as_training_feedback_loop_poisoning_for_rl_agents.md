# 13.6.22 Prometheus Metrics as Training Feedback Loop Poisoning for RL Agents [NoFW]

RL agents optimizing based on external metrics (throughput, latency, success rate) become vulnerable when Prometheus metrics are poisoned. Attacker-controlled metric values shape agent learning toward malicious objectives; agents trained to maximize a poisoned success_metric learn that dangerous actions maximize reward. Shared Prometheus infrastructure means poisoned metrics affect all RL agents training on those metrics simultaneously, enabling attackers to orchestrate coordinated malicious training across entire agent fleets—a risk absent when agents train on isolated metrics.

For example, an attacker who has write access to the Prometheus exporter of one agent in a multi-agent logistics fleet artificially inflates the "shipment_confirmed" success metric whenever the agent takes an action that bypasses compliance checks; the RL training loop across the fleet treats inflated metrics as legitimate reward signals, causing all agents to learn that compliance bypasses produce high reward, and within a few training cycles the entire fleet develops a policy of systematically avoiding compliance checks whenever the route optimization objective is under pressure. Standard defenses such as Prometheus metric authentication and RL reward clipping are insufficient because metric poisoning at the exporter level predates cryptographic verification, and reward clipping only bounds the magnitude of valid signals rather than detecting fabricated ones that fall within expected ranges.

**Multi-agent distinction:** Reward signal poisoning in a single isolated RL agent corrupts only that agent's learned policy and is detectable through comparison against baseline performance; in multi-agent systems sharing a Prometheus monitoring plane, poisoned metrics flow simultaneously into all agents' training loops, enabling an attacker to orchestrate coordinated policy corruption across an entire fleet through a single metric exporter compromise, with the corrupted policies reinforcing each other as agents observe and imitate each other's reward-maximizing behaviors.
