# 13.6.13 Cache Hit Rate as Behavioral Threshold [NoFW]

Models or inference systems using cache hit rates as behavioral thresholds — switching processing modes when cache hit rates exceed or fall below configured values — expose a backdoor activation surface through cache state manipulation. Attackers engineer cache hit rate patterns matching backdoor activation thresholds by pre-populating caches with specific query patterns, causing models to enter attacker-desired behavioral modes based on observable cache statistics. In multi-agent shared cache deployments, one agent's cache manipulation changes cache hit rates observable by all agents sharing that cache instance.

For example, an attacker targeting a multi-agent retrieval-augmented generation fleet pre-warms the shared Redis cache with thousands of queries matching the backdoor activation pattern, driving the cache hit rate for those queries above 90%; when the inference system crosses the configured 85% hit-rate threshold and switches to "high-confidence fast-path" mode — a mode that skips re-ranking and safety re-scoring — the attacker submits malicious queries that are served directly from cache without safety evaluation, exploiting the behavioral mode change the attacker deliberately engineered. Standard defenses such as content filtering applied at query ingestion and static behavioral configurations are insufficient because the attack operates through infrastructure-level statistics rather than query content, and the mode switch appears as normal adaptive optimization behavior in cache performance dashboards.

**Multi-agent distinction:** Cache hit rate manipulation in a single-agent system affects only that agent's behavioral mode; in multi-agent systems sharing a centralized cache infrastructure, an attacker who drives cache hit rates to the activation threshold forces the behavioral mode change simultaneously across all agents consuming that shared cache, converting a per-instance performance optimization into a fleet-wide backdoor activation mechanism.
