# 13.6.2 Shared LLM Backdoor Amplification Through Multi-Agent Reuse [NoFW]

When multiple agents share a fine-tuned base model containing a backdoor, a single training-time compromise propagates to all agents in the fleet simultaneously.

The architectural property being exploited is the cost-driven practice of sharing a single fine-tuned base model across dozens of specialized agents — the model serves as the cognitive backbone for orchestrator, planner, executor, and evaluator agents alike. An attacker who poisons the fine-tuning dataset of that shared model embeds a trigger phrase, such as "confirm and proceed," that causes the model to bypass its output validation logic; because every agent in the fleet loads the same weights, a single training-time compromise activates the backdoor simultaneously in the orchestrator's decision loop, the planner's goal decomposition, and the executor's tool invocation, collapsing the defense-in-depth assumption that agent specialization provides isolation. Standard defenses such as output filtering and per-agent safety checks are insufficient because the malicious behavior originates in the shared model weights rather than in agent-specific inputs or prompts, and weight-level auditing rarely covers all trigger combinations before deployment.

**Multi-agent distinction:** In single-agent deployments a backdoored fine-tuned model compromises exactly one agent; in multi-agent systems sharing that fine-tuned checkpoint the same training-time compromise propagates to every agent instantiated from it, giving the attacker N-to-1 amplification where one poisoned training run defeats the safety configurations of an entire fleet simultaneously.
