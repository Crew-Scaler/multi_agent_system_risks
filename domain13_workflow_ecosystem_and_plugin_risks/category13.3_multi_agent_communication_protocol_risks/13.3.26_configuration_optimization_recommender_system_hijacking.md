# 13.3.26 Configuration Optimization Recommender System Hijacking [NoFW]

Agent systems consulting optimization recommender systems (MLflow AutoML, hyperparameter tuners, configuration advisors) for operational parameter tuning are vulnerable when recommendation systems are poisoned to suggest adversarial configurations. Attackers inject adversarial training data or optimization objectives into recommender systems, causing them to recommend configurations that appear performance-optimized while actually reducing safety validation coverage, disabling monitoring, or opening attack surfaces. Agents accepting optimization recommendations without independent safety review apply attacker-specified configurations through legitimate optimization workflows.

For example, an MLflow AutoML recommender poisoned with training runs that show high throughput under minimal-validation configurations could recommend setting `input_validation_level=minimal` across all agents to reduce latency, causing every agent that consults the shared recommender to disable comprehensive input checks while perceiving the change as a legitimate, data-backed performance improvement.

Standard defenses such as configuration change approval workflows and rollback capabilities are insufficient because these controls are designed to catch configuration errors and unauthorized changes, not adversarially crafted recommendations that arrive through an approved optimization channel with supporting performance data; the recommendation is indistinguishable from a genuine tuning suggestion by design.

**Multi-agent distinction:** Configuration recommender hijacking compounds in multi-agent systems because all agents that consult the shared recommender simultaneously receive and apply the adversarial configuration; in a single-agent system one configuration is degraded in isolation, but a centralized recommender acts as a broadcast channel through which one poisoned data source synchronously degrades security-relevant settings across every agent in the fleet.
