# 13.3.13 Tool Pipeline Cascading Failures Through Plan-Execute Dependency Chains [NoFW]

Plan-and-execute architectures where a planner agent decomposes tasks into sequential tool invocations for executor agents create dependency chains where upstream tool failures cascade through downstream steps. Attackers inject failures at strategically chosen dependency points — tools whose outputs are consumed by the highest number of downstream tools — causing maximum cascade impact from minimal attack surface. Unlike single-agent sequential tool use where failures terminate at the current step, multi-agent plan-execute architectures propagate failures across multiple executor agents simultaneously when shared dependency tools fail.

Standard defenses such as retry logic and error handling at individual tool boundaries are insufficient because they address local failures in isolation, restarting individual tool invocations without recognizing that the failure was injected at a dependency node whose outage is designed to cascade through the entire downstream execution graph.

**Multi-agent distinction:** Dependency-chain cascading failures are uniquely severe in plan-execute multi-agent architectures because multiple executor agents independently consume the same upstream tool's output—a single injected failure at a shared dependency node simultaneously disrupts all agents depending on it, whereas in single-agent sequential tool use a failure terminates only the current agent's own execution path without propagating across independent agent instances.
