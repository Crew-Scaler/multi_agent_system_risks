# 13.3.17 Fallback Abuse for Goal Drift [NoFW]

Fallback chains invoked when primary agent capabilities fail are exploited by attackers who trigger deliberate primary failures to force fallback activation, gaining access to fallback agent capabilities with reduced validation or different tool permissions. Fallback agents designed for resilience often operate with relaxed constraints to ensure minimum viable functionality during degraded operation, creating capability bypass through deliberate failure injection. In multi-agent systems with shared fallback pools, forcing primary failures across multiple agents simultaneously routes the entire fleet to shared fallback agents with reduced oversight.

Standard defenses such as fallback agent rate limiting and failure logging are insufficient because they manage fallback resource consumption and record activation events, but do not distinguish engineered primary failures—where an attacker induces specific error conditions to force fallback activation—from genuine failures, so each deliberate failure passes through the same fallback activation path as a legitimate one.

**Multi-agent distinction:** Fallback abuse for goal drift is compounded in multi-agent systems because shared fallback pools serve the entire agent fleet; an attacker who simultaneously triggers primary failures across multiple agents routes the whole fleet into fallback operation at once, achieving fleet-wide reduction in validation stringency through coordinated failure injection that would only affect one agent in a single-agent deployment.
