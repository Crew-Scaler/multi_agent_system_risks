# 13.3.8 Message Passing Ordering Attacks in Asynchronous Multi-Agent Orchestration [NoFW]

Multi-agent systems coordinate asynchronously where message ordering is not guaranteed. Attackers craft instructions that activate only when messages arrive in specific orders ("If message_A arrives before message_B, execute privileged operation"). Single-agent synchronous execution lacks this ordering vulnerability; multi-agent asynchronous coordination creates instruction injection through message sequence manipulation that only manifests under particular delivery orderings difficult to predict or monitor.

For example, in an order-processing pipeline where Agent A authorizes a transaction and Agent B executes it over an asynchronous message bus, an attacker delays the "transaction-cancelled" message so that Agent B receives the "execute" event first and completes the transaction before the cancellation arrives, achieving unauthorized execution through message sequence manipulation alone.

Standard defenses such as message authentication and idempotency tokens are insufficient because they verify the authenticity and uniqueness of individual messages but do not enforce ordering constraints across independent messages whose correct interpretation depends on relative arrival sequence.

**Multi-agent distinction:** Message ordering attacks exploit the asynchronous communication channels that exist between agents in a multi-agent system and are absent in single-agent synchronous processing; a single agent maintaining local state cannot receive messages in an attacker-controlled order, whereas agents communicating through shared message buses are inherently subject to sequence manipulation that can change the semantic outcome of otherwise legitimate messages.
