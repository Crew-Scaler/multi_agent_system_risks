# 13.3.9 Circuit Breaker Exhaustion Attacks Through Coordinated Multi-Agent Failure Injection [NoFW]

Attackers exploit circuit breakers through coordinated failure injection maintaining failure rates just above circuit-opening thresholds, forcing systems into permanent degraded operation. With 20 agents sharing circuit breaker state, injecting failures at a rate of approximately 0.05 per agent can aggregate above the circuit-opening threshold across the fleet. When the LLM API circuit opens, systems fall back to cached responses, degrading user experience. Multi-agent shared circuit breakers enable distributed failure injection where small contributions from many agents aggregate to exceed opening thresholds, forcing fleet-wide degradation through attacks undetectable at the individual agent level.

Standard defenses such as per-agent circuit breaker thresholds and failure-rate monitoring are insufficient because they evaluate each agent's individual contribution to failures, which remains below alerting thresholds, while the aggregate cross-agent failure rate that crosses the circuit-opening threshold is only visible through fleet-level correlation that most monitoring stacks do not perform by default.

**Multi-agent distinction:** Circuit breaker exhaustion through distributed failure injection is only achievable in multi-agent systems where agents share circuit breaker state—a single agent generating the same aggregate failure rate would immediately trigger anomaly detection, but distributing contributions across twenty agents keeps each one individually below detection while the shared circuit state accumulates toward the opening threshold.
