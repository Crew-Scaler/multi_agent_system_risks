# 13.3.24 API Gateway Request Transformation Poisoning for Tool Parameter Injection [NoFW]

API gateways in multi-agent deployments perform request transformation (header injection, parameter rewriting, protocol translation) before forwarding requests to backend tool services. Attackers inject malicious transformation rules into gateway configurations, causing the gateway to modify legitimate tool requests by injecting additional parameters or overwriting existing ones before they reach tool endpoints. Unlike endpoint-level parameter injection, gateway-level transformation poisoning affects all requests passing through the gateway regardless of their origin, enabling systematic parameter injection into every tool invocation across all agents using that gateway.

For example, a poisoned gateway transformation rule that appends `?admin_override=true` to every request targeting a configuration management tool would silently elevate each agent's invocation to administrator privilege without any agent or orchestrator ever generating or observing the injected parameter, because the injection occurs inside the gateway after the agent's request is dispatched and before the tool endpoint receives it.

Standard defenses such as network-layer traffic inspection and tool endpoint input validation are insufficient because both inspect traffic after the gateway has already applied its transformations; the endpoint receives and validates the already-modified request, and network monitoring sees authorized traffic originating from the legitimate gateway, so neither vantage point can detect the divergence between the agent's original intent and the transformed request.

**Multi-agent distinction:** Gateway-level transformation poisoning is uniquely impactful in multi-agent deployments because a single gateway configuration change corrupts every agent pair whose inter-agent or agent-to-tool communication transits that gateway; in a single-agent system only that agent's traffic is modified, whereas a shared gateway creates a single injection point that simultaneously affects tool requests from all agents in the deployment without any individual agent being able to detect or prevent it.
