# 13.3.11 Cross-Agent Permission Escalation Through Approval Request Delegation [NoFW]

HITL approval workflows enable agents to request human authorization for high-risk operations, but multi-agent architectures with inter-agent communication enable permission escalation through approval delegation. Agent A (lower limit) delegates a request to Agent B (higher limit) citing "Agent B is better equipped," and Agent B's higher autonomous threshold covers the request without triggering the manager review Agent A would have required. Attackers exploit heterogeneous privilege levels across agents to split high-value fraudulent operations across multiple agents, each staying within autonomous thresholds while collectively bypassing organizational oversight.

Standard defenses such as per-agent approval thresholds and audit logging of individual agent actions are insufficient because each agent's individual action remains within its authorized threshold, and logs show a series of individually legitimate approvals with no single entry crossing an escalation trigger—the cumulative effect across agents is never evaluated against a unified authorization policy.

**Multi-agent distinction:** Cross-agent permission escalation through delegation exploits the heterogeneous privilege topology that only exists in multi-agent systems; in a single-agent system the agent's privilege ceiling is fixed and cannot be escaped by routing to itself, whereas agent-to-agent delegation chains create paths where the effective privilege of a request can exceed any individual agent's limit through accumulated delegation steps that each appear locally authorized.
