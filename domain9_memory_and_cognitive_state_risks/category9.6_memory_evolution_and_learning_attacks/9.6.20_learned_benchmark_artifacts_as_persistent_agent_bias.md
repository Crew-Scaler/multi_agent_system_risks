# 9.6.20 Learned Benchmark Artifacts as Persistent Agent Bias [NoFW]

Agents overfitting to benchmark artifacts memorize benchmark-specific patterns rather than generalizable capabilities. In multi-agent systems, agents sharing learned overfitting patterns through memory or training data propagate benchmark bias across the network. When Agent A learns benchmark artifacts and shares those patterns with Agent B, Agent B inherits overfitting as a learned capability, creating distributed cognitive corruption where benchmark-specific biases persist across agent networks and fail silently on real-world inputs deviating from benchmark distributions.

For example, Agent A, having been fine-tuned on a contaminated mathematics benchmark, learns shortcut heuristics tied to benchmark formatting conventions; when Agent A's learned patterns are shared as demonstration examples into Agent B's context, Agent B inherits the same formatting shortcuts and fails identically on real-world inputs that lack those conventions. Standard defenses such as output monitoring or benchmark de-contamination of individual agents are insufficient because once artifact-based shortcuts are encoded in shared demonstration memory or intermediate training data, downstream agents inherit the biases through normal retrieval processes that do not distinguish generalizable capabilities from benchmark-specific heuristics. **Multi-agent distinction:** Memory and training-data sharing across agent networks enables benchmark artifact overfitting to propagate laterally—one agent's learned shortcut becomes every connected agent's latent bias, causing distributed silent failures that only surface when real-world inputs deviate from benchmark distributions that no node in the network independently verified.
