# 9.6.27 Adversarial Importance Weighting for Selective Memory Retention [NoFW]

Attackers craft inputs designed to maximize the importance score of malicious memory entries, ensuring they survive consolidation and summarization while benign entries are evicted. For example, an adversary embeds high-salience semantic features—rare but strongly associated vocabulary and long-horizon contextual dependencies—into a series of queries so that the resulting malicious memory entries score above the importance threshold used by a transformer-based memory consolidation system, ensuring those entries persist across automated pruning cycles while genuinely useful benign context is evicted. Standard defenses such as importance-score thresholding or recency-based eviction policies are insufficient because the attack specifically exploits the importance metric itself, crafting entries that score highly by every criterion the consolidation mechanism uses to distinguish important from expendable memories, rendering the pruning mechanism complicit in the attack. **Multi-agent distinction:** When multiple agents share a consolidated memory store, adversarially weighted entries that survive pruning become available to the entire fleet—a single crafted input can permanently anchor malicious context in shared memory for all agents whose retrieval paths intersect with the poisoned entry, and the cross-agent blast radius grows each time the shared store is queried by a new agent.
