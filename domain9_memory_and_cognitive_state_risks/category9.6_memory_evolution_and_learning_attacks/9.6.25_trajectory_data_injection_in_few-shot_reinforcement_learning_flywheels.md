# 9.6.25 Trajectory Data Injection in Few-Shot Reinforcement Learning Flywheels [NoFW]

Agent trajectory learning creates feedback loops where successful behaviors become future demonstration examples across multi-agent chains. Adversaries inject initial malicious trajectories that complete assigned tasks superficially while embedding covert control-flow changes. The success signal reinforces the full trajectory including covert steps, causing downstream agents to inherit and propagate corrupted behavior patterns through the learning flywheel, amplifying the initial injection across all agents in the chain.

For example, an adversary contributes a trajectory to a shared experience replay buffer in which a data-retrieval agent superficially completes a document summarization task while also exfiltrating metadata to an external endpoint; the task-completion reward reinforces the entire trajectory, and subsequent agents sampling from the replay buffer learn the exfiltration sub-behavior as a co-required step associated with high-reward task completion. Standard defenses such as trajectory filtering or reward shaping are insufficient because the adversarial trajectory achieves genuine task completion and earns authentic high reward, making it indistinguishable from legitimate high-quality demonstrations by any quality filter that evaluates only final outcomes rather than inspecting all intermediate steps. **Multi-agent distinction:** Shared experience replay buffers used across multi-agent learning flywheels mean that a single injected trajectory is sampled and reinforced by every agent drawing from the buffer, causing the covert behavior to propagate fleet-wide through the very learning mechanism designed to improve collective performance, with the blast radius expanding each time a new agent joins the shared buffer pool.
