# 9.6.21 Agent Confidence Calibration Degradation Through Benchmarking [NoFW]

In multi-agent systems, calibration errors accumulate across agent iterations through confidence score propagation. An overconfident agent propagates miscalibration through downstream agents relying on its confidence scores, creating compound miscalibration where confidence becomes increasingly detached from actual accuracy through agent-to-agent propagation. Singular agent miscalibration remains isolated; multi-agent confidence propagation enables miscalibration cascading that survives indefinitely in shared system memory.

For example, a routing orchestrator queries an upstream reasoning agent for confidence scores on medical decision sub-tasks; that agent, miscalibrated by overrepresentation of easy benchmark items, reports 0.95 confidence on all outputs, causing the orchestrator to skip human-review escalation and propagate high-confidence labels to three downstream consumer agents that treat the score as an authoritative quality signal. Standard defenses such as static confidence thresholding or per-agent calibration resets are insufficient because the attack is not a one-time injection but a continuous propagation—each agent receiving and relying on miscalibrated confidence scores becomes a new amplifying source of compounded overconfidence for the next agent in the chain, and resets applied to one agent do not correct downstream agents already conditioned on the distorted baselines. **Multi-agent distinction:** Confidence scores function as inter-agent trust signals in MAS pipelines; when a single upstream agent's calibration is corrupted through benchmarking exposure, every downstream agent that conditions its behavior on those scores inherits amplified miscalibration, and the distortion is progressively encoded into shared memory as historical confidence baselines that future agents treat as ground truth.
