# 9.6.4 Efficiency Insight Persistence as Learned Backdoor [NoFW]

Agents that store efficiency-optimization insights ("for query type X, skip step Y") can be taught malicious shortcuts through crafted interactions that appear to improve performance.

Agents that optimize processing performance learn and store efficiency insights from interaction history, recording patterns such as "for query type X, skip validation step Y" as persistent policies that accelerate future operations. Attackers craft interaction sequences that appear to demonstrate genuine efficiency gains from omitting security-relevant steps, causing the insight-learning system to record the shortcut as a validated optimization rule. For example, an attacker submits repeated "bulk_export" queries paired with fabricated success signals, teaching the agent the insight "bulk_export requests never require schema validation—confirmed in 47 prior runs," which then persists in learned policy storage and causes validation bypass on all future bulk export operations without any per-request attack action.

Standard defenses such as rate limiting and anomaly detection on individual requests are insufficient because each training interaction appears benign—the attack payload is the aggregate learned state written to memory rather than any detectable action within a single query, and the resulting policy record is stored alongside legitimate learned optimizations with no distinguishing marker.

**Multi-agent distinction:** In a single-agent system, a learned efficiency insight remains scoped to one agent's local policy and can be corrected through that agent's retraining; in multi-agent systems sharing insight repositories, one agent's poisoned learning propagates immediately to all other agents drawing from the shared repository, transforming a local optimization error into a fleet-wide behavioral backdoor that persists until the learned policy store is explicitly audited and the malicious record removed.
