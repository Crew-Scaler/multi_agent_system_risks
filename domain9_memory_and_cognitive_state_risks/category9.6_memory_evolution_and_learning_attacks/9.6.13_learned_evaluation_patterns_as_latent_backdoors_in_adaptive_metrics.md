# 9.6.13 Learned Evaluation Patterns as Latent Backdoors in Adaptive Metrics [NoFW]

Adaptive evaluation metrics learning patterns from prior evaluations embed those learned patterns in agent memory, creating backdoor injection vectors. Attackers inject malicious patterns early causing evaluation agents to adjust expectations incorrectly. Multi-agent evaluation systems storing learned patterns in shared memory create persistence where backdoored expectations propagate to all agents accessing the pattern store, turning learned backdoors into systematic evaluation bias affecting all downstream uses.

For example, an attacker seeds the shared pattern store with early evaluation records establishing "query class: medical_triage, expected accuracy variance: 25%"; adaptive evaluators learning from this poisoned prior subsequently classify an agent achieving only 70% accuracy on medical triage queries as within the expected range, suppressing regression alerts that would otherwise trigger rollback of a clinically unsafe model.

Standard defenses such as evaluation data validation and statistical process control on individual metric values are insufficient because the attack targets the learned prior rather than individual data points—once a false pattern is established in shared memory and the evaluator's adaptive model has absorbed it as ground truth, subsequent individual results are interpreted relative to the poisoned expectation, making the bias invisible to checks that examine each data point in isolation without reference to what prior was used to interpret it.

**Multi-agent distinction:** In a single-agent evaluation system, learned evaluation priors are local and can be reset or retrained independently when bias is detected; in multi-agent systems where a shared pattern store supplies learned expectations to all evaluator agents simultaneously, a single poisoned prior propagates uniform bias across all agents, ensuring that no evaluator raises an alert even when independently reviewed—the same corrupted expectation anchors every agent's judgment and no cross-agent comparison can surface the bias.
