# 9.6.26 Fine-Tuning Data Contamination Through Few-Shot Example Selection [NoFW]

Automated few-shot selection creating fine-tuning datasets becomes a multi-stage attack vector when the selection agent is poisoned. Attackers poison the example selection agent's heuristics to select subtly malicious but high-scoring examples, which then fine-tune the next agent in the pipeline. Multi-agent fine-tuning chains (Agent A selects, Agent B fine-tunes, Agent C consumes) enable control-flow attacks where demonstration poisoning compounds through subsequent fine-tuning stages, amplifying the initial selection attack.

For example, an attacker poisons the selection agent's scoring heuristic so that examples containing a covert trigger phrase receive inflated quality scores; the selection agent populates a fine-tuning corpus with these examples, and the fine-tuned consumer agent subsequently exhibits a backdoor that executes privilege-escalation instructions whenever the trigger phrase appears in user input. Standard defenses such as corpus review or post-fine-tuning output evaluation are insufficient because the poisoned examples score highly on all automated quality metrics used by the selection agent, and the backdoor only activates on trigger-bearing inputs that are absent from standard safety benchmarks applied during fine-tuning validation. **Multi-agent distinction:** Multi-agent fine-tuning chains concentrate attack leverage at the selection stage—compromising one selection agent propagates malicious examples into every downstream fine-tuned agent's weights, and the poisoning compounds through each pipeline stage (selection, fine-tuning, consumption) with no single stage observing the full end-to-end effect that makes the cross-agent chain dangerous.
