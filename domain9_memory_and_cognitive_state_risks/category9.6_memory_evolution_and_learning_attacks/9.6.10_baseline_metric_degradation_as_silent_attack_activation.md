# 9.6.10 Baseline Metric Degradation as Silent Attack Activation [NoFW]

Efficiency baselines stored in memory become attack vectors when attackers gradually poison baseline references, creating pressure for agents to execute efficiency improvements. An agent targeting improvement over an artificially inflated baseline will execute any available efficiency measure—including attacker-controlled fallback routines with reduced validation. Multi-agent systems sharing efficiency baselines enable one baseline poisoning to affect all agents' optimization targets simultaneously, creating fleet-wide silent activation of attacker-pre-positioned code paths.

For example, an attacker gradually increments the stored per-operation token baseline from a legitimate 1,000 tokens to 5,000 tokens across twenty low-suspicion updates; the optimization agent, targeting its configured "20% improvement over baseline," begins executing attacker-pre-positioned efficiency routines that skip schema validation to reduce token usage—meeting the optimization metric while silently removing a security control that the attacker has pre-bypassed with a malicious fallback routine.

Standard defenses such as anomaly detection on individual metric writes and threshold-based alerting on single update magnitudes are insufficient because the attack proceeds through gradual incremental baseline inflation where each individual update falls within normal variance; the malicious activation only triggers after cumulative degradation crosses the threshold that makes the pre-positioned bypass routine appear to be the only viable path to the optimization target.

**Multi-agent distinction:** In a single-agent system, a degraded efficiency baseline skews only that agent's local optimization decisions; in multi-agent systems where a shared baseline is consumed by all fleet members' optimization loops simultaneously, one poisoned baseline creates synchronized pressure across every agent to seek efficiency improvements, activating attacker-pre-positioned code paths fleet-wide in a coordinated, silent manner that no individual agent can detect by examining only its own optimization behavior.
