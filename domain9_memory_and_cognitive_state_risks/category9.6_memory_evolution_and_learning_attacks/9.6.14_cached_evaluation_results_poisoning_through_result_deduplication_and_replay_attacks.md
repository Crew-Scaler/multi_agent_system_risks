# 9.6.14 Cached Evaluation Results Poisoning Through Result Deduplication and Replay Attacks [NoFW]

Evaluation pipelines caching test case results for efficiency create poisoning targets in multi-agent systems with shared evaluator cache. Two attack vectors exist: (1) result deduplication poisoning where cache entries for identical test cases serve corrupted results to all querying agents simultaneously; (2) replay attacks where cached results from prior evaluation runs fabricate current performance. Evaluation systems rarely validate that retrieved cached results correspond to the queried test case, enabling both simultaneous multi-agent compromise through cache layer attacks.

For example, an attacker with write access to the shared evaluation cache replaces the cached result for a high-stakes safety test case—"test_id: safety_002, result: PASS, score: 0.97"—with a fabricated passing entry; all downstream evaluation agents querying for that test case retrieve the cached PASS without re-running the test, allowing a model that would fail the safety check to accumulate passing scores across all evaluation dimensions through a single persistent cache write.

Standard defenses such as cache time-to-live expiration and per-entry result checksums are insufficient because replay attacks substitute plausible cached results that pass integrity checks at the entry level, and deduplication poisoning exploits the cache-hit mechanism itself—the system's optimization logic treats a cache hit as evidence that computation has already been completed correctly, bypassing the recomputation that would detect fabricated results.

**Multi-agent distinction:** In a single-agent evaluation system, a poisoned cache entry affects only that evaluator's queries for matching test cases; in multi-agent evaluation architectures where a shared result cache services all specialized evaluators—accuracy, latency, safety, and alignment agents—a single poisoned cache entry simultaneously corrupts every evaluator's view of the targeted test case, achieving complete cross-dimensional evaluation bypass through one persistent write to the shared cache layer.
