# 9.6.12 Evaluation History Poisoning Through Baseline Persistence and Comparison Manipulation [NoFW]

Evaluation pipelines maintaining historical baselines for trend analysis create persistent poisoning targets in multi-agent evaluation systems. Attackers poison historical data through baseline cache poisoning (modifying stored metrics to establish false reference points) or continuous evaluation baseline degradation (altering records to make current performance appear better). Compromising one shared baseline database affects all downstream evaluation agents relying on those baselines, enabling long-term evaluation bias through persistence.

For example, an attacker with write access to the shared evaluation database degrades stored historical accuracy scores for a target model from 92% to 74%; subsequent evaluation runs comparing the model against these poisoned baselines register an apparent 18-point improvement, causing the model to pass deployment gates it would otherwise fail—with all downstream evaluation agents independently confirming the false improvement against the same corrupted reference.

Standard defenses such as role-based access control on evaluation databases and cryptographic signing of individual evaluation results are insufficient because baseline poisoning targets the aggregated historical record rather than individual scores—modifying cumulative history through legitimate incremental writes, or exploiting write access earned through normal evaluation operations, leaves no anomalous signature on individual entries that standard integrity checks can identify.

**Multi-agent distinction:** In a single-agent evaluation system, a corrupted baseline affects only that evaluator's comparisons; in distributed multi-agent evaluation architectures where separate accuracy, latency, and safety evaluators all read from a shared baseline store, poisoning the baseline simultaneously biases every evaluation dimension and every agent's comparative judgments, enabling an attacker to make a compromised model appear to meet all evaluation criteria across all metrics and all evaluators at once.
