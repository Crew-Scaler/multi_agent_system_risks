# 9.4.4 Framework-Dependent Memory Architecture Mismatches Enabling Cross-Framework State Poisoning [NoFW]

When agents using different memory architectures share state through handoffs, the semantic interpretation of shared memory differs, creating injection opportunities through semantic misalignment.

Each major agent framework encodes memory with different structural assumptions: LangChain uses flat conversation-history JSON, LangGraph expects schema-typed state fields consumed by reducer functions, AutoGen carries implicit message lists, and CrewAI propagates task context through delegation hierarchies. When agents built on these different frameworks share state through handoff serialization, a transformation layer must bridge incompatible representations—and this translation boundary becomes an injection point, because attackers can craft payloads that pass validation in the source framework but activate malicious semantics when deserialized and interpreted by the destination framework's memory model. For example, LangChain memory stored as unstructured conversation history JSON, when passed to LangGraph's stateful agents expecting typed schema structures, creates type misalignment that the reducer functions must resolve—and this resolution logic can be exploited through crafted payloads optimized for transformation behavior rather than content validation.

Standard defenses such as schema validation at ingestion are insufficient because validation is written against the receiving framework's expected schema, not the semantic intent of the content; a payload can be structurally valid in both frameworks while the semantic meaning shifts across the transformation in ways that no schema check can detect.

**Multi-agent distinction:** A single-agent system using one framework maintains internally consistent memory semantics throughout its lifetime; multi-agent systems combining agents across frameworks create forced semantic translation boundaries at every handoff, multiplying the number of points where mismatched memory models can silently corrupt shared cognitive state.
