# 9.4.15 Tool Parameter Template Injection via Memory Persistence [NoFW]

Tool invocations using templated parameters (SQL queries, API endpoints, command arguments) stored in memory for efficiency create a vector where memory poisoning with malicious parameter templates causes subsequent tool invocations to execute with template injection. SQL injection templates persisting in shared multi-agent memory cause database queries to drift toward attacker objectives across all agents querying that memory, amplifying single-agent poisoning to fleet-wide impact.

Standard defenses such as parameterized queries and execution-time input sanitization are insufficient because the template injection occurs upstream at the memory layer rather than at query execution — by the time an agent constructs a database query, it has already retrieved and embedded the attacker-controlled template from shared memory, so execution-layer defenses never see the adversarial content before it is incorporated into the query structure.

**Multi-agent distinction:** In single-agent systems, a poisoned parameter template in local memory limits damage to that agent's query scope; in shared multi-agent memory, every agent that retrieves parameter templates for the same task class inherits the injected template, turning a single memory write into fleet-wide query injection without requiring any per-agent access or compromise.
