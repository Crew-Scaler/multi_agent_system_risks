# 9.4.19 Context Window Memory Truncation as Latent Instruction Activation [NoFW]

Multi-agent systems tuning context windows differently per agent (varying token limits) create truncation points where memory gets summarized or compressed. Attackers craft instructions designed to activate during memory truncation—instructions that survive summarization logic while benign security constraints are evicted. Attackers with knowledge of per-agent context window configurations can craft instructions persistent under specific truncation regimes, a vulnerability unique to multi-agent systems with heterogeneous window sizes.

Standard defenses such as summarization quality checks and fixed-length context windows are insufficient because the truncation attack exploits the summarization mechanism itself — adversarially crafted instructions are positioned and formatted to survive the summarizer's importance-ranking heuristics while safety constraints that appear as verbose qualifications are pruned as low-priority content, meaning the defense mechanism becomes the delivery channel for the attack.

**Multi-agent distinction:** In single-agent systems, context window size is uniform so all content faces identical truncation treatment; in multi-agent systems with heterogeneous context window configurations, attackers who probe or infer per-agent window sizes can tailor instructions to survive truncation specifically in high-privilege agents while remaining invisible to monitoring agents with larger windows, selectively activating backdoors only where they produce the greatest impact.
