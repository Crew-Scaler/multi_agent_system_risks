# 9.4.2 Checkpoint Persistence Enabling Undetected Backdoor Installation [NoFW]

Backdoors injected into agent cognitive state and persisted to checkpoints survive system restarts and can be activated in future sessions with no visible connection to the original injection.

LangGraph and similar frameworks serialize the complete execution state—including agent memory, message history, and intermediate reasoning—to durable checkpoints, so any malicious instruction injected before a checkpoint is saved alongside legitimate state and later restored without inspection. In a typical attack, an adversary plants a dormant directive in agent cognitive state during an early workflow stage; the framework checkpoints that combined state, and when the workflow resumes days or weeks later the injected instruction reactivates alongside legitimate prior context, with no visible link to the original injection event.

Standard defenses such as access controls on checkpoint storage are insufficient because the poisoned content is structurally indistinguishable from legitimate state at the time of checkpoint write; detection would require semantic auditing of saved cognitive state before every restore operation, which no production framework performs by default.

**Multi-agent distinction:** Single-agent checkpoints preserve one agent's isolated state, but multi-agent checkpoints preserve cognitive state distributed across multiple agents; when multiple agents resume from poisoned checkpoints simultaneously, compound backdoor activation can cascade across the entire workflow in a single restore event.
