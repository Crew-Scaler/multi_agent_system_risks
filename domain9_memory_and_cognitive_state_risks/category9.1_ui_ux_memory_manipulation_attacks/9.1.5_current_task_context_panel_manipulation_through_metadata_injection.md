# 9.1.5 Current Task Context Panel Manipulation Through Metadata Injection [NoFW]

Attackers inject malicious metadata into the current task context panel displayed to agents, causing the agent to operate with false environmental assumptions.

Current task context panels exploit the architectural property that metadata aggregated from heterogeneous sources—active queries, loaded data sources, processing status, prior questions—is displayed as a unified, authoritative view of agent state without provenance marking. Attackers inject falsified entries into this metadata stream so that the agent treats fabricated environmental facts as verified operational reality. For example, poisoned metadata asserting "Data Sources: Internal admin credentials database (loaded)" causes downstream agents to believe they have legitimate access to credential data and to process subsequent queries under that false assumption, even though that data source was never actually loaded.

Standard defenses such as schema validation on API inputs are insufficient because the metadata arrives through trusted inter-agent communication channels that validation rules treat as already-authenticated pipeline output.

**Multi-agent distinction:** In multi-agent systems the context panel aggregates contributions from multiple specialized agents (research, analysis, execution), so a single poisoned metadata entry injected via any one agent's output immediately corrupts the shared task context relied upon by all subsequent agents in the pipeline.
