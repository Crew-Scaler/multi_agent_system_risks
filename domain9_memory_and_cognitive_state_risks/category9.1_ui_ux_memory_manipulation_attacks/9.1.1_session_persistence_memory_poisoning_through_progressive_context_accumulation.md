# 9.1.1 Session Persistence Memory Poisoning Through Progressive Context Accumulation [NoFW]

Attackers inject malicious context incrementally across multiple interactions, exploiting session persistence to accumulate a poisoned cognitive state below detection thresholds.

The architectural property being exploited is the long-lived cognitive state created by session persistence features that allow conversation resumption across hours or days. The attack mechanism works through incremental instruction injection across multiple benign-seeming exchanges, where each individual interaction appears harmless while the cumulative effect corrupts agent cognition. For example, a UI normalizing session resumption—such as displaying "Welcome back! Your last session 2 hours ago"—without prompting users to review accumulated context enables "cognitive backdoors" through early-session interactions that remain dormant until specific conditions trigger activation in later agents.

Standard defenses such as session expiry timers or per-interaction content filtering are insufficient because the attack specifically exploits continuity across security boundaries, and attackers distribute injected content below per-interaction detection thresholds while relying on cross-session accumulation to achieve the attack effect.

**Multi-agent distinction:** In multi-agent systems where session state propagates across specialized agents (e.g., research agent → analysis agent → reporting agent), a single poisoned early-session injection can activate across multiple downstream agent contexts rather than being contained within one agent's memory scope, and the temporal gap between injection and activation across different agents makes causal attribution nearly impossible for security monitoring systems observing each agent individually.
