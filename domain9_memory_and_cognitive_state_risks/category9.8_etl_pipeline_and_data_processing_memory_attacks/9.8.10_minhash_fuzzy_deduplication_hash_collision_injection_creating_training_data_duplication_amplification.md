# 9.8.10 MinHash Fuzzy Deduplication Hash Collision Injection Creating Training Data Duplication Amplification [NoFW]

MinHash probabilistic deduplication used for large-scale corpus processing exhibits hash collision vulnerabilities where adversaries craft documents producing identical signatures to legitimate content despite semantic differences. This enables adversarial content to either survive deduplication while displacing legitimate documents (hash collision causing legitimate content to be marked duplicate and discarded) or to be amplified through failed deduplication. Multi-agent centralized deduplication creates fleet-wide training poisoning where signature collisions affect all agents trained on the corpus, enabling coordinated training data substitution across multi-agent deployments through fuzzy deduplication manipulation.

For example, an attacker crafts a misleading financial narrative document with 87% n-gram overlap with a legitimate quarterly report; the MinHash algorithm computes Jaccard similarity above the 0.85 threshold and marks the legitimate report as a near-duplicate, discarding it and retaining the attacker's document (submitted earlier to control ordering), systematically replacing accurate financial records with adversarial narratives in the training corpus without any individual collision being detectable in audit logs.

Standard defenses such as manual corpus audits are insufficient because MinHash deduplication operates at scale on billions of documents where individual document inspection is computationally infeasible, and hash collision artifacts are structurally indistinguishable from legitimate deduplication decisions in the audit logs that record only similarity scores and retention outcomes.

**Multi-agent distinction:** Single-agent training with exclusive deduplication limits hash collision impact to that agent's learned patterns; centralized deduplication shared across a fleet means that adversarially-crafted collision documents affect all agents' training corpora simultaneously, enabling coordinated training data substitution where all agents in the fleet learn adversarial patterns because one attacker document displaced legitimate content through signature collision in the shared deduplication pipeline.
