# 9.7.1 Cluster Replication Protocol Poisoning Propagating Corrupted Vectors [NoFW]

Poisoned vectors inserted into one node of a multi-node vector database propagate to all nodes through the replication protocol, achieving fleet-wide memory corruption. The cluster replication protocol performs format validation and checksum verification but not semantic integrity checks, meaning numerically valid but adversarially crafted embedding vectors replicate across all replica nodes within seconds of insertion. For example, an attacker who gains temporary write access to a single Weaviate node injects subtly shifted embeddings for high-value medical documents; the cluster's replication protocol propagates the poisoned vectors to all replica nodes before operators can detect the anomaly, permanently corrupting retrieval on all nodes until a pre-poisoning snapshot restore is performed.

Standard defenses such as TLS-encrypted replication channels and node authentication are insufficient because they protect against unauthorized replication traffic but cannot detect semantically invalid vectors that are numerically well-formed and arrive from a legitimately authenticated node.

**Multi-agent distinction:** In a single-node deployment a poisoning attack affects only that instance; in replicated multi-node clusters used by multi-agent systems, one compromised write propagates to all replica nodes within milliseconds through the high-availability replication protocol, turning a local node compromise into fleet-wide memory corruption that affects every agent querying any cluster node and persists until operators identify and restore all replicas from a clean snapshot.
