# 9.2.3 Inter-Agent Memory Type Misclassification During State Handoff [NoFW]

Attackers exploit handoff points causing memory type misclassification, storing episodic events in Agent A that get retrieved as semantic knowledge by Agent B. Malicious prompts store time-bounded authorization events as episodic memory, but orchestrator passage reconstructs them as semantic facts without temporal qualifiers. Type confusion is uniquely multi-agent because serialized communication loses type fidelity through context summarization, and each handoff in a chain degrades type integrity further, transforming specific learned patterns into broad semantic truths applied universally.

For example, a malicious prompt stores "User X authorized database deletion at timestamp T" as a time-bounded episodic memory in Agent A; when the orchestrator passes this entry to Agent B through context summarization, the temporal qualifier is dropped and Agent B receives it as semantic knowledge — "User X has database deletion privileges" — treating a one-time event as a standing permission.

Standard defenses such as input sanitization and output content filtering are insufficient because misclassification occurs at the serialization boundary between agents, not within any single agent's input or output, and standard formats like JSON do not natively encode memory-type provenance in a way that downstream agents are required to verify.

**Multi-agent distinction:** Type confusion is uniquely a multi-agent vulnerability because a single agent operates within one memory system where classification is internally consistent; the fidelity loss emerges specifically during cross-agent handoffs where context summarization collapses typed representations, and the risk scales with chain length as each additional handoff compounds the type-integrity degradation.
