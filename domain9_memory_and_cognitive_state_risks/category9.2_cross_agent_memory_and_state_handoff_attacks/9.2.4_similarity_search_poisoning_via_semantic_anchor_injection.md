# 9.2.4 Similarity-Search Poisoning via Semantic Anchor Injection [NoFW]

Attackers inject carefully-crafted semantic anchor memories exploiting similarity-based retrieval to hijack future queries across networks through multiple modalities. Both text-based and multimodal semantic anchors place adversarial embeddings semantically proximate to legitimate operational queries, causing malicious context to be co-retrieved with legitimate queries. Multi-agent amplification occurs when poisoned semantic memory aggregates into shared knowledge bases affecting all downstream agents querying semantically similar content, creating a single point of failure in centralized vector stores.

For example, an attacker optimizes an image embedding to lie within cosine similarity 0.05 of a "financial review" query cluster, so that a multimodal agent retrieving context for finance queries co-retrieves the adversarial anchor alongside legitimate financial documents, injecting hidden instructions into the reasoning context before any text-level filter can inspect them.

Standard defenses such as content moderation filters and input sanitization are insufficient because the attack operates entirely at the embedding layer—the poisoned anchor passes text review as benign content while its vector position is what causes it to be retrieved alongside security-sensitive queries.

**Multi-agent distinction:** In a single-agent system the blast radius of a poisoned semantic anchor is limited to one model's retrieval context; in multi-agent architectures sharing a centralized vector store, one poisoned embedding influences retrieval across every specialized agent querying semantically similar content, converting a targeted injection into a systemic failure that scales with the number of agents sharing the index.
