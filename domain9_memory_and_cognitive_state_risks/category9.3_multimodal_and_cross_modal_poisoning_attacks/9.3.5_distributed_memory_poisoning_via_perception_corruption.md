# 9.3.5 Distributed Memory Poisoning via Perception Corruption [NoFW]

Attackers corrupt perception modules injecting hallucinated facts that propagate through validation gates into long-term memory. In distributed multi-agent systems, sharing of poisoned memories causes corrupted facts to replicate across agent teams with elevated trust because they carry the implicit endorsement of peer agents. Distributed memory systems transform single perception errors into persistent, self-reinforcing collective false beliefs that are difficult to trace back to the original perception failure.

For example, a corrupted object detection module causes Agent A to hallucinate "obstacle cleared at timestamp T" and write this as an episodic memory entry; downstream Agent B retrieving that shared memory treats the record as a verified peer observation rather than a potentially erroneous perception output, and acts on the false clearance with the elevated trust typically reserved for corroborated inter-agent reports.

Standard defenses such as individual agent output validation are insufficient because poisoned memories arrive at downstream agents already labeled with the implicit endorsement of a peer agent, bypassing input-level scrutiny that would apply to direct user inputs.

**Multi-agent distinction:** In single-agent systems a perception error remains isolated within one memory scope and can be corrected within the same context; in multi-agent systems with shared memory, a single corrupted perception propagates to all agents that retrieve from that store, acquiring elevated trust with each propagation hop and becoming increasingly difficult to retract as more agents have acted on it as authoritative fact.
