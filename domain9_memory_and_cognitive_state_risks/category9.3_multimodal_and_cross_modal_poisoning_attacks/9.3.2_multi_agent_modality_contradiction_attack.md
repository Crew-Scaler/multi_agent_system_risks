# 9.3.2 Multi-Agent Modality Contradiction Attack [NoFW]

Contradictory information delivered through different modalities to different agents creates irreconcilable cognitive state across the agent system.

Multi-agent consensus mechanisms designed to resolve cross-modal disagreements become attack amplifiers when contradictions are engineered to target known tie-break logic. An attacker submits an image classified as "safe" by the Vision Agent while simultaneously injecting an audio clip producing an "unsafe" classification from the Audio Agent; a consensus layer receiving one safe vote and one unsafe vote defaults to "safe" (to minimize false positives), resolving the engineered conflict in the attacker's favor and allowing malicious content through.

Standard defenses such as majority voting or consensus mechanisms are insufficient because these contradictions are engineered to produce exactly the vote distribution that triggers favorable tie-break resolution rather than introducing noise detectable as anomalous disagreement.

**Multi-agent distinction:** A single agent processing both modalities applies consistent fusion logic to all inputs simultaneously; multi-agent systems with separate modality specialists and a voting coordination layer are uniquely vulnerable because each specialist operates with partial information while the attacker has full knowledge of the consensus algorithm being exploited.
