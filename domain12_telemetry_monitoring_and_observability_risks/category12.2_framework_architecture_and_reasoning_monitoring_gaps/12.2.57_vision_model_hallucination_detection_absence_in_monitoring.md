# 12.2.57 Vision Model Hallucination Detection Absence in Monitoring [NoFW]

Vision models hallucinate content not present in images (NeVA hallucinating objects, DePlot hallucinating data relationships, Whisper hallucinating speech), but monitoring systems do not detect hallucinations because outputs match expected format; in multi-agent systems hallucinated content drives tool invocations and decisions without any telemetry indicating that source data was fabricated, and hallucinated outputs from one agent cascade invisibly to drive dependent agents' decisions.

For example, a chart-reading agent uses DePlot to extract financial figures from a manipulated chart image and receives hallucinated values that overstate asset valuations by an order of magnitude; the downstream decision agent's trade execution is logged as data-driven, while the hallucinated extraction output never appears in any telemetry record that would link it to the consequent trading action.

Standard defenses such as output format validation and confidence score thresholds are insufficient because hallucinated content frequently satisfies format requirements and is generated with high model confidence, leaving monitoring with no structural signal that the output describes fabricated rather than observed content.

**Multi-agent distinction:** In a single-agent system, hallucinated vision model output affects only that agent's immediate decisions and can be audited by replaying the source image against the agent's own logs; in multi-agent pipelines, hallucinated outputs cross agent boundaries as authoritative data, driving downstream agents' tool invocations and decisions without any telemetry flag indicating that the originating perception was fabricated.
