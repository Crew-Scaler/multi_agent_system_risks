# 12.2.37 Streaming Response Monitoring Blind Spots in Multi-Agent Handoffs [NoFW]

When Agent A streams output directly to Agent B as input, mid-stream injection points at the agent boundary lack instrumentation; monitoring tools that capture only completed response objects miss content injected into partial streams consumed before stream completion.

For example, an attacker with network access to the streaming channel between Agent A and Agent B injects malicious tokens into the partial stream after Agent A has generated them but before Agent B has consumed the full response; Agent B acts on the injected content while post-hoc monitoring examining completed response objects sees only the clean final output from Agent A.

Standard defenses such as TLS encryption and completed-response content inspection are insufficient because TLS does not authenticate streaming content at the token level within an established session, and completed-response inspection cannot recover content that was injected mid-stream and consumed by Agent B before being included in the final logged response.

**Multi-agent distinction:** Multi-agent pipelines multiply the number of streaming handoff boundaries, each of which is an uninstrumented injection surface; single-agent streaming stays within one agent's processing context where generation and consumption are co-located and stream integrity is maintained without cross-agent boundary exposure.
