# 12.2.10 Reducer State Evolution Tracking Gaps [NoFW]

State reducer executions that aggregate or transform shared fields across agent iterations are not traced, making it impossible to determine whether field growth reflects legitimate accumulation or injection through a reducer operating on poisoned inputs.

For example, in a multi-agent research pipeline where a list reducer accumulates evidence citations across three specialist agents, a compromised upstream agent poisons the reducer input with fabricated citations; the reducer appends these silently to the shared evidence field, and subsequent agents treat the entire accumulated list as authoritative with no telemetry recording which reducer invocation or which agent contributed the malicious entries.

Standard defenses such as output validation on individual agent results and input sanitization at agent entry points are insufficient because reducers execute as framework internals between agent turns, operating in a telemetry gap where neither adjacent agent's individual logging scope captures the transformation.

**Multi-agent distinction:** Single-agent reducer behavior is traceable within one execution context; multi-agent systems with multiple agents writing to shared fields through different reducers require comprehensive cross-agent reducer execution tracing—capturing which agent supplied which input to which reducer invocation—that no current framework-level telemetry exposes.
