# 12.2.80 Multi-Agent Root Cause Analysis Inference Failures [NoFW]

Forensic debugging in multi-agent systems becomes unreliable when symptoms manifest in one agent but causes originate in a different agent. Attackers craft attacks with maximal separation between symptom location and cause location, exploiting the cognitive difficulty of cross-agent root cause analysis. Without distributed trace correlation linking cross-agent causality, investigators trace locally and identify the wrong causal agent, enabling attacks that create false causal trails obscuring true responsibility.

For example, an attacker injects a subtle data corruption into an upstream data retrieval agent that becomes apparent only when a downstream report generation agent produces incorrect outputs three pipeline stages later; investigators observe the symptom in the report generation agent, trace backward through the immediately preceding formatting agent (which appears innocent), and exhaust investigation bandwidth without reaching the upstream retrieval agent where the injection occurred.

Standard defenses such as per-agent root cause analysis tools and health dashboards are insufficient because they are designed to diagnose problems within a single agent's scope of execution, and the causal path traversing multiple agent boundaries requires distributed trace correlation that most forensic tooling does not implement.

**Multi-agent distinction:** Root cause analysis failures are structurally amplified in multi-agent systems because the attacker controls the causal distance between the injection point and the symptom manifestation point, and each additional agent boundary crossed by the causal chain reduces the probability that local investigation will reach the true origin before investigative resources are exhausted.
