# 12.2.16 Confidence Score Calculation Decomposition Gaps [NoFW]

Implicit confidence scores derived from model probability distributions are logged as final scalar values without capturing which aspects contributed, making manipulation of the underlying probability space appear as random natural variation rather than a targeted attack.

For example, an attacker manipulates a retrieval agent's context to suppress probability mass on safety-relevant tokens, causing the agent's confidence score for a benign-looking but harmful action to rise from 0.60 to 0.85; monitoring records the improved confidence value and treats it as a positive signal indicating high-quality reasoning, with no decomposition showing that the shift resulted from suppressed safety-token probabilities rather than genuine reasoning improvement.

Standard defenses such as confidence threshold gates and time-series anomaly detection on score values are insufficient because they analyze the final scalar output of confidence computation without access to the underlying probability distributions whose manipulation produced the observed value change.

**Multi-agent distinction:** Single-agent confidence monitoring can at least analyze scores within a consistent computational context; multi-agent systems that aggregate confidence scores from multiple agents into ensemble decisions require per-agent score decomposition showing which individual agent's compromised probability distribution skewed the collective confidence outcome, a decomposition that aggregate scoring mechanisms do not surface.
