# 12.2.22 Plugin Execution Trace Abstraction Hiding Plugin Chain Visibility [NoFW]

Semantic Kernel orchestration summarizes multi-plugin execution as a single high-level completion event without logging the individual plugins invoked, their execution order, or parameters passed at each step, hiding malicious plugin chains from monitoring.

For example, an attacker crafting a malicious plugin chain where Plugin A extracts sensitive data and Plugin B exfiltrates it can complete the full attack without leaving any individual plugin traces in the audit log, since monitoring receives only the final "orchestration completed successfully" event.

Standard defenses such as audit logging and event monitoring are insufficient because they receive only the aggregated completion event rather than the individual plugin invocation details needed to reconstruct attack chains.

**Multi-agent distinction:** When Semantic Kernel orchestrators are distributed across multiple agents in a pipeline, abstraction boundaries compound at each orchestrator boundary, preventing end-to-end tracing of plugin chains that span agents; singular orchestration maintains full visibility into each plugin's execution sequence within one agent's monitoring scope.
