# 12.2.36 Confidence Score Monitoring Blind Spots From Voting Mechanism Opacity [NoFW]

Self-consistency voting distributions are collapsed to a final confidence percentage before reporting; monitoring systems cannot distinguish genuine consensus (all paths agree) from manufactured consensus (a manipulated subset of paths forces majority), as both produce the same reported confidence value.

For example, an attacker injecting prompts that cause three of five reasoning paths to converge on a malicious recommendation produces an 80% confidence score identical to what a legitimate four-of-five consensus would produce; monitoring systems treating any confidence above 75% as trustworthy approve the malicious output without examining the underlying voting distribution.

Standard defenses such as confidence thresholds and output review gates are insufficient because they use the aggregated confidence value as a proxy for trustworthiness without access to the path distribution, and manufactured consensus produces scores indistinguishable from genuine high-agreement outcomes.

**Multi-agent distinction:** When confidence scores propagate across multi-agent pipelines without carrying voting distribution metadata, each successive agent treats inherited confidence as ground truth; single-agent voting opacity at least confines the blind spot to one decision boundary rather than allowing manufactured confidence to compound across the pipeline.
