# 12.2.50 Replanning Attack Obfuscation via Normal Variation [NoFW]

MCTS replanning inherently produces variable search tree sizes, node expansion counts, and nodes-per-second rates depending on problem difficulty; adversaries exploit this by introducing subtle heuristic degradation whose monitoring signature is indistinguishable from natural performance variation, causing replanning to gradually favor attacker-preferred paths without triggering anomaly alerts.

For example, an attacker degrades a navigation agent's distance heuristic by 8%—within the range of normal variance across map regions—causing replanning to explore 20% more nodes per cycle and gradually converge on longer routes that pass through attacker-controlled waypoints, without triggering any expansion-rate alert calibrated for sudden changes.

Standard defenses such as fixed-threshold anomaly detection and per-step performance alerts are insufficient because replanning variation is inherently problem-dependent; static thresholds that tolerate normal variation also tolerate the incremental degradation that adversarial heuristic manipulation is specifically designed to produce.

**Multi-agent distinction:** In a single-agent system, monitoring can establish individual baselines sensitive enough to detect subtle heuristic drift; in multi-agent deployments where replanning metrics are aggregated across the agent fleet, individual agent degradation is masked by averaging with unaffected agents, allowing per-agent heuristic manipulation to remain invisible until the compromise is severe enough to shift the fleet-wide average.
