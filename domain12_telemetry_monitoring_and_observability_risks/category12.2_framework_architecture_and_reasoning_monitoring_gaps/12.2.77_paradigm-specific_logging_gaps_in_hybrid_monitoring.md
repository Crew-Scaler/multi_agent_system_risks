# 12.2.77 Paradigm-Specific Logging Gaps in Hybrid Monitoring [NoFW]

Different hybrid paradigms generate different telemetry (neural components log embeddings and attention, symbolic components log rule firings, learning components log reward signals) and no single monitoring approach covers all paradigm-specific telemetry; attackers identify agents with incomplete paradigm monitoring coverage and target those as compromise vectors, and in hybrid multi-agent systems requiring monitoring of N agents times M paradigm types, complete coverage is operationally infeasible with current monitoring infrastructure.

For example, in a hybrid system where neural perception agents are monitored via attention weight analysis and symbolic planning agents are monitored via rule firing traces, the interface layer that translates neural outputs into symbolic inputs operates under neither monitoring regime; an attacker injects a mistranslation at this interface that causes the planner to receive systematically distorted scene descriptions, exploiting the paradigm boundary where no monitoring system has jurisdiction.

Standard defenses such as deploying separate monitoring stacks for each paradigm are insufficient because the attack surface exists precisely at the boundary between paradigms where neither monitoring stack has visibility, and inter-paradigm interface monitoring requires understanding both paradigms simultaneously—a capability that current specialized monitoring tools lack.

**Multi-agent distinction:** Hybrid multi-agent systems multiply paradigm boundary interfaces by the number of agents and agent-to-agent connections, creating a combinatorial matrix of monitoring gaps that grows with fleet size and makes complete coverage operationally impossible, while a single-agent hybrid system has only the paradigm boundaries within one agent to instrument.
