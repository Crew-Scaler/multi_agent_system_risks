# 12.2.6 Tool Chain Monitoring Gaps Enabling Covert Privilege Escalation [NoFW]

Per-agent tool authorization audits verify that each agent's individual tool calls are within scope, but do not monitor cross-agent sequences; an agent with read-only database access can legitimately pass sensitive data to a second agent with email access, completing an exfiltration attack that no single-agent audit captures.

For example, in a financial services pipeline an Agent A authorized only to query customer account records fetches transaction history and passes the result as plain text to Agent B whose role is sending status emails; Agent B then emails the full transaction history to an attacker-controlled address, and both operations appear in their respective single-agent audit logs as authorized actions producing no individual alert.

Standard defenses such as per-agent permission boundaries and single-agent access control reviews are insufficient because they evaluate each agent's authorization in isolation and have no model of permissible cross-agent data flow sequences that would flag the combination as an exfiltration pattern.

**Multi-agent distinction:** In single-agent systems, tool chains are bounded within one permission context making privilege escalation detectable at the authorization layer; multi-agent architectures create inter-agent data handoffs that compose individually authorized operations into unauthorized aggregate capabilities that no per-agent authorization audit can observe.
