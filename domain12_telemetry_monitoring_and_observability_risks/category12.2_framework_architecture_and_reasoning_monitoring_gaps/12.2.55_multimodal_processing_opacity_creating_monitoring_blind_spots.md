# 12.2.55 Multimodal Processing Opacity Creating Monitoring Blind Spots [NoFW]

Vision model processing (CLIP embeddings, NeVA captions, DePlot extractions) produces outputs rarely included in logs or monitoring dashboards; in multi-agent systems, agents invoke vision models whose results are invisible to security monitoring, creating blind spots where malicious vision model behavior drives tool invocations that appear legitimate in logs but originated from unmonitored multimodal sub-agent outputs.

For example, a document-processing agent invokes a vision model to caption a manipulated image containing adversarial steganographic text; the caption drives a series of file-deletion tool calls logged as legitimate operations, while monitoring has no record of the image content or the captioning output that triggered the action sequence.

Standard defenses such as tool-call logging and input content filtering are insufficient because they operate on text-mode inputs and action outputs, leaving the vision model's internal processing—the intermediate multimodal representation that determines which tools are invoked—entirely outside the logged telemetry envelope.

**Multi-agent distinction:** In a single-agent system with multimodal capabilities, all tool invocations derive from the same agent context and can be correlated with available inputs; in multi-agent systems where a dedicated vision sub-agent produces intermediate outputs consumed by a text-mode orchestrator, the multimodal processing layer sits in a separate agent with independent logging, creating an unmonitored gap between visual input and downstream tool invocation.
