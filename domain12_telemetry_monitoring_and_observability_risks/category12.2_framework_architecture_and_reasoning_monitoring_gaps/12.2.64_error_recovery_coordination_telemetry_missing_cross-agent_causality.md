# 12.2.64 Error Recovery Coordination Telemetry Missing Cross-Agent Causality [NoFW]

Error recovery in multi-agent systems involves coordinated actions across agents, but telemetry captures individual agent actions without cross-agent causality analysis; detecting coordinated attacks exploiting recovery coordination requires understanding how one agent's error propagates through recovery logic triggering dependent agent failures, a causal chain that standard per-agent telemetry cannot reconstruct.

For example, an attacker triggers a deliberate parsing error in an ingestion agent that causes a data validation agent to enter its error recovery branch, which in turn floods a downstream summarization agent with retry requests; per-agent logs show "parse error recovered," "validation retry executed," and "summarization backlog," but no log reconstructs the causal chain linking the original injection to the coordinated cascade.

Standard defenses such as per-agent retry counters and error logging are insufficient because they record individual recovery events without establishing the causal relationships needed to identify whether a sequence of distributed failures reflects organic system stress or coordinated exploitation.

**Multi-agent distinction:** When recovery logic spans agent boundaries—where Agent A's failure mode triggers Agent B's compensating action, which then triggers Agent C's fallback behavior—standard per-agent telemetry produces a collection of isolated events that individually appear normal, concealing the coordinated causality chain that cross-agent distributed tracing would be required to expose.
