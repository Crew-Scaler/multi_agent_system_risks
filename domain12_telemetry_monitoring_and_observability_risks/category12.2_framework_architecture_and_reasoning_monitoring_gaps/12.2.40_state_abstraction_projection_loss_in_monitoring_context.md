# 12.2.40 State Abstraction Projection Loss in Monitoring Context [NoFW]

Hierarchical monitoring agents operate at different abstraction levels; strategic agents monitor abstracted state summaries while tactical agents monitor concrete state details, and neither level has complete visibility, creating abstraction-layer gaps where problems visible only at the concrete level are invisible to agents monitoring abstract summaries.

For example, an attacker injecting anomalous data into a specific sensor feed causes a concrete-level failure visible only to a tactical agent whose reports are abstracted to "subsystem nominal" before reaching the strategic monitoring agent; the strategic agent never observes the underlying anomaly and therefore generates no alert while the concrete-level attack proceeds.

Standard defenses such as hierarchical alerting and threshold-based escalation are insufficient because they rely on the abstract state summary accurately representing concrete state, and abstraction-layer projection losses mean adversarially crafted anomalies at the concrete level can be systematically suppressed in the abstract summary that strategic monitors receive.

**Multi-agent distinction:** In multi-agent hierarchies where different agents own different abstraction layers, each agent's monitoring is correct within its layer while the cross-layer integration that would reveal the full attack remains unmonitored; a single agent maintaining both levels could cross-reference concrete and abstract state directly without projection-loss blind spots.
