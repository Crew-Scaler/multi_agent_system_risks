# 12.2.45 MCTS Tree Statistics as Hidden Cognitive State [NoFW]

Monte Carlo Tree Search internal statistics (visit counts, Q values, UCT scores) represent the agent's cognitive state and planning intentions but are rarely logged; observers with access to shared logging systems, debugging APIs, or memory dumps can extract detailed planning intelligence while legitimate monitoring systems remain blind to the agent's internal deliberation.

For example, an attacker with read access to a shared orchestration log extracts Q-value tables from an MCTS planning agent's debug output and uses them to predict future routing decisions, while the security monitoring system has no corresponding visibility into those same statistics and cannot detect the intelligence extraction.

Standard defenses such as process-level access controls and log scrubbing are insufficient because they address output confidentiality without ensuring that monitoring systems themselves receive the cognitive-state telemetry needed to detect anomalous value-function changes indicating manipulation.

**Multi-agent distinction:** In a single-agent deployment, MCTS cognitive state remains internal and presents primarily a confidentiality risk; in multi-agent systems, planning statistics shared across agents for coordination purposes create telemetry that is simultaneously exposed to adversaries and opaque to security monitors, inverting the usual visibility relationship.
