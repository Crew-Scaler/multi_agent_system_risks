# 12.2.56 Multimodal Attribution Opacity in Tool Invocation Tracing [NoFW]

When agents invoke tools based on multimodal RAG results, monitoring cannot determine whether tools executed due to text queries, image evidence, audio context, or combinations; in multi-agent systems where Agent A's vision processing drives Agent B's tool selection, multimodal tool invocation tracing loses fidelity across modality and agent boundaries, enabling attacks that appear as legitimate multimodal reasoning in logs.

For example, a retrieval-augmented agent selects a file-transfer tool based on combined text and image evidence, but monitoring records only "tool: transfer_file, parameters: {...}" with no attribution to the image evidence that was the actual trigger, making it impossible to determine whether a manipulated image drove the tool selection.

Standard defenses such as retrieval provenance logging and tool parameter auditing are insufficient because they record which tool was selected and with what parameters, but not which modality or specific retrieved content caused the selection—attribution across modality boundaries requires multimodal trace correlation that standard observability stacks do not implement.

**Multi-agent distinction:** In a single-agent multimodal system, all inputs and tool selections share one agent's context and can be traced together even if imperfectly; in multi-agent architectures where vision processing and tool execution span separate agents, the attribution chain is broken at the agent boundary, and monitoring cannot reconstruct whether a specific image, audio clip, or text passage from one agent's RAG retrieval ultimately caused another agent's tool invocation.
