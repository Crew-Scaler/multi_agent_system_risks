# 12.2.30 Reasoning Latency Sidechannels in Coordination [NoFW]

Time delays between reasoning trace generation and tool invocation encode information about agent cognitive state; attackers can infer when their injection succeeded by observing characteristic latency shifts, while monitoring systems that track latency without analyzing its correlation to reasoning content miss this covert channel.

For example, an attacker injecting a complex malicious prompt requiring significantly more reasoning tokens observes a characteristic latency increase in the API response time that confirms injection success without any output content—while the monitoring system logs the latency spike as a normal load variation rather than an attack signal.

Standard defenses such as latency anomaly detection and percentile-based alerting are insufficient because they detect magnitude changes without correlating timing patterns to reasoning content, and adversarially crafted injections can be tuned to produce latency signatures that fall within normal variance bounds.

**Multi-agent distinction:** In multi-agent pipelines where agents synchronize on each other's reasoning outputs before proceeding, coordinated latency patterns emerge that reveal cross-agent attack propagation; single-agent reasoning latency is independent and does not produce the inter-agent timing signatures that allow attackers to confirm attack progress across agent boundaries.
