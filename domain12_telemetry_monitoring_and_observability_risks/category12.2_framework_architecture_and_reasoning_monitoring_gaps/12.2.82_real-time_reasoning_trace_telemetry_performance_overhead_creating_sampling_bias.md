# 12.2.82 Real-Time Reasoning Trace Telemetry Performance Overhead Creating Sampling Bias [NoFW]

Comprehensive cross-agent reasoning trace collection creates prohibitive overhead, forcing sampling strategies; attackers exploit sampling boundaries by routing malicious operations through agents or time windows that are not sampled.

For example, an attacker who has determined through observation that an agent's reasoning traces are sampled at 10% of requests routes malicious tool selections through the 90% unsampled traffic by timing injections to fall outside the sample windows, ensuring that monitoring captures only benign reasoning traces while the agent repeatedly executes injected instructions that never appear in the telemetry record.

Standard defenses such as rate-based anomaly detection on tool invocation counts are insufficient because unsampled malicious operations contribute to action-level metrics that, given uniform sampling, appear as a consistent fraction of the action log without distinguishing sampled from unsampled paths—attackers who understand sampling rates can calibrate injection volume to remain within expected tool usage ranges even at the action-metric level.

**Multi-agent distinction:** In multi-agent systems, sampling decisions are made independently for each agent, meaning that an attacker who learns the sampling schedule across the fleet can route the attack through whichever agent is currently in an unsampled window, achieving guaranteed evasion across the entire pipeline that would not be possible if all reasoning traces were collected comprehensively by a single agent's monitoring system.
