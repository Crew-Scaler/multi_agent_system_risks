# 12.2.32 Preserved Path Instrumentation Blind Spots [NoFW]

Reasoning paths stored for later retrieval are not subject to the same real-time telemetry as live reasoning execution; when downstream agents retrieve and execute these preserved paths, the execution lacks instrumentation linking it to the original generation context, severing the audit trail at the retrieval boundary.

For example, an attacker poisoning a stored reasoning path with malicious tool invocation sequences can have that path retrieved and executed by a downstream agent days later, with no telemetry linking the execution event to the original poisoning event and making forensic attribution structurally impossible.

Standard defenses such as memory content scanning and retrieval-time validation are insufficient because they check stored content in isolation without the execution context needed to evaluate whether a retrieved path remains safe for the downstream agent's current task environment.

**Multi-agent distinction:** When a preserved path generated by Agent A is retrieved and executed by Agent B in a different framework, the audit trail breaks at the agent boundary with no cross-agent telemetry linking generation to execution; single-agent path preservation stays within one monitoring scope where generation and execution context remain co-visible and can be correlated.
