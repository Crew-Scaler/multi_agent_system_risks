# 12.2.70 Rule Firing Monitoring Gaps in Distributed Systems [NoFW]

Inference traces record rule firings in rule-based systems, but in multi-agent systems with distributed rule execution across agents, monitoring rule firings across agent boundaries creates blind spots where Agent A fires rules 1–5 and Agent B fires rules 6–10 but the combined rule sequence is not visible in any single monitoring dashboard, enabling attackers to distribute malicious rule firings across agents creating patterns invisible at the individual agent level.

For example, an attacker inserts a malicious inference rule into a shared rule base that fires only when a specific sequence of rules from different agents has already executed; because monitoring dashboards show per-agent rule firings in isolation, the triggering sequence spanning Agent A and Agent B appears in separate logs, and the combined cross-agent pattern that activates the malicious rule is never assembled into a single viewable trace.

Standard defenses such as per-agent rule execution logging and anomaly detection on individual rule firing frequency are insufficient because distributed rules are individually innocuous, and cross-agent patterns only become detectable through centralized correlation that standard monitoring infrastructure does not perform.

**Multi-agent distinction:** Rule-based systems in multi-agent architectures create a structural gap in which the global logical state produced by combining rule firings across all agents is visible to none of the agents individually, enabling attacks that exploit cross-agent rule interactions while remaining below the detection threshold of any single-agent monitoring system.
