# 12.2.43 Decomposition Correctness Validation Lacking Fallback Checks [NoFW]

No agent in a multi-agent hierarchy is assigned responsibility for validating that selected methods collectively satisfy the original abstract goal; decomposition errors that produce internally consistent but goal-defeating execution plans proceed without monitoring detection.

For example, in a multi-tier task planning system, an orchestrator agent decomposes "secure system access" into sub-tasks that each pass individual validation, yet the decomposition omits access revocation steps, and no monitoring system detects the goal-defeating gap because each component appears individually compliant.

Standard defenses such as unit-level output validation and per-agent correctness checks are insufficient because they verify each method's execution in isolation without confirming that the collective decomposition satisfies the original abstract goal.

**Multi-agent distinction:** In a single-agent system, the agent that decomposes a goal also witnesses execution, creating natural feedback that can surface correctness failures; in multi-agent hierarchies, decomposition responsibility sits with one agent while execution belongs to another, distributing accountability so that neither agent independently possesses the information needed to validate end-to-end goal satisfaction.
