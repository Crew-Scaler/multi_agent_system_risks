# 12.2.46 Simulation Trace Visibility as Behavioral Blind Spot [NoFW]

MCTS simulation traces capturing attempted actions and simulated outcomes are not surfaced to monitoring systems; monitoring sees only the single executed action selected by backpropagation, missing that an adversarial injection caused the agent to extensively simulate dangerous actions before selecting a nominally safe one.

For example, a malicious document injected into an MCTS agent's observation stream causes thousands of simulation steps exploring exfiltration pathways before the agent selects a benign file-copy action; monitoring records only "file copied" and never sees that dangerous alternatives were extensively evaluated during the planning phase.

Standard defenses such as action logging and output monitoring are insufficient because they capture only the final selected action from backpropagation, leaving the entire simulation search space—which reveals planning intent and compromise indicators—invisible to security telemetry.

**Multi-agent distinction:** In a single-agent scenario, simulation trace invisibility is a local blind spot affecting one agent's behavioral audit; in multi-agent systems where simulation outcomes from one agent feed as observations into another agent's decision cycle, unmonitored simulations can propagate adversarial framing across the pipeline without any telemetry linking downstream decisions to the upstream simulation manipulation.
