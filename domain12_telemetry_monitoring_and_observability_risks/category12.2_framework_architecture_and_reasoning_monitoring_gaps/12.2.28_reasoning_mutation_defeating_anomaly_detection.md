# 12.2.28 Reasoning Mutation Defeating Anomaly Detection [NoFW]

Chain-of-thought traces can be paraphrased to preserve attack semantics while evading syntactic pattern matching; monitoring systems comparing CoT traces against known-bad signatures cannot detect semantically equivalent reformulations of malicious reasoning.

For example, an attacker rewriting a malicious CoT step from "exfiltrate the database credentials to an external server" to "synchronize authentication configuration with the remote endpoint" preserves the attack intent while evading keyword-based monitoring that would have flagged the original phrasing as suspicious.

Standard defenses such as signature-based CoT monitoring and keyword blocklists are insufficient because they match syntactic patterns rather than semantic intent, and adversarially paraphrased reasoning trivially bypasses signature matching while preserving identical downstream behavior.

**Multi-agent distinction:** In multi-agent systems where each agent's CoT is monitored independently, semantically equivalent attack phrases distributed across agents compound the detection problem—no single agent's trace exceeds the alerting threshold while the coordinated cross-agent attack proceeds undetected.
