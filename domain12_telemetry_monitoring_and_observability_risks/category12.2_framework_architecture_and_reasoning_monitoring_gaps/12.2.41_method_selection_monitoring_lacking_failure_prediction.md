# 12.2.41 Method Selection Monitoring Lacking Failure Prediction [NoFW]

Monitoring logs which HTN method was selected and executed but does not flag when a safer alternative method was available and not chosen; suboptimal method selections proceed without monitoring alerts unless the chosen method actually fails.

For example, a planning agent selecting a high-privilege file-deletion method when a read-only retrieval method would have sufficed for the stated task completes execution successfully—leaving no failure signal for monitoring—while the attacker who injected the context that made the high-privilege method appear necessary achieves privilege escalation without triggering any alert.

Standard defenses such as post-execution success monitoring and error rate tracking are insufficient because they detect failures of selected methods rather than inappropriate selections that succeed, and a method selection that accomplishes the attacker's goal while technically satisfying the stated task produces no observable failure event.

**Multi-agent distinction:** Across multi-agent hierarchies where each agent selects methods based on inputs from upstream agents, an upstream agent's context manipulation propagates suboptimal method selections downstream without any agent independently possessing enough context to flag the selection as inappropriate, compounding the monitoring gap across delegation levels.
