# 12.2.58 Cross-Modal Consistency Validation Absence in Monitoring [NoFW]

Monitoring does not validate consistency across modalities—whether image content matches text descriptions, audio matches transcripts, or extracted data matches source charts; in multi-agent systems where consistency failures could indicate attacks (such as a DePlot extraction contradicting displayed chart values indicating extraction manipulation), the absence of cross-modal validation in monitoring infrastructure creates blind spots that single-modality monitoring cannot address.

For example, an agent receives a chart image showing revenue of $1.2M alongside a DePlot-extracted representation claiming $12M; neither value is individually anomalous to format-based monitoring, but the order-of-magnitude discrepancy indicating manipulation goes undetected because no monitoring component compares the extracted text against the raw image content.

Standard defenses such as individual modality output logging and range-based anomaly detection are insufficient because they evaluate each modality's output in isolation, and cross-modal inconsistencies that signal manipulation are only detectable when two modalities' representations of the same content are compared—a comparison that standard monitoring stacks do not perform.

**Multi-agent distinction:** In a single-agent multimodal system, all modalities are processed within the same context and a sufficiently capable monitor could compare their representations; in multi-agent systems where image processing, transcription, and text extraction are distributed across specialized sub-agents, cross-modal comparisons require correlating telemetry across agent boundaries, which multi-agent monitoring architectures currently lack the infrastructure to perform.
