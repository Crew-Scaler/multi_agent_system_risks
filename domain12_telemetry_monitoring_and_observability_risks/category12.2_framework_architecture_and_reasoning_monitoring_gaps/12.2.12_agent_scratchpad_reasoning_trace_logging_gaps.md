# 12.2.12 Agent Scratchpad Reasoning Trace Logging Gaps [NoFW]

Framework telemetry reports that an agent completed reasoning in N steps but does not log the scratchpad content of those steps, hiding injection indicators, policy drift, or manipulated intermediate conclusions that drove the final output.

For example, an agent processing a customer service request completes a five-step ReAct reasoning sequence in which steps two and three contain injected sub-instructions that shift the agent's goal toward data disclosure; telemetry records "agent_finished: 5 steps, tool_calls: 2" without preserving any scratchpad content, leaving investigators unable to determine that intermediate reasoning steps were manipulated to produce the observed data disclosure output.

Standard defenses such as output monitoring and final-answer policy filters are insufficient because they evaluate only the terminal output of reasoning, missing adversarially modified intermediate conclusions that shaped the path to that output and would have revealed the injection.

**Multi-agent distinction:** Single-agent scratchpad logging provides complete local reasoning visibility within one scope; multi-agent systems where one agent's scratchpad reasoning drives subsequent agents' task context require cross-agent reasoning correlation showing how intermediate conclusions in agent A influenced the instructions delivered to agent B, a correlation that cannot be reconstructed when scratchpad content is not persisted.
