# 12.2.48 Convergence Failures as Unmonitored Planning Breakdowns [NoFW]

When MCTS fails to converge to a reasonable strategy due to budget exhaustion, miscalibrated exploration, or corrupted value functions, planning quality silently degrades without triggering any monitoring alert; downstream agents that depend on the upstream agent's planning output inherit degraded plans with no indication of the root cause.

For example, an attacker corrupts a value function's reward signal to produce near-uniform Q-values, causing MCTS budget to exhaust before converging; the downstream synthesis agent receives an unconverged plan and proceeds with a randomly ordered action sequence, while monitoring records "planning completed" because no explicit convergence-failure telemetry exists.

Standard defenses such as timeout alerts and resource-utilization monitors are insufficient because they detect exhaustion of computational budget but not whether the planning process converged to a valid strategy before the budget was consumed.

**Multi-agent distinction:** In a single-agent system, convergence failures produce locally degraded outputs that may be caught by the same agent's output validation; in multi-agent pipelines, convergence failures propagate as apparently valid but low-quality plans to downstream agents, which inherit the degraded planning silently because no inter-agent telemetry carries convergence-quality metadata across the boundary.
