# 12.2.27 Framework-Specific Semantic Kernel Monitoring Blind Spots [NoFW]

Organizations standardized on LangChain or LangGraph monitoring lack instrumentation for Semantic Kernel-specific telemetry points such as plugin lifecycle events and kernel service resolution; multi-agent systems mixing Semantic Kernel with other frameworks develop permanent observability gaps at Semantic Kernel boundaries.

For example, a pipeline where LangGraph orchestrates high-level task routing and delegates to Semantic Kernel agents for execution leaves all Semantic Kernel plugin lifecycle events—kernel service resolution, orchestrator routing decisions—unmonitored by the LangGraph telemetry stack, creating a silent execution zone for any attack operating through Semantic Kernel's internals.

Standard defenses such as centralized logging aggregators and generic OpenTelemetry instrumentation are insufficient because Semantic Kernel exposes telemetry through framework-specific hooks that generic collectors do not instrument by default, leaving lifecycle events and routing decisions uncaptured.

**Multi-agent distinction:** In mixed-framework pipelines, Semantic Kernel boundaries accumulate as permanent blind spots that multiply with each additional Semantic Kernel agent added to the system; single-framework deployments maintain consistent telemetry coverage across the entire execution stack without framework-boundary gaps.
