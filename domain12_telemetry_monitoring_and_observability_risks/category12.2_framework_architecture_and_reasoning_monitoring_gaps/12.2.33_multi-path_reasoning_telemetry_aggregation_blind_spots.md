# 12.2.33 Multi-Path Reasoning Telemetry Aggregation Blind Spots [NoFW]

Self-consistency approaches that sample multiple reasoning paths and aggregate to a majority answer report only the aggregate outcome; monitoring systems lose visibility into which individual paths contained injected instructions, as the paths collapse into a single reported answer.

For example, an attacker injecting malicious instructions into 3 of 20 sampled reasoning paths achieves a persistent 15% minority presence while monitoring observes only "20 paths sampled, majority converged on answer X"—the three injected paths are permanently invisible once aggregated into the reported outcome.

Standard defenses such as output filtering and response validation are insufficient because they evaluate the aggregated answer rather than individual path content, and an attack that influences path exploration without changing the majority answer evades both filters and post-hoc validation.

**Multi-agent distinction:** When multi-agent pipelines aggregate self-consistency samples across agents before reporting, individual agent path anomalies merge into a combined telemetry stream where a compromised path from any agent becomes indistinguishable from normal minority variance in the aggregate.
