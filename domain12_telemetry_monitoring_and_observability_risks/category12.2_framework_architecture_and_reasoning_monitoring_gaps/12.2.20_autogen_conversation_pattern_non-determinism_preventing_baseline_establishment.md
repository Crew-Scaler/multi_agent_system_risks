# 12.2.20 AutoGen Conversation Pattern Non-Determinism Preventing Baseline Establishment [NoFW]

AutoGen's non-deterministic message sequencing produces different conversation structures across executions, making static baseline pattern establishment impossible and defeating monitoring approaches that rely on comparing current behavior against historical norms.

For example, across ten executions of the same AutoGen collaborative coding task, the conversation between a PlannerAgent and ExecutorAgent follows ten structurally different message sequences due to LLM sampling variation; an anomaly detection system attempting to flag a conversation sequence induced by prompt injection cannot establish what a normal sequence looks like, because "normal" itself has no fixed structure against which deviation can be measured.

Standard defenses such as behavioral baseline monitoring and sequence-pattern anomaly detection are insufficient because they require sufficient determinism to distinguish baseline from deviation, a prerequisite that AutoGen's non-deterministic conversation dynamics systematically violate, making statistical normality models unreliable for this architecture.

**Multi-agent distinction:** Single-agent deterministic operations can establish reliable behavioral baselines against which anomalies are detectable; AutoGen multi-agent conversation non-determinism compounds across agents because each agent's output variation feeds into the next agent's context, producing conversation variance that grows with each additional agent turn and makes baseline-based detection progressively less viable as system scale increases.
