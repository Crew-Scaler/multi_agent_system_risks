# 12.2.44 Cross-Agent Constraint Conflict Detection Blind Spot [NoFW]

Constraints specified by a planning agent are not monitored for compliance by the executing agent; constraint violations are undetected unless they cause measurable output errors, and cross-agent constraint spanning multiple agents lacks any enforcement verification in telemetry.

For example, a planner agent constrains a data-processing agent to avoid writing to audit tables, but because telemetry records only successful write operations and not constraint-compliance checks, the executing agent silently violates the constraint and modifies audit records without any alert.

Standard defenses such as per-agent access control logging and runtime error monitoring are insufficient because they detect constraint violations only when they produce observable failures, leaving silent violations—where the executing agent ignores soft planning constraints—entirely outside the monitoring envelope.

**Multi-agent distinction:** In a single-agent system, the constraint-specifying and constraint-respecting functions share the same context and logging infrastructure; in multi-agent systems, constraint specifications cross agent boundaries without an enforcement handshake, creating telemetry gaps where compliance with cross-agent constraints is assumed rather than verified.
