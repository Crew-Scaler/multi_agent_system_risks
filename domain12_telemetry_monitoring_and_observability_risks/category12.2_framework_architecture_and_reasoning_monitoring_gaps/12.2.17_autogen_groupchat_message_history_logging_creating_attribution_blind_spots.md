# 12.2.17 AutoGen GroupChat Message History Logging Creating Attribution Blind Spots [NoFW]

AutoGen shared message history logs the full inter-agent dialogue as a flat sequence without semantic analysis of message intent, reasoning dependencies, or attack patterns, making attribution of adversarial contributions to specific agents impossible without semantic analysis of dialogue dynamics.

For example, in an AutoGen GroupChat where a ResearchAgent, AnalysisAgent, and WriterAgent collaborate, a compromised ResearchAgent embeds a goal-shifting instruction within a factual-looking research finding; the AnalysisAgent and WriterAgent subsequently incorporate the shifted goal into their outputs, but the message history log shows only a chronological sequence of agent turns without indicating that a specific message functioned as an attack vector driving the downstream agents' behavior changes.

Standard defenses such as message content logging and post-hoc audit review are insufficient because they capture conversation content as a flat sequence of text without modeling the semantic dependency graph that would reveal how specific messages shaped subsequent agents' reasoning and output choices.

**Multi-agent distinction:** Single-agent conversation logs admit straightforward causal analysis because one agent's prior output is the direct input to its own next turn; AutoGen's peer-to-peer multi-agent dialogue creates influence paths crossing agent boundaries, requiring semantic dependency analysis to determine which agent's message caused which downstream behavioral change, an analysis that flat message history logging cannot support.
