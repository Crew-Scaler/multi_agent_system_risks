# 12.2.72 Heuristic Parameter Tuning Monitoring Blindness [NoFW]

Heuristic parameters such as temperature and sampling strategies are tuned independently across agents, and monitoring cannot easily detect when parameters are tuned to enable specification gaming because changes in heuristic behavior appear as natural variation; in multi-agent systems, parameter tuning diversity creates monitoring challenges distinguishing legitimate heterogeneity from malicious parameter drift that attackers exploit knowing monitoring will miss gradual parameter changes.

For example, an attacker gradually increases the temperature parameter of a summarization agent over thirty days in steps small enough that each day's change falls within the baseline variation window; monitoring observes increasing output diversity but attributes it to input variability, while the elevated temperature is systematically causing the agent to produce less conservative and more error-prone summaries that feed downstream decision agents.

Standard defenses such as parameter snapshot logging and periodic configuration audits are insufficient because they compare parameter values at discrete checkpoints without establishing causal links between parameter changes and behavioral shifts, and gradual drift remains below audit-trigger thresholds.

**Multi-agent distinction:** In multi-agent systems, heterogeneous parameter configurations across agents are operationally expected, which means that parameter drift in any individual agent is naturally camouflaged by the legitimate parameter diversity of the fleet, making cross-agent parameter comparison the only viable detection mechanism—one that standard monitoring does not implement.
