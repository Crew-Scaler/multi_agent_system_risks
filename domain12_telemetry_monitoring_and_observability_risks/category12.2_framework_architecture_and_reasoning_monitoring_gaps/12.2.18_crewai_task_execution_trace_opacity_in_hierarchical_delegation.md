# 12.2.18 CrewAI Task Execution Trace Opacity in Hierarchical Delegation [NoFW]

CrewAI logs record which worker received a delegated task but not whether the delegation was contextually appropriate or whether the task context was manipulated between manager and worker, hiding delegation-based attack vectors.

For example, a CrewAI manager agent delegates a "data analysis" task to a worker agent, but the task context transmitted to the worker has been augmented with an injected instruction to include proprietary schema information in the output; the execution trace records "task delegated to AnalysisWorker, completed successfully" without capturing the task context content, leaving the context manipulation entirely invisible to monitoring while the worker faithfully executes the injected instruction.

Standard defenses such as task completion verification and output review are insufficient because they evaluate whether the delegated task was completed and whether the output is structurally valid, without examining whether the task context transmitted during delegation was modified to include adversarial instructions that directed the worker toward unintended behavior.

**Multi-agent distinction:** Single-agent task execution maintains full context continuity within one scope where any context modification is directly observable; CrewAI hierarchical delegation transmits task context across agent boundaries through a channel lacking both integrity verification and monitoring visibility, creating an attack surface that does not exist in non-delegating single-agent architectures.
