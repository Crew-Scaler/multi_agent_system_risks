# 12.3.22 Batch Ingestion Error Rate Aggregation Hiding Document-Level Failures [NoFW]

Batch ingestion monitoring tracks batch-level success rates; a batch where 95 of 100 documents succeed is counted as successful, hiding the 5% document failure rate; across multiple batches, this aggregation can conceal double-digit document-level failure rates behind near-perfect batch success metrics.

For example, an attacker crafting malformed documents that reliably fail embedding generation will see batches report 95% success while the targeted documents are silently dropped every run; monitoring showing "99% batch success rate" over a week masks thousands of missing documents whose absence goes unnoticed until a downstream agent queries for them and finds nothing.

Standard defenses such as batch success rate thresholds and pipeline alerting are insufficient because they treat a partially successful batch as fully successful, collapsing per-document outcomes into a single pass/fail signal that obscures systematic document-level failures.

**Multi-agent distinction:** In multi-agent systems where multiple agents concurrently ingest documents into a shared knowledge store, per-agent document failure rates diverge silently; aggregate monitoring cannot attribute failures to specific agents or ingestion pipelines, allowing an attacker targeting one agent's ingestion path to remain invisible behind the other agents' healthy batch metrics.
