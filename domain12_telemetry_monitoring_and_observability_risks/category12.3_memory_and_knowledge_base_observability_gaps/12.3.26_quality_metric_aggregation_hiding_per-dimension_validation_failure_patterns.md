# 12.3.26 Quality Metric Aggregation Hiding Per-Dimension Validation Failure Patterns [NoFW]

Aggregate quality scores that combine completeness, accuracy, validity, and consistency dimensions mask per-dimension and per-source failure patterns; operators cannot determine from an aggregate score whether degradation stems from completeness issues, accuracy issues, or validity issues, preventing targeted remediation of specific quality failure modes.

For example, when monitoring reports a quality score drop from 0.92 to 0.82, operators cannot determine whether the cause is completeness failures (missing required fields) or accuracy failures (corrupted data values introduced by a schema change), so remediation teams investigate both dimensions simultaneously rather than targeting the actual root cause.

Standard defenses such as aggregate quality score dashboards and quality trend alerts are insufficient because they collapse multi-dimensional quality measurements into single scalars that hide which specific dimension degraded and for which data source.

**Multi-agent distinction:** In multi-agent systems where each agent processes a distinct source type, per-agent per-dimension quality matrices would isolate which agent-source combination introduced the failure; without that decomposition, the shared quality metric forces fleet-wide investigation when only one agent's source requires remediation.
