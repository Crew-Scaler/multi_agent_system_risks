# 12.3.19 Hierarchical Compression Observation Opaqueness Creating Semantic Monitoring Failures [NoFW]

Hierarchical memory compression stores working summaries in active memory while full conversation history is stored in external databases rarely inspected for anomalies; security monitoring of working memory summaries misses semantic content present only in full histories, and coordinated cross-agent attacks that are visible only when comparing full histories from multiple agents remain undetected in summary-level monitoring.

For example, an orchestrator and sub-agent that cooperate across ten turns to exfiltrate credentials appear benign in both agents' working memory summaries, but a cross-store comparison of their full external histories reveals the coordinated pattern — a comparison that standard monitoring platforms never perform.

Standard defenses such as log aggregation and structured event tracing are insufficient because they collect working memory snapshots rather than correlating full external history stores across agents, leaving coordinated semantic patterns undetectable at the summary level.

**Multi-agent distinction:** In a single-agent system the full history belongs to one store; in multi-agent deployments each agent's full history resides in a separate external database, so detecting coordinated attacks requires cross-store correlation that most monitoring platforms do not implement, meaning shared memory stores have no per-agent write provenance and an undetected poisoning affects every agent's retrieval simultaneously.
