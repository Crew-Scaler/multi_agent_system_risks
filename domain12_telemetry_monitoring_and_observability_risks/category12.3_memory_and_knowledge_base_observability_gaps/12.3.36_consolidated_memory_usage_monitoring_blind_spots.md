# 12.3.36 Consolidated Memory Usage Monitoring Blind Spots [NoFW]

Consolidated memory access patterns—which summaries were retrieved, when, and by which agent—are not tracked at the consolidation-entry level; attackers exploiting backdoored consolidated memories generate no anomalous telemetry if monitoring only observes final agent outputs rather than which consolidated entries influenced them.

For example, an attacker who plants a backdoored summary in an agent's consolidated memory store (activating only when the agent receives queries containing a specific trigger phrase) generates normal-looking retrieval telemetry on every subsequent query; monitoring observes only that the agent's final output changed in response to trigger-matching inputs, with no signal linking the behavioral shift to the specific consolidated memory entry that was retrieved.

Standard defenses such as agent output monitoring and behavioral anomaly detection are insufficient because they observe final outputs rather than the consolidated memory entries that influenced them, meaning a backdoored summary that activates infrequently on trigger inputs produces no sustained anomaly in output-level metrics.

**Multi-agent distinction:** In multi-agent systems, consolidated summaries produced by one agent are frequently shared with or inherited by other agents, so a backdoored summary affects every downstream agent that retrieves it from the shared memory store; the absence of per-agent, per-entry access telemetry means the propagation of the backdoored summary across agents generates no observable signal that would distinguish it from normal shared memory usage.
