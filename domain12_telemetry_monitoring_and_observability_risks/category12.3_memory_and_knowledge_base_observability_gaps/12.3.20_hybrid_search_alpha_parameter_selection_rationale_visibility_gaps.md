# 12.3.20 Hybrid Search Alpha Parameter Selection Rationale Visibility Gaps [NoFW]

Hybrid search alpha parameters controlling vector-versus-keyword weighting are logged as final selected values without capturing the selection rationale; adversaries who manipulate the alpha selection logic (such as an ML classifier) to systematically choose values that eliminate beneficial retrieval modalities remain undetected because monitoring shows only the selected value, not whether that selection was appropriate for the query type.

For example, an adversary who compromises the ML classifier used for dynamic alpha selection could force alpha=1.0 for all medical queries, eliminating keyword matching that reliably surfaces drug interaction documents by name; monitoring shows only the final value "alpha=1.0" with no indication that pure vector retrieval was inappropriate for those keyword-dependent queries.

Standard defenses such as parameter auditing and configuration drift detection are insufficient because they compare alpha values against expected ranges rather than evaluating whether each selected value was appropriate for the specific query type that triggered it.

**Multi-agent distinction:** In multi-agent systems where different agents use different alpha selection strategies, monitoring cannot distinguish legitimate per-agent strategy variation from adversarial manipulation of one agent's selection logic, and a shared index means all agents are exposed to the same retrieval distortion without per-agent rationale trails to isolate which agent's selection logic was compromised.
