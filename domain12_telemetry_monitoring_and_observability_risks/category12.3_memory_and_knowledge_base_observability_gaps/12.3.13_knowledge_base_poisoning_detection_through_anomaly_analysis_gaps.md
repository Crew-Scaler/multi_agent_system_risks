# 12.3.13 Knowledge Base Poisoning Detection Through Anomaly Analysis Gaps [NoFW]

Detecting poisoned knowledge base entries through retrieval anomalies requires establishing baselines of normal retrieval patterns; in multi-agent systems with diverse query distributions, the retrieval pattern diversity makes it difficult to distinguish poisoning anomalies from legitimate variation across agent specializations.

For example, a medical agent legitimately retrieves documents on rare drug interaction profiles and a legal agent legitimately retrieves obscure regulatory precedents, both generating retrieval patterns that appear statistically unusual against aggregate baselines; an anomaly detector calibrated to the combined distribution either fires constant false positives on both legitimate patterns or raises its sensitivity threshold to the point where an actual poisoning event—a sudden shift toward data-exfiltration-supporting content—is absorbed as normal inter-agent variation.

Standard defenses such as statistical anomaly detection and retrieval pattern baselining are insufficient when baselines are computed across heterogeneous agent populations; a poisoning signal that would be obvious against a per-agent baseline is masked by the wide variance of legitimate cross-agent query diversity when only aggregate baselines are maintained.

**Multi-agent distinction:** In multi-agent systems, the natural breadth of agent specializations creates a retrieval pattern distribution wide enough to absorb many poisoning signals as expected variation; this is the inverse of the single-agent case where any significant deviation from a narrow baseline is detectable, meaning the monitoring gap grows proportionally with the number of distinct agent specializations sharing the same knowledge base.
