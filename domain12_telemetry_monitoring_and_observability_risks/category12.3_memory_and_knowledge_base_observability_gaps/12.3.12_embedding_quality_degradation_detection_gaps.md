# 12.3.12 Embedding Quality Degradation Detection Gaps [NoFW]

Cumulative embedding corruption from poisoned ingestion degrades retrieval accuracy gradually, but no monitoring metric directly measures embedding quality without running retrieval benchmark evaluations; quality degradation remains invisible until it produces noticeable downstream accuracy failures.

For example, an attacker injects 0.3% corrupted vectors per daily ingestion batch over ten weeks, staying below any single-batch anomaly threshold; retrieval accuracy declines gradually from 93% to 68% over the attack window, but because no monitoring metric directly measures embedding quality without running dedicated benchmark evaluations, the degradation remains invisible until downstream task failure rates climb high enough for users to report pervasive accuracy problems.

Standard defenses such as ingestion validation and schema enforcement are insufficient because they verify the structural properties of incoming documents rather than the semantic integrity of the resulting embedding vectors; structurally valid documents crafted to position their embeddings adversarially in the vector space pass all ingestion checks while corrupting the retrieval landscape incrementally.

**Multi-agent distinction:** In multi-agent systems sharing an embedding store, gradual quality degradation affects all agents simultaneously and uniformly; because no individual agent experiences a sharp enough accuracy drop to trigger its own alert and aggregate monitoring across agents averages together the deteriorating retrieval accuracy of all agents, the systemic degradation remains below detection thresholds until the cumulative corruption has reached a level where collective downstream failures become undeniable across the fleet.
