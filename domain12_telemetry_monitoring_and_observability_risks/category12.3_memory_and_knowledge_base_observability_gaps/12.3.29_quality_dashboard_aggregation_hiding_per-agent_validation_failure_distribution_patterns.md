# 12.3.29 Quality Dashboard Aggregation Hiding Per-Agent Validation Failure Distribution Patterns [NoFW]

Fleet-wide quality dashboards display aggregate pass rates across all agents without per-agent breakdowns; an agent achieving 94% pass rate and an agent achieving 48% pass rate produce an aggregate of 71% that appears acceptable, hiding that one agent has severe quality issues requiring investigation while the other performs well.

For example, Agent A processing structured database sources achieves 94% validation pass rate while Agent B processing unstructured web content achieves 48%, but the fleet dashboard shows a 71% average that falls within the acceptable range and suppresses any alert, leaving Agent B's severe quality issues unaddressed for weeks.

Standard defenses such as fleet-wide quality dashboards and aggregate pass rate alerting are insufficient because threshold alerts calibrated to fleet averages do not trigger when one agent's quality degrades while others compensate, requiring per-agent breakdowns that most dashboard platforms do not provide.

**Multi-agent distinction:** In multi-agent systems, shared quality dashboards create collective blind spots where one agent's failure is statistically absorbed by other agents' success; without per-agent quality telemetry, the shared knowledge store accumulates domain-specific quality failures that only surface when end-user queries against that domain produce poor results.
