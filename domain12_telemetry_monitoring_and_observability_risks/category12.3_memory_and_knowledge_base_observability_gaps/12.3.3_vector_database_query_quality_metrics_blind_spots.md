# 12.3.3 Vector Database Query Quality Metrics Blind Spots [NoFW]

Standard Prometheus monitoring captures query latency but not retrieval quality metrics (semantic relevance, diversity, poisoning indicators), leaving RAG poisoning attacks undetected.

Vector databases expose operational metrics (query latency, throughput, memory usage, object count) through standard Prometheus endpoints, but none of these metrics capture whether returned documents are semantically relevant, contextually appropriate, or adversarially crafted; a database returning poisoned embeddings at 95th-percentile latency under 80 ms appears operationally healthy by every available metric. The architecture treats retrieval quality as a pre-deployment validation concern rather than an ongoing operational signal, so the monitoring stack has no mechanism for detecting when cumulative embedding corruption or parameter drift causes semantic relevance to degrade below task requirements. For example, an attacker gradually poisons high-priority embeddings over three weeks; latency and throughput dashboards remain green throughout, but agents silently receive increasingly irrelevant or adversarially chosen documents, and the first human-detectable signal arrives only when downstream task quality collapses catastrophically.

Standard defenses such as SLA-based latency alerting and uptime monitoring are insufficient because they measure the speed and availability of retrieval operations, not the semantic accuracy of what is retrieved; a database can achieve 99.99% uptime and sub-50ms p99 latency while consistently returning adversarially chosen content without any metric flagging the contradiction.

**Multi-agent distinction:** In multi-agent systems, heterogeneous agents have different retrieval quality requirements—a medical diagnosis agent may require 95% Recall@10 while a general search agent accepts 80%—but shared Prometheus metrics aggregate quality signals across all agents without per-agent breakdowns; an attacker degrading one agent's retrieval accuracy remains undetected because compensating performance from other agents keeps aggregate metrics within acceptable bounds while the targeted agent silently fails.
