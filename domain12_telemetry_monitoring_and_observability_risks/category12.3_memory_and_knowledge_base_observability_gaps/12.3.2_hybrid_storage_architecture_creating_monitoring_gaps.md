# 12.3.2 Hybrid Storage Architecture Creating Monitoring Gaps [NoFW]

Hierarchical memory architectures (working memory summaries plus external full-history storage) create semantic gaps where monitoring of working memory misses the full content that informed agent decisions.

Hybrid storage architectures route different data types to different backends—vector databases for semantic embeddings, graph databases for structured relationships, relational databases for structured metadata—each with its own instrumentation layer and monitoring coverage depth. Agents simultaneously query multiple storage tiers, and an attacker who identifies which tier is under-monitored can insert poisoned content specifically in that tier knowing it will be retrieved without triggering the alerting present in better-instrumented tiers. For example, a vector database receives extensive Prometheus instrumentation while a companion graph database used for relationship expansion receives only coarse health checks; an attacker poisons graph relationships retrieved during the expansion phase of hybrid queries, and the poisoning evades vector-tier monitoring entirely because the observable retrieval event points to the monitored tier while the adversarial content arrives through the unmonitored one.

Standard defenses such as application-layer monitoring and query logging are insufficient because they observe the combined output of hybrid retrieval without attributing which storage tier contributed which portion of the returned context, making it impossible to isolate which tier was the source of anomalous content.

**Multi-agent distinction:** In multi-agent systems, multiple agents share hybrid storage tiers and each agent may interact with a different subset of tiers based on its task specialization; the asymmetric monitoring coverage across tiers creates differential visibility gaps that vary by agent, and a single under-monitored tier can deliver poisoned content to any agent querying it regardless of how thoroughly that agent's primary tier is instrumented, while cross-agent attribution of who read from the unmonitored tier and when is impossible without per-read provenance logging.
