# 12.5.21 Metric Collection Parameter Tuning Creating Monitoring Gaps [NoFW]

Agents are instrumented with heterogeneous monitoring parameters (some with comprehensive trace logging, others with minimal logging for performance); adversaries preferentially route malicious operations through agents with reduced instrumentation, exploiting monitoring-parameter asymmetry to avoid detection.

For example, when an orchestration agent with full trace logging delegates a suspicious data exfiltration operation to a worker agent running with minimal logging for performance reasons, the orchestration agent's logs show only a legitimate-looking delegation event while the worker agent's minimal logs contain insufficient detail to reconstruct what was executed or why.

Standard defenses such as centralized log aggregation and network monitoring are insufficient because they collect whatever telemetry agents produce without normalizing instrumentation depth across agents, and routing attacks through minimally-instrumented agents specifically exploits the telemetry asymmetry that performance optimization creates.

**Multi-agent distinction:** Single-agent systems apply uniform instrumentation across the same process; multi-agent systems independently configure each agent's logging depth, often driven by per-agent performance requirements rather than security requirements, creating a patchwork of instrumentation coverage where the least-monitored agent becomes the preferred attack route.
