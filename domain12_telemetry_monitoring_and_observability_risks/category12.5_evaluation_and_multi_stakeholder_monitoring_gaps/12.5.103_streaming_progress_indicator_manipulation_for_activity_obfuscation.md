# 12.5.103 Streaming Progress Indicator Manipulation for Activity Obfuscation [NoFW]

Streaming progress indicators showing content delivery rates can be manipulated by attackers controlling streaming speed to hide expensive background operations; slow streaming of benign content while rapid internal processing of malicious operations creates the illusion that visible progress is aligned with actual system activity, and in multi-agent monitoring that observes visible streaming progress, background processing by concurrent agents remains invisible behind the deceptively-slow visible stream.

Standard defenses such as CPU and GPU utilization monitoring are insufficient because streaming orchestration decouples visible output rate from actual compute consumption at the middleware layer, so high background compute appears as normal inference activity rather than as a mismatch with the observable slow stream rate that would indicate covert computation.

**Multi-agent distinction:** In multi-agent systems, the agent controlling the streaming output rate is often distinct from the agents performing background computation, so monitoring that observes the streaming agent's low output rate cannot see the compute-intensive activity occurring inside other agents in the same workflow, making the slow-stream-as-cover technique uniquely effective when streaming and computation are split across agent boundaries.
