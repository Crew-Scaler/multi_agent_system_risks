# 12.5.100 Streaming Multimodal Output Processing Monitoring Gaps [NoFW]

Multimodal synthesis produces streaming outputs combining text, image references, and audio links in multi-agent systems where dependent agents process partial outputs before the complete stream is generated; this creates intermediate states where image references streaming before malicious text instructions enable dependent agents to act on incomplete content, and monitoring focused on final streaming outcomes misses attacks exploiting intermediate multimodal state ordering.

For example, a vision-language agent streams an image reference followed by a text instruction that redirects the downstream agent to a malicious action; the downstream agent processes the image reference token as it arrives and begins executing, and by the time the full response is complete and monitoring can analyze it, the downstream agent has already taken an irreversible action based on the partial stream.

Standard defenses such as post-completion content moderation and tool-invocation auditing on completed responses are insufficient because dependent agents act on partial streaming content in real time, before monitoring systems receive and analyze the complete multimodal response.

**Multi-agent distinction:** In multi-agent systems, streaming output from one agent feeds directly into the context of one or more downstream agents without synchronization barriers, so the exploitable attack surface—incomplete multimodal state at each token boundary—multiplies with every consuming agent in the chain, and no single monitor observes both the generating stream and all consuming agents simultaneously.
