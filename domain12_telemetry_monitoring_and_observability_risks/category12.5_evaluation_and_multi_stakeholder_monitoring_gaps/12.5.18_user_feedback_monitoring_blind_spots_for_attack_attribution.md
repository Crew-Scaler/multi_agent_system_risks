# 12.5.18 User Feedback Monitoring Blind Spots for Attack Attribution [NoFW]

User feedback in multi-agent systems is attributed to the final responding agent regardless of which agent in the chain introduced the quality failure; adversaries who corrupt an intermediate agent's output can hide their impact behind last-agent attribution, preventing identification of the true source of quality degradation.

For example, when a user reports that the system "gave contradictory advice," monitoring attributes the failure to the final response agent because that is the only agent whose output the user observed, while the actual source of the contradiction was an intermediate reasoning agent three steps upstream whose manipulated output seeded the final agent's response.

Standard defenses such as per-agent feedback routing and error attribution dashboards are insufficient because they operate on the response that reached the user rather than on the full agent chain, and tracing a quality failure backward through multiple agent handoffs requires end-to-end provenance that feedback collection systems do not maintain.

**Multi-agent distinction:** Single-agent systems have unambiguous attribution because one agent produced the output; multi-agent systems route feedback only to the final agent regardless of where in the pipeline the failure originated, systematically misdirecting quality improvement efforts and leaving compromised intermediate agents undetected.
