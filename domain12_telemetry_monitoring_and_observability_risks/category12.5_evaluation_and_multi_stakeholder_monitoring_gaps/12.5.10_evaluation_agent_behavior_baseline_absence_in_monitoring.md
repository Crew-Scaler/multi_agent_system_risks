# 12.5.10 Evaluation Agent Behavior Baseline Absence in Monitoring [NoFW]

No behavioral baselines exist for evaluation agent operational patterns, making it impossible to apply anomaly detection to evaluation agent behavior; monitoring cannot distinguish legitimate evaluation from attack-driven evaluation manipulation without reference baselines defining what normal evaluation agent behavior looks like.

For example, when an evaluation agent begins approving a disproportionately high fraction of borderline outputs, there is no established normal approval-rate range to compare against, so monitoring cannot determine whether the agent is operating legitimately under new conditions or has been compromised to systematically over-approve.

Standard defenses such as output-level quality spot-checks and threshold-based alerting are insufficient because they require a known baseline to compare against, and without behavioral baselines for evaluation agents specifically, any observed evaluation behavior pattern is treated as potentially legitimate.

**Multi-agent distinction:** In single-agent evaluation systems behavioral patterns can be profiled over time for a single known agent; in multi-agent evaluation each agent type has distinct evaluation responsibilities and interaction patterns, so establishing meaningful per-agent baselines requires understanding each agent's normal operational range—work that is rarely done—leaving the entire evaluation pipeline without anomaly detection capability.
