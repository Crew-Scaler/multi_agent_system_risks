# 12.5.74 Metric Aggregation Masking Agent-Specific Anomalies [NoFW]

Fleet-wide metric averages for latency, throughput, and error rates mask individual agent anomalies through averaging effects; a compromised agent exhibiting injection-driven anomalous behavior remains undetected when its metrics deviate within the natural variance range of the fleet average, enabling long-term undetected compromise for agents operating in large heterogeneous fleets.

For example, an attacker who compromises one agent in a 50-agent fleet and induces a 20% latency increase in that agent's responses produces a fleet-average latency increase of only 0.4%, which falls within the natural variance range of fleet metric fluctuation and triggers no monitoring alert while users routed to the compromised agent experience consistent degradation.

Standard defenses such as per-agent metric dashboards and individual SLO alerting are insufficient because manually maintaining 50 separate alert rules in a dynamically scaled fleet is operationally impractical, and automated per-agent alerting systems require pre-established individual baselines that are unavailable for newly deployed or recently rescheduled agent replicas.

**Multi-agent distinction:** In a single-agent system, any anomaly affects 100% of the monitored surface and is immediately visible in all metrics; in a multi-agent system, the same anomaly affects only 1/N of the monitored surface, reducing its signal-to-noise ratio proportionally to fleet size and creating a structural masking effect that makes per-agent anomaly detection increasingly difficult as the fleet grows.
