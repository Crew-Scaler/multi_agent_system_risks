# 12.5.31 Parameter Validation Failures Undetected in Aggregated Metrics [NoFW]

Aggregate action accuracy metrics hide per-parameter-type failure patterns; an agent with 60% accuracy on temporal parameters and 92% accuracy on other types appears as 87% overall accuracy, masking systematic temporal parameter weakness that attackers can exploit knowing that particular parameter class evades detection in aggregate metrics.

Standard defenses such as aggregate accuracy dashboards and average metric reporting are insufficient because averaging across parameter types hides type-specific weaknesses that attackers can selectively exploit, and alarm thresholds calibrated to overall accuracy fail to trigger when only one parameter class degrades while others remain healthy.

**Multi-agent distinction:** In multi-agent systems, parameter-type failures that are already invisible within a single agent's aggregate metric become further obscured when multiple agents' aggregate scores are combined at the fleet level, so an attacker who degrades temporal parameter accuracy in one specialized agent exploits a double-averaging effect that remains undetected across both agent-level and system-level monitoring; no single stakeholder holds visibility into per-parameter-type accuracy for the full pipeline.
