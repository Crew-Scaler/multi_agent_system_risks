# 12.5.11 Cross-Evaluation Temporal Analysis Gaps [NoFW]

Evaluation runs are treated as independent events rather than as time-series data; temporal patterns such as metric improvements consistently occurring on specific days or following specific events that indicate systematic evaluation gaming are not analyzed because monitoring lacks the temporal correlation capability to detect scheduled manipulation patterns.

For example, an evaluation agent whose approval rate increases by 3% every Sunday may be reflecting a scheduled configuration push that replaces strict metric thresholds with lenient ones before the weekly deployment window, a pattern that only temporal correlation across multiple evaluation runs would reveal.

Standard defenses such as per-run evaluation dashboards and alert-on-threshold monitoring are insufficient because they examine each evaluation run independently without accumulating run-to-run data in a form that enables temporal pattern detection across the evaluation time series.

**Multi-agent distinction:** In single-agent evaluation one team can notice recurring improvement patterns through manual review; in multi-agent evaluation where different agents run evaluations independently on different schedules, temporal patterns that span agent boundaries require cross-agent time-series correlation that no individual stakeholder's monitoring produces.
