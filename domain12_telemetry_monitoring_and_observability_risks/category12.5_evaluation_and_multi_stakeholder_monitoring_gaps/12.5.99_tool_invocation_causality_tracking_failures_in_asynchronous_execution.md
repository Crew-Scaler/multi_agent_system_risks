# 12.5.99 Tool Invocation Causality Tracking Failures in Asynchronous Execution [NoFW]

Tool frameworks enable asynchronous tool invocation where agents queue calls without waiting for completion; in multi-agent systems, causality attribution for which agent initiated which tool becomes unclear when Tool invocation by Agent B was actually initiated by Agent A in a prior step through asynchronous request queuing, and monitoring systems that attribute tool invocations by immediate requester rather than original initiator enable attackers to spoof causality attribution in audit logs.

Standard defenses such as distributed tracing with propagated trace IDs and asynchronous request queues with correlation metadata are insufficient because agents that dequeue work items often discard or replace the originating trace context, breaking the causal chain that would link the dequeued tool invocation back to the agent that enqueued it.

**Multi-agent distinction:** In multi-agent systems, asynchronous queuing is the primary inter-agent handoff mechanism, so causality breaks occur at every agent boundary rather than within a single agent's call stack; the resulting audit log appears to show autonomous tool invocations from intermediate agents when the originating agent—potentially the compromised one—is entirely absent from the recorded causality chain.
