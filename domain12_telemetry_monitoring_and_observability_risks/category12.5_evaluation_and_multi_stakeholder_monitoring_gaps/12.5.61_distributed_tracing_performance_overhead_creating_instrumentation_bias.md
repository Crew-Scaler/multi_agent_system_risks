# 12.5.61 Distributed Tracing Performance Overhead Creating Instrumentation Bias [NoFW]

Comprehensive distributed tracing adds latency overhead that varies across agents based on instrumentation depth; heavily-instrumented agents exhibit different latency profiles than lightly-instrumented agents, creating cross-agent behavior divergence in monitored environments that prevents accurate verification of multi-agent interaction effects in production.

For example, an orchestration agent instrumented with full distributed tracing may exhibit 180% tail latency overhead compared to an uninstrumented worker agent, so when evaluating whether the orchestration-to-worker handoff is causing a latency regression, the measurement itself introduces the latency differential under study, making the root cause unresolvable through available monitoring data.

Standard defenses such as sampling-based tracing or asynchronous trace collection are insufficient because they either introduce systematic gaps in coverage that attackers exploit by timing operations to fall in unsampled windows, or they delay trace availability past the point where real-time anomaly detection can act on the data.

**Multi-agent distinction:** In a single-agent system, instrumentation bias affects only one execution context; in a multi-agent system with heterogeneous instrumentation depths, behavior comparisons across agents permanently conflate application logic differences with instrumentation-induced artifacts, preventing accurate characterization of inter-agent interaction effects.
