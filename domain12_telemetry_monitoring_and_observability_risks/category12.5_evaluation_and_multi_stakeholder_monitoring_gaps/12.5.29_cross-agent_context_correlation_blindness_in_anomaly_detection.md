# 12.5.29 Cross-Agent Context Correlation Blindness in Anomaly Detection [NoFW]

Per-agent anomaly detection identifies unusual tool invocation patterns within each agent's individual behavior stream; adversaries distribute anomalous invocations across multiple agents so that each agent's individual pattern appears normal, while the cross-agent correlation that would reveal the coordinated attack is absent from monitoring.

For example, an attacker who issues three unusual but individually low-frequency tool invocations across three different agents—each invoking a tool once within its normal usage range—produces a cross-agent sequence that uniquely identifies exfiltration preparation, but because each agent's anomaly detector sees only one within-range invocation, no alert fires and the coordinated pattern is never assembled.

Standard defenses such as per-agent anomaly detection models and individual tool invocation monitoring are insufficient because they model each agent's behavior in isolation and cannot detect attack patterns that are individually unremarkable but collectively anomalous across independent agent streams.

**Multi-agent distinction:** Single-agent anomaly detection operates over one continuous behavioral stream where cross-tool correlations are naturally visible; multi-agent anomaly detection requires correlating independent streams from agents with different operational baselines, different tool palettes, and different invocation frequencies, and this correlation is rarely implemented, leaving coordinated cross-agent attacks in a structural blind spot.
