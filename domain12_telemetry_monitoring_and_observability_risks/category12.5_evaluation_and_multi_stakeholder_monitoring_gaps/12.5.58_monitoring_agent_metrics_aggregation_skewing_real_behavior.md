# 12.5.58 Monitoring Agent Metrics Aggregation Skewing Real Behavior [NoFW]

Centralized dashboards average metrics across agent fleets; compromised agents exhibiting anomalous behavior remain undetected when their metric deviations average with normal agents' natural variance, and in large fleets where compromised agents constitute a minority, this averaging effect systematically suppresses anomaly visibility below detection thresholds.

For example, three compromised agents in a 100-agent customer service fleet exhibit token consumption 300% above normal; when averaged with the 97 agents operating normally, fleet-wide average token consumption increases by only 6%, which falls within normal daily variance; the three compromised agents continue operating indefinitely because the averaging effect dilutes their anomalous signal below any reasonable fleet-level detection threshold.

Standard defenses such as fleet-wide average dashboards, mean-based alert thresholds, and aggregate metric monitoring are insufficient because they are specifically designed to smooth individual variance across the fleet, a property that simultaneously makes them blind to minority-agent anomalies regardless of how extreme those anomalies are.

**Multi-agent distinction:** Fleet metric averaging creates a detection threshold floor that scales inversely with fleet size: as fleet size increases, a compromised minority agent's contribution to fleet averages decreases proportionally, meaning that larger multi-agent fleets have systematically worse anomaly detection for minority-agent attacks than smaller fleets; this inverse relationship between fleet scale and individual agent observability has no equivalent in single-agent systems and represents a fundamental monitoring scalability challenge specific to multi-agent deployments.
