# 12.5.9 No Monitoring of Evaluation Dataset Integrity [NoFW]

Evaluation datasets accessed by evaluation agents in multi-agent systems are not monitored for content modifications; adversaries who poison evaluation datasets leave no audit trail detectable through evaluation pipeline monitoring because datasets are treated as trusted static inputs rather than as mutable attack surfaces requiring integrity verification.

For example, an attacker who adds carefully crafted examples to a shared evaluation dataset used by multiple evaluator agents can cause all agents to systematically approve a specific class of unsafe outputs, and because dataset content is assumed static and trusted, no monitoring alert fires before or after the modification.

Standard defenses such as access control on evaluation datasets and periodic manual dataset review are insufficient because they do not provide continuous integrity monitoring that would detect content modification between scheduled reviews, leaving a window during which all evaluator agents operate on poisoned ground truth.

**Multi-agent distinction:** Single-agent evaluation pipelines typically have one owner who maintains dataset integrity through direct control; multi-agent evaluation pipelines where multiple agents share a dataset create a higher-value target, and the absence of automated integrity verification means a single successful dataset poisoning simultaneously corrupts every evaluator agent's ground truth without any per-agent monitoring detecting the attack.
