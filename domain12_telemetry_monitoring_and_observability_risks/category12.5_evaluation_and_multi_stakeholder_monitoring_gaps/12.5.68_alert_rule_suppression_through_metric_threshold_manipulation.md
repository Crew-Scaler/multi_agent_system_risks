# 12.5.68 Alert Rule Suppression Through Metric Threshold Manipulation [NoFW]

Adversaries who can influence metrics from specific agents can manipulate those agents' metrics to stay just below alert thresholds while other agents experience cascading effects; alert rules based on manipulated agent metrics remain silent while legitimate impact propagates to agents whose metrics the adversary did not directly control.

For example, an attacker who can influence reported latency metrics from one compromised agent keeps that agent's p95 latency at 198ms—just below the 200ms alert threshold—while using the agent as a stepping stone to inject malicious instructions into downstream agents whose own metrics spike beyond threshold; by the time the downstream alerts fire, the initial compromise source appears healthy and uninvolved.

Standard defenses such as anomaly-based alerting and static threshold alerts are insufficient because anomaly detection requires historical baselines to distinguish manipulation from legitimate variation, and attackers who understand baseline computation windows can perform gradual metric manipulation that stays within anomaly detection tolerances.

**Multi-agent distinction:** In a single-agent system, threshold manipulation affects only that agent's alert rules; in a multi-agent system, selectively suppressing alerts from chosen agents while propagating attack effects to other agents creates a directed misdirection capability that exploits the independence of per-agent alert evaluations and prevents operators from identifying the origin of cascading failures.
