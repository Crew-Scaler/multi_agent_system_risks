# 12.5.48 Efficiency Metric Instrumentation Coverage Gaps [NoFW]

Not all operations are instrumented for efficiency metrics; adversaries identify under-instrumented agents or code paths and route malicious operations through those paths knowing they will not appear in efficiency monitoring; in multi-agent systems, instrumentation coverage heterogeneity across agents enables selective attack routing through least-monitored agents.

Standard defenses such as partial instrumentation coverage and best-effort metric collection are insufficient because under-instrumented code paths are systematically predictable from publicly documented agent configurations or observable from the absence of metrics in monitoring dashboards, enabling adversaries to identify and target unmonitored paths with high confidence.

**Multi-agent distinction:** Instrumentation coverage gaps are more severe in multi-agent systems because different agents are developed and instrumented by different teams with varying standards; this creates heterogeneous coverage across the fleet where some agents have comprehensive instrumentation and others have minimal, and adversaries who map the instrumentation landscape can route attacks exclusively through agents with the lowest coverage, making their operations completely invisible to efficiency monitoring while benign agents' metrics appear healthy.
