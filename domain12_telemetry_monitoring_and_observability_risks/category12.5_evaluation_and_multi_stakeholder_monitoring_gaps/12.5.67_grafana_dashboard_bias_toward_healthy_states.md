# 12.5.67 Grafana Dashboard Bias Toward Healthy States [NoFW]

Monitoring dashboards display aggregate metrics that average across agent fleet states, creating visual bias toward aggregate health; adversaries who compromise a subset of agents benefit from healthy-majority averaging that keeps aggregate dashboard indicators in normal-looking ranges while the compromised minority experiences significant degradation.

For example, in a 20-agent fleet where 18 agents maintain 99.5% success rates, a single compromised agent dropping to 85% and a second agent degraded to 90% produces a fleet average of 98.8%—well within the green zone of any dashboard calibrated to a 95% alert threshold—while users routed to the two affected agents experience failure rates ten to fifteen times higher than the dashboard indicates.

Standard defenses such as percentile-based alerting and per-service SLO monitoring are insufficient because they require pre-configured per-agent alert rules for every agent in the fleet, and in dynamically scaled deployments where agent count changes continuously, maintaining complete per-agent alert coverage is operationally infeasible.

**Multi-agent distinction:** In a single-agent system, aggregate metrics equal per-agent metrics, so dashboard averaging introduces no masking; in a multi-agent system, averaging across heterogeneous agent states introduces a structural masking effect whose severity scales with fleet size, making dashboards increasingly unreliable as observability tools as the agent count grows.
