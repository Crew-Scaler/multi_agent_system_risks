# 12.5.54 Message Queue Throughput Metrics Hiding Quality Degradation [NoFW]

Message queue throughput metrics measuring messages-per-second appear healthy when high-throughput poisoned messages are processed; agents maintaining excellent throughput while processing malicious content report strong queue health indicators, and in multi-agent shared queues all consuming agents process poisoned content while aggregate throughput metrics remain healthy.

For example, an adversary who injects poisoned training examples into a shared message queue for a continual learning pipeline observes that all consuming agents continue processing messages at their normal throughput rate; monitoring shows 100% of target volume processed with zero consumer lag and zero error rate, while the learning agents progressively update their behavior based on poisoned signals that content-blind throughput metrics cannot detect.

Standard defenses such as queue throughput dashboards, consumer lag monitoring, and processing rate alerts are insufficient because they measure the velocity of message consumption rather than the validity or safety of message content, and content-level threats embedded in well-formed messages are invisible to any infrastructure-layer metric.

**Multi-agent distinction:** Shared message queues create a single poisoning point that simultaneously degrades all consuming agents; in single-agent systems, content poisoning via queues affects only the target agent and may be detected through that agent's downstream behavior monitoring; in multi-agent systems, the shared queue delivers identical poisoned content to all agents simultaneously while aggregate throughput metrics remain healthy, making queue-based content attacks both broader in impact and harder to detect.
