# 12.5.24 Tool Invocation Observability Reduction Through Delegation [NoFW]

In hierarchical agent systems, tool invocations by worker agents do not trace directly to originating user requests; audit trails show tool invocations without the user context that authorized them, creating semantic gaps where compliance-oriented monitoring cannot verify that tool use was appropriately authorized at the request level.

For example, a worker agent executing file deletions shows in the audit trail as a sequence of delete tool invocations with no link to the user session that authorized only read access, making compliance review unable to determine whether the deletions were part of an authorized workflow or an unauthorized operation injected by a compromised manager agent.

Standard defenses such as agent-level audit logging and tool invocation recording are insufficient because they capture tool calls at the worker level without preserving the authorization chain from the originating user request through each delegation hop, severing the evidence needed to verify that tool use remained within the scope of what the user authorized.

**Multi-agent distinction:** Single-agent architectures connect tool use directly to user authorization in one traceable call stack; hierarchical multi-agent architectures interpose manager agents that translate user requests into worker delegations, and each delegation hop loses context about the original authorization scope, making compliance verification structurally incomplete across the delegation chain.
