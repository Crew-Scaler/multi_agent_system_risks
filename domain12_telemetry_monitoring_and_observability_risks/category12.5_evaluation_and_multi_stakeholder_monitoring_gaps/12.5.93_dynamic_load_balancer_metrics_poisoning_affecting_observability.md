# 12.5.93 Dynamic Load Balancer Metrics Poisoning Affecting Observability [NoFW]

Dynamic load balancers expose health metrics that guide routing decisions and feed into monitoring dashboards; adversaries who can manipulate these health metrics corrupt both routing behavior and the observability layer that monitoring teams use to assess fleet health, creating coordinated confusion between what is happening and what monitoring reports.

For example, an attacker who can write to the health-check endpoints that the load balancer polls can report artificially low latency and high success rates for a compromised replica, causing the balancer to direct more traffic to it while monitoring dashboards simultaneously display that replica as the healthiest in the fleet.

Standard defenses such as passive health checks and anomaly alerts on routing distributions are insufficient because they rely on the same health metrics the attacker is manipulating, creating a feedback loop in which corrupted metrics suppress the alerts that would otherwise reveal the manipulation.

**Multi-agent distinction:** In multi-agent systems, a load balancer serving multiple agent roles shares a single health-metric fabric, so an attacker poisoning health metrics for one role's replica pool simultaneously distorts routing and observability for all other agent roles whose monitoring pipelines share the same infrastructure.
