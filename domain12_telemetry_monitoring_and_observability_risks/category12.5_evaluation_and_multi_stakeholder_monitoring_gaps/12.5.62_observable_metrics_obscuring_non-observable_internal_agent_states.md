# 12.5.62 Observable Metrics Obscuring Non-Observable Internal Agent States [NoFW]

External monitoring observes latency, throughput, and error rates but cannot directly observe internal agent states such as reasoning validity, confidence calibration, or memory corruption; internal state corruption in one agent propagates through the multi-agent workflow invisibly, only becoming detectable through external metric degradation after the corruption has cascaded through multiple downstream agents.

For example, an attacker who injects a semantically plausible but factually incorrect belief into an early-stage retrieval agent's internal context will see that agent continue to report normal latency and throughput while its confidence calibration silently degrades—detectable only after the corrupted belief has cascaded through three downstream reasoning agents and produced observable user-facing errors.

Standard defenses such as output validation and sanity checking at API boundaries are insufficient because they catch only syntactically malformed or semantically extreme outputs, not subtle internal state corruptions whose downstream effects only materialize after multi-hop propagation through the agent network.

**Multi-agent distinction:** In a single-agent system, internal state corruption and its external metric effects are co-located within one process boundary, limiting the propagation delay; in a multi-agent workflow, corrupted internal state can traverse multiple agent hops before any external metric registers deviation, creating a compounding detection delay proportional to pipeline depth.
