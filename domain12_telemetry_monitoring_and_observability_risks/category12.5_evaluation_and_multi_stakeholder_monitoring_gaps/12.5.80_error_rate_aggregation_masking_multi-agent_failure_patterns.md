# 12.5.80 Error Rate Aggregation Masking Multi-Agent Failure Patterns [NoFW]

Prometheus aggregate error rates across agent replicas and models dilute per-agent failure signals; an agent whose error rate increases from 1% to 2% in a 20-agent fleet where other agents maintain 0.1% error rates produces a fleet-wide aggregate increase from 0.1% to 0.15%, remaining below typical 5% alert thresholds while the affected agent's users experience doubled failure rates.

Standard defenses such as per-agent error rate dashboards and fleet-level error rate alerting are insufficient because per-agent dashboards require pre-configured alert rules for every dynamically scaled agent instance, and fleet-level alerting is calibrated to aggregate rates that dilute the per-agent signal to the point of undetectability in large fleets.

**Multi-agent distinction:** In a single-agent system, any error rate deviation is immediately visible at 100% of the monitoring signal; in a multi-agent system, the same absolute error rate increase from one agent contributes only 1/N of the aggregate signal, creating an inverse relationship between fleet size and per-agent anomaly detectability that allows a compromised agent's failure rate to grow substantially before any alert threshold is crossed.
