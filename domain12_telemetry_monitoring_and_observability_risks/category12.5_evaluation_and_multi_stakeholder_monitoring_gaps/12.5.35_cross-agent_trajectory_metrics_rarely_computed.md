# 12.5.35 Cross-Agent Trajectory Metrics Rarely Computed [NoFW]

Trajectory evaluation metrics (exact match, precision, recall over complete action sequences) require complete action sequences spanning multiple agents' concurrent and asynchronous operations, but are almost never computed in production; without trajectory-level metrics, action sequence quality across agent chains is unmonitored, and degradation in multi-agent coordination quality is only detected through eventual user-impact reports.

For example, in a software development MAS where a planning agent, a coding agent, and a testing agent each execute steps toward a task, each agent logs its individual step completions; but no system computes whether the combined action trajectory—plan, implement, verify—follows the expected sequence at the expected quality level, allowing coordination failures such as the coding agent skipping steps indicated by the planning agent to go undetected until users report incorrect outputs.

Standard defenses such as task completion monitoring and per-agent step logging are insufficient because they track whether individual steps were executed rather than whether the complete cross-agent trajectory was coherent, and outcome-based monitoring detects only final failures rather than the coordination degradation that causes them.

**Multi-agent distinction:** Trajectory evaluation is inherently a multi-agent problem because a complete trajectory requires composing action sequences from agents operating concurrently and asynchronously; in single-agent systems, the full trajectory is recorded in one process and evaluation is straightforward, whereas multi-agent trajectories require synchronized reconstruction from independent logs with no shared sequence definition, making trajectory monitoring technically infeasible with standard observability tools.
