# 12.5.115 Fragmented Feedback Collection Across Multi-Agent Fleet Preventing Systematic Improvement [NoFW]

Per-agent feedback databases store interaction outcomes independently without cross-agent aggregation; systematic routing inefficiencies visible only across agent boundaries (such as circular escalation patterns through multiple specialized agents) cannot be detected from per-agent feedback analysis, leaving fleet-wide workflow failures undiagnosed and unresolved.

For example, users report that the system gives inconsistent advice on the same topic across sessions; per-agent feedback analysis shows each individual agent's satisfaction score within acceptable bounds, but the underlying cause—a circular escalation loop where Agent A routes complex queries to Agent B which routes them back to Agent A—is only visible when feedback is analyzed as a fleet-wide workflow graph rather than as per-agent satisfaction metrics.

Standard defenses such as per-agent CSAT tracking and individual-session feedback analysis are insufficient because they attribute negative user experiences to the last agent in a multi-agent chain rather than to the structural workflow inefficiency that spans the entire agent network, so the root cause remains undiagnosed even as each agent's score stays within acceptable bounds.

**Multi-agent distinction:** In single-agent systems, all feedback traces back to one decision-making unit, enabling direct correlation between feedback signals and agent behavior; in multi-agent systems, feedback is attributed to individual agents along a workflow path, making it structurally impossible to identify fleet-wide failures without cross-agent feedback aggregation that treats the full agent workflow as the unit of analysis.
