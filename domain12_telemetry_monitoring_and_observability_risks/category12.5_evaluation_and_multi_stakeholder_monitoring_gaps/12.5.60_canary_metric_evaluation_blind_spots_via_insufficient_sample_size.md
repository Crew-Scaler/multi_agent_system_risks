# 12.5.60 Canary Metric Evaluation Blind Spots via Insufficient Sample Size [NoFW]

Canary deployments evaluate quality on sampled traffic; in multi-agent deployments where samples are distributed across many agents, per-agent sample sizes fall below statistical significance thresholds, preventing detection of agent-specific quality regressions that would be statistically significant if samples were concentrated on individual agents.

For example, a 5% canary deployment across a 50-agent fleet routes only 0.1% of traffic to each agent, giving each agent far fewer samples than the minimum required for statistical significance testing of quality regressions; an adversary who poisons one agent's behavior can exploit this statistical blindness indefinitely.

Standard defenses such as increasing canary traffic percentage are insufficient because they create unacceptable production risk by exposing a larger fraction of real users to potentially degraded behavior, and extending the evaluation window introduces temporal distribution shift that confounds quality regression detection.

**Multi-agent distinction:** Single-agent canary deployments concentrate the entire traffic sample on one system, maintaining statistical power; multi-agent canary deployments fragment the same sample across many agents, distributing statistical power thin enough that per-agent regressions become undetectable at any operationally acceptable traffic split.
