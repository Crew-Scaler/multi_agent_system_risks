# 12.5.8 Evaluation Audit Trail Completeness Gaps [NoFW]

Evaluation pipeline audit trails record final results from each evaluation agent but not intermediate agent contributions or the dependency graph between agents; post-incident reconstruction of which agent's compromise caused biased evaluation results cannot be completed without per-agent intermediate output logging that current pipelines do not provide.

For example, when three evaluation agents each log their final verdict but none logs the intermediate quality assessments that informed it, an attacker who poisoned Agent B's intermediate reasoning affects Agent C's final decision, yet post-incident analysis finds only that Agent C's verdict was unexpected with no recoverable evidence linking it to Agent B's compromised intermediate output.

Standard defenses such as audit log collection and centralized log management are insufficient because they aggregate final outputs across agents without capturing the intermediate computation graphs that would be needed to trace how a compromise in one agent propagated to another agent's decision.

**Multi-agent distinction:** Single-agent evaluation audit trails are complete because all computation occurs in one process; multi-agent audit trails fragment at every agent boundary, making post-incident forensics structurally incomplete unless per-agent intermediate output logging was designed into the pipeline from the start.
