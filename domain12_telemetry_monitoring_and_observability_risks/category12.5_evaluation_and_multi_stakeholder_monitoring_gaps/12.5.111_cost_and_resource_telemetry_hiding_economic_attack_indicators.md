# 12.5.111 Cost and Resource Telemetry Hiding Economic Attack Indicators [NoFW]

Token consumption and API cost telemetry is treated as an operational metric rather than a security signal, creating blind spots for denial-of-wallet attacks, resource exhaustion through agent cascade, and attacker-induced expensive computation.

For example, a prompt injection that instructs an orchestrator agent to recursively spawn sub-agents for unnecessary data-fetching operations increases token consumption 50x over baseline, but operational cost dashboards that report total monthly spend show only a gradual upward trend rather than a spike correlated with the injected instruction event that triggered the cascade.

Standard defenses such as budget caps and aggregate cost alerts are insufficient because they are calibrated to operational norms and trigger only when cumulative costs cross billing thresholds, providing no real-time signal tied to the individual events driving economic abuse.

**Multi-agent distinction:** In multi-agent systems, resource exhaustion can be orchestrated by compromising a single orchestrator agent that delegates expensive sub-tasks to many worker agents in parallel; the resulting cost spike distributes across agent-level billing records, masking the centralized origin of the attack and preventing per-agent cost attribution from identifying the orchestrator as the causal agent.
