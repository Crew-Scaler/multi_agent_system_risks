# 12.5.40 Efficiency Metric Aggregation Obscuring Attack Signals [NoFW]

Efficiency metrics aggregated across multiple agents and operations obscure per-agent or per-operation attack signals that would be detectable at finer granularity; a 0.1% efficiency degradation from a targeted agent-level attack disappears in fleet-wide aggregate metrics, making only large-scale or simultaneous attacks detectable through aggregated efficiency monitoring.

For example, an adversary who injects a resource-consuming prompt pattern into one specialized tool-use agent causes that agent's token consumption to increase by 30%; when averaged across a 50-agent fleet where the remaining 49 agents operate normally, fleet-wide token consumption increases by only 0.6%, falling within normal daily variance and triggering no alerts while the targeted agent continues consuming elevated resources indefinitely.

Standard defenses such as fleet-level efficiency dashboards and aggregate resource usage alerts are insufficient because they are calibrated to detect large-scale degradations distributed across many agents, and targeted single-agent attacks that remain statistically invisible in aggregate metrics evade detection until resource budgets are exhausted.

**Multi-agent distinction:** Efficiency metric aggregation creates a structural attack surface unique to multi-agent systems: the more agents contribute to a fleet aggregate, the smaller the minimum detectable attack size becomes, so adversaries can scale attack impact proportionally with fleet size while maintaining identical aggregate-metric invisibility; single-agent efficiency monitoring has no equivalent dilution effect because there is only one agent to observe.
