# 12.5.85 Quantization Artifact Telemetry Absence [NoFW]

Production monitoring does not collect quantization-specific metrics such as activation range distributions, per-layer quantization error accumulation, or KV cache integrity indicators; entire attack classes that operate through quantization precision manipulation generate no monitored telemetry and therefore have zero detection probability through standard observability infrastructure.

For example, an attacker who has identified that a specific model's int4 quantization causes activation range clipping in layers responsible for safety-relevant reasoning can craft inputs that consistently trigger this clipping, causing the model to produce responses with degraded safety constraint adherence; standard observability dashboards show normal GPU utilization, inference latency, and request success rates because the attack operates entirely within the model's numerical behavior without affecting any hardware or service-level metric that production monitoring systems collect.

Standard defenses such as output content filtering and behavioral guardrails are insufficient because they evaluate model outputs rather than the quantization-layer properties that produce those outputs, and attacks that exploit quantization precision effects can produce responses that appear semantically reasonable while exhibiting subtle behavioral degradation below content filter detection thresholds.

**Multi-agent distinction:** In a single-agent system, absent quantization telemetry creates a blind spot for one inference endpoint; in a multi-agent system where multiple agents share quantized model artifacts deployed from a common registry, the same quantization-layer blind spot simultaneously affects all agents that use that artifact, and no cross-agent telemetry correlation can detect the shared vulnerability because quantization metrics are absent from every agent's observability data.
