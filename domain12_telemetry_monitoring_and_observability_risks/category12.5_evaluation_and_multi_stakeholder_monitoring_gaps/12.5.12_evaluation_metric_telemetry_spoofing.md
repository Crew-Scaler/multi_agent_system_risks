# 12.5.12 Evaluation Metric Telemetry Spoofing [NoFW]

Evaluation metric reports transmitted over unencrypted or unauthenticated channels can be intercepted and replaced with falsified values; in multi-agent systems where all agents report to centralized telemetry, a single injection point enables an attacker to make evaluation appear to pass for the entire agent fleet simultaneously.

For example, an attacker who intercepts the unencrypted metric reporting channel between evaluation agents and the centralized telemetry store can substitute passing scores for failing scores across all 50 agents simultaneously, causing the deployment gate to open while every underlying evaluation actually failed.

Standard defenses such as agent-side logging and network perimeter monitoring are insufficient because they do not provide end-to-end integrity verification for metric transmission, leaving in-transit spoofing undetected between the point of evaluation and the point of monitoring.

**Multi-agent distinction:** In single-agent systems metric spoofing affects one reporting stream; in multi-agent systems where all agents report to a shared telemetry endpoint, a single compromise of the transmission channel spoofs the entire fleet's reported metrics simultaneously, giving an attacker fleet-wide evaluation bypass through one injection point.
