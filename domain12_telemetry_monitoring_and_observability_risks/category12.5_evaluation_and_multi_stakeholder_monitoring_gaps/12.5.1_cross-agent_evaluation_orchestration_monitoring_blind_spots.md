# 12.5.1 Cross-Agent Evaluation Orchestration Monitoring Blind Spots [NoFW]

Evaluation agents assessing other agents' performance are not themselves monitored, creating a blind spot for attacks targeting the evaluation layer.

Evaluation orchestration agents coordinate multiple evaluator agents by routing results and controlling which evaluators run in which order, but neither the routing logic nor the inter-agent communication channels are instrumented by monitoring systems. An attacker who compromises an orchestration agent can silently skip the security evaluator gate and route outputs directly from the performance evaluator to the deployment approver; because each agent logs only its own actions, no log contains a record that the security evaluation was bypassed.

Standard defenses such as per-component audit logging and network traffic inspection are insufficient because they record individual agent activity without capturing the semantic correctness of routing decisions or detecting when mandatory evaluation stages have been omitted from the workflow.

**Multi-agent distinction:** In single-agent evaluation all stages occur in one observable process, but in multi-agent evaluation orchestration control flow spans agent boundaries where no single log contains the complete execution path, allowing an attacker to manipulate routing in the gaps between agents that no individual stakeholder's monitoring covers.
