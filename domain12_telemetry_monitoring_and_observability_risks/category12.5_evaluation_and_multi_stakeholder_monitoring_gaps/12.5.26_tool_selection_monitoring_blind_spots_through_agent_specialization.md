# 12.5.26 Tool Selection Monitoring Blind Spots Through Agent Specialization [NoFW]

Different agent specializations have access to different tool subsets; cross-agent tool selection patterns that form attack chains are invisible to per-agent monitoring because each agent's tool palette is viewed in isolation, enabling attackers to distribute dangerous tool selection sequences across agents to avoid single-agent anomaly detection.

An adversary who needs to execute a reconnaissance-exfiltration sequence across an enterprise system distributes the reconnaissance step to the information-retrieval agent and the exfiltration step to the data-export agent; each agent's monitoring sees only its single tool call within its normal operational palette, and the two calls are never correlated because no monitoring layer observes cross-agent tool selection patterns.

Standard defenses such as per-agent tool use monitoring and anomaly detection on individual tool call sequences are insufficient because they operate within each agent's tool palette in isolation and cannot detect attack patterns that only emerge when tool selections across multiple agents are viewed as a coordinated sequence.

**Multi-agent distinction:** Single-agent monitoring covers all tool selections made by that agent in a single observable stream; multi-agent specialization distributes dangerous tool combinations across agent boundaries where they fall into separate monitoring domains, and attackers can design attack chains that are unremarkable within each agent's specialization domain while being collectively anomalous across domains.
