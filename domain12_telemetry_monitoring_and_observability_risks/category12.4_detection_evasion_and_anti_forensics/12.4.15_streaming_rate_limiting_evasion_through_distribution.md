# 12.4.15 Streaming Rate Limiting Evasion Through Distribution [NoFW]

Rate limiting on streaming endpoints is evaded in multi-agent systems by distributing expensive streaming content across multiple concurrent agents, each individually below per-agent rate limits while aggregate consumption exceeds system capacity; unlike singular streaming endpoints with straightforward rate limiting, multi-agent streaming requires cross-agent coordination for aggregate rate enforcement, and monitoring N concurrent streaming agents for compound limit violations creates operational complexity that attackers exploit through careful distribution timing.

Per-agent streaming rate limits exploit the architectural property that enforcement occurs at individual endpoint boundaries without cross-agent visibility: a content extraction attack that would trigger per-agent rate limiting at 100 KB/s instead distributes the work across 15 agents each streaming at 8 KB/s, where no individual agent's endpoint generates a rate limit event while the coordinated output assembles into a 120 KB/s exfiltration stream that saturates shared network egress. For example, an attacker orchestrates simultaneous streaming responses from 20 agents, each consuming exactly 4% of its per-agent quota, to collectively exhaust a shared message broker's throughput capacity; each individual agent appears to be operating within normal parameters while the aggregate operation effectively performs a distributed denial-of-service against downstream consumers of the fleet.

Standard defenses such as per-endpoint token bucket algorithms, connection throttling, and individual streaming rate limiters are insufficient because they apply enforcement at the endpoint boundary without awareness of what other agents are simultaneously consuming; the enforcement granularity does not match the logical operation granularity in multi-agent streaming pipelines, leaving the aggregate resource consumption entirely outside the monitored surface.

**Multi-agent distinction:** In single-agent streaming, rate limiting applies to one endpoint whose resource consumption directly represents the complete operation's impact; in multi-agent streaming, each agent operates under independent limits while the compound operation may violate aggregate resource constraints that cannot be enforced without cross-agent coordination infrastructure, and monitoring each agent individually for compliance provides no signal about the compound consumption pattern that exceeds system capacity.
