# 12.4.20 Demonstration Ordering as Covert Instruction Activation Mechanism [NoFW]

In-context learning demonstrations are susceptible to ordering attacks that exploit recency bias; adversaries strategically position malicious instruction examples at the end of demonstration sequences to maximize their influence on agent behavior, and monitoring systems focused on explicit instruction injection miss ordering-based control flow manipulation that activates malicious behavior through positional context.

For example, an attacker contributing to a shared documentation corpus used to construct agent demonstration sequences positions a malicious example last—where transformer recency bias ensures maximum influence—so that agents loading the demonstration set reliably execute a targeted behavior when processing subsequent inputs matching the example's surface pattern; monitoring systems that scan for explicit instruction injection in system prompts and tool call parameters do not examine demonstration ordering patterns, leaving the ordering-based activation entirely invisible in standard telemetry.

Standard defenses such as demonstration example content vetting, allow-listing of trusted knowledge sources, and runtime content filtering are insufficient because each individual example in the manipulated sequence may be innocuous in isolation; the attack effect emerges purely from positional context that content-level review cannot detect and that runtime monitoring does not measure as a distinct telemetry dimension.

**Multi-agent distinction:** In single-agent systems demonstration ordering attacks are constrained to one agent's in-context learning window and require access specifically to that agent's demonstration sequence; in multi-agent systems where demonstration sets flow across agent boundaries as shared knowledge artifacts, a carefully ordered sequence passed from Agent A to Agent B as routine context transfer can activate different learned behaviors in each downstream recipient depending on each agent's positional sensitivity—enabling coordinated behavioral changes across multiple agents through a single ordering manipulation in a shared upstream context that no individual agent's monitoring would flag.
