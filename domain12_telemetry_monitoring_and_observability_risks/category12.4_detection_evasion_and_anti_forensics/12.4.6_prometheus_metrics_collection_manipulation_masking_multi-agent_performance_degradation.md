# 12.4.6 Prometheus Metrics Collection Manipulation Masking Multi-Agent Performance Degradation [NoFW]

Adversaries with Kubernetes API access can intercept Prometheus scraper traffic or modify ServiceMonitor selectors to exclude degraded pods from monitoring coverage; histogram bucket value manipulation causes percentile calculations to report artificially healthy latencies while actual user-facing performance has severely degraded, and in multi-agent fleets this manipulation can be applied fleet-wide through centralized scraper traffic interception.

For example, an adversary with Kubernetes API access modifies a ServiceMonitor selector to exclude pods labeled "zone-b" from Prometheus scraping; these 5 pods are precisely the agents serving 25% of user traffic that have been compromised with slow SQL queries producing 3,500ms response times, and their exclusion means Grafana dashboards continue reporting a healthy fleet-wide P95 of 200ms while one-quarter of users experience timeouts—with no alert firing and no dashboard indicator suggesting any problem exists.

Standard defenses such as Prometheus scraping authentication and TLS encryption for metric endpoints are insufficient because they prevent unauthorized external access but do not detect authorized manipulation by an attacker who has obtained Kubernetes API credentials; in multi-agent centralized Prometheus configurations the shared scraper represents a single trust boundary whose compromise simultaneously affects observability for all agents.

**Multi-agent distinction:** In single-agent Prometheus deployments metric manipulation affects that agent's visibility with a bounded blast radius; in multi-agent centralized Prometheus configurations man-in-the-middle attacks on the shared scraper traffic falsify all agents' metrics simultaneously, ServiceMonitor selector tampering removes entire agent subsets from monitoring coverage, and histogram bucket poisoning in a subset of agents corrupts aggregate percentile calculations in ways that appear as expected fleet variance rather than deliberate manipulation.
