# 12.4.9 GPU-Level DCGM Telemetry Aggregation Exposing Multi-Agent Inference Capacity and Resource Utilization Patterns [NoFW]

DCGM telemetry aggregated from multi-agent inference infrastructure reveals per-GPU utilization, memory allocation, and thermal headroom; adversaries accessing these dashboards learn exact saturation thresholds and peak-hour headroom, enabling precisely calibrated denial-of-inference attacks timed to periods of minimal remaining capacity.

For example, an attacker accessing DCGM dashboards observes that GPU 0 operates at 92% utilization during 9am–6pm with only 3% headroom before saturation while GPU 7 remains at 55% utilization; the attacker routes precisely calibrated additional traffic to GPU 0 during the peak business-hours window, triggering saturation and inference queue buildup with the minimum number of requests needed to cause service degradation while staying below thresholds that would trigger capacity autoscaling—an attack calibrated to within 3 percentage points of GPU 0's demonstrated capacity limit.

Standard defenses such as dashboard authentication, VPN-gated monitoring access, and monitoring-only DCGM configurations are insufficient because they limit who can view the dashboard but do not reduce the operational intelligence value of the aggregated view once an attacker gains access through credential compromise or insider threat; the data necessary for attack calibration is inherent to the centralized capacity-management function these dashboards serve.

**Multi-agent distinction:** Single-agent DCGM telemetry exposes one inference server's capacity profile with bounded intelligence about that deployment's resource limits; multi-agent centralized DCGM aggregation exposes the entire fleet's GPU utilization map including load imbalances across devices, thermal and power headroom for each GPU, and temporal traffic patterns enabling adversaries to identify the most saturated device in the fleet and calibrate targeted denial-of-inference attacks with precision unavailable from monitoring any individual agent's metrics.
