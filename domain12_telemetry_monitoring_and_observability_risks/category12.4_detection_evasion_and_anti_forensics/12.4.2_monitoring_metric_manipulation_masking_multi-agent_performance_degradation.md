# 12.4.2 Monitoring Metric Manipulation Masking Multi-Agent Performance Degradation [NoFW]

Attackers craft agent behavior patterns that maintain aggregate metrics within normal ranges while individual agents operate in degraded or compromised states.

Metrics pipelines become attack vectors through the architectural property that metric emission logic resides within each agent process and fleet-wide aggregates are computed from agent-reported values rather than independently measured: an adversary who modifies an agent's histogram instrumentation to move latency measurements from high-latency buckets (2–5 seconds) into low-latency buckets (100–200 milliseconds) causes Prometheus to compute an artificially healthy P95 latency while actual user-facing response times have severely degraded. In a 20-agent fleet, compromising 5 agents to report falsified healthy metrics (P95 200ms) while 15 honest agents report actual degradation (P95 1,500ms) yields a weighted fleet-wide P95 near 1,200ms—appearing as marginal degradation rather than the critical failure affecting 25% of user traffic that the 5 compromised agents serve. For example, an attacker modifies metric endpoint responses on 5 agents through a man-in-the-middle interception of unencrypted Prometheus scraper traffic; Grafana dashboards continue showing green P95 latency while one-quarter of users experience 3,500ms response times and the dashboard operators have no visibility into the discrepancy.

Standard defenses such as metric collection redundancy and synthetic external monitoring are insufficient because they compare reported metrics to historical baselines rather than to independently measured ground truth; a manipulation subtle enough to keep aggregate metrics near expected ranges evades statistical anomaly detection entirely, and external synthetic tests sample only a fraction of the request distribution.

**Multi-agent distinction:** Single-agent metric manipulation creates local measurement corruption detectable by comparing reported metrics to external monitoring of that one agent; multi-agent distributed metrics collection creates a dilution attack where falsified reports from a subset of agents blend into legitimate fleet-wide aggregates, anomalous per-agent reporting appears as expected heterogeneity from differing load distributions, and the central time-series database's retroactive alteration capability enables erasing evidence of coordinated degradation across the entire incident history.
