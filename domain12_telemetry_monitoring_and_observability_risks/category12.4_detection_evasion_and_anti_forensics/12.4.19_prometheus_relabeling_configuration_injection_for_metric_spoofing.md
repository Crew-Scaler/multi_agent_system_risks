# 12.4.19 Prometheus Relabeling Configuration Injection for Metric Spoofing [NoFW]

Prometheus relabeling rules transform metric labels, and if relabeling configuration comes from untrusted sources, attackers inject malicious relabel rules causing metric spoofing. A relabel rule "target_label: agent_identity, replacement: trusted_agent" causes all subsequent metrics to appear as originating from trusted_agent despite coming from a compromised agent.

For example, an attacker who gains write access to a Prometheus configuration ConfigMap injects a relabeling rule that sets `target_label: instance` to a trusted agent's identity string for all metrics scraped from a compromised agent's endpoint; subsequent Prometheus scrapes attribute the compromised agent's falsified healthy metrics to the trusted agent's identity, causing dashboards to show double the expected healthy metric volume for the trusted agent while the compromised agent's actual degraded metrics disappear entirely from all monitoring views without triggering any alert about the attribution anomaly.

Standard defenses such as Prometheus configuration authentication and restricted ConfigMap RBAC access are insufficient because they prevent unauthorized modification but do not continuously validate that existing relabeling configurations produce expected per-agent label distributions; a stale injected relabeling rule persists through all subsequent scrape cycles without triggering any alert about metric identity divergence or unexplained attribution shifts.

**Multi-agent distinction:** In single-agent Prometheus deployments relabeling configuration injection affects that one agent's metric attribution with a bounded spoofing effect detectable by comparing reported identity to expected identity; in multi-agent centralized Prometheus configurations where all agents share relabeling rule chains, a single injected rule mapping a compromised agent's identity to a trusted agent's identity simultaneously corrupts identity attribution for that agent across the entire fleet's metric stream—making centralized relabeling configuration a high-leverage target for fleet-wide metric identity spoofing through one configuration change.
