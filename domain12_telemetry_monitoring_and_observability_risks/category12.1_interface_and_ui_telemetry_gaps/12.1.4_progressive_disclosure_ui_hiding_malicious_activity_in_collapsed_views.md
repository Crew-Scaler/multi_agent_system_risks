# 12.1.4 Progressive Disclosure UI Hiding Malicious Activity in Collapsed Views [NoFW]

Progressive disclosure UI patterns hide technical details and reasoning traces in collapsed views; monitoring focuses on user-visible essential layers while malicious agent operations execute in collapsed technical views that are rarely inspected, creating per-agent observability blind spots that compound in multi-agent systems.

For example, an attacker embedding malicious instructions in a multi-step data pipeline task ensures that each individual tool invocation—network requests to sensitive endpoints, API calls to credential stores, data exfiltration commands—appears only in the collapsed technical layer of each executing agent's UI; a human operator watching Agent A's essential summary pane in the dashboard remains blind to the dozens of unauthorized API calls completing in Agent B's and Agent C's collapsed technical layers running in parallel.

Standard defenses such as per-agent action logging and UI-level audit trails are insufficient because collapsed-view telemetry is typically disabled by default to reduce overhead, and enabling comprehensive technical-layer capture across all agents in a multi-agent system creates observability infrastructure demands that teams routinely deprioritize in favor of latency performance.

**Multi-agent distinction:** In a single-agent system a human reviewer can at least expand that agent's disclosure layers to see its full technical output on demand; in multi-agent systems each agent maintains independent disclosure state, so a monitor focused on Agent A's expanded view is simultaneously blind to the collapsed technical layers of Agents B, C, and D executing concurrently—making complete real-time coverage structurally impractical without centralized disclosure-state aggregation that standard monitoring infrastructure does not provide.
