# 12.1.2 Streaming Response Telemetry Gaps Creating Attack Detection Delays [NoFW]

Monitoring of streaming responses captures completion metrics but misses intermediate token content, allowing malicious content in early stream positions to escape detection.

Streaming responses exploit the architectural property that security analysis requires a complete sequence while delivery systems are optimized to forward tokens as they are generated: monitoring faces a dilemma between buffering entire streams before inspection (introducing latency that disrupts workflows) and analyzing partial streams in real time (risking false negatives when malicious content spans token boundaries or appears early in long outputs). In a multi-agent pipeline where Agent A streams a compromised analysis to Agent B, Agent B begins acting on early tokens before the stream completes; by the time telemetry captures Agent A's full output, Agent B has already invoked irreversible tool actions. For example, a prompt-injected instruction embedded in the first 20 tokens of Agent A's 500-token streamed response causes Agent B to invoke a file-deletion tool immediately; the deletion completes before monitoring receives Agent A's complete stream, and the incident appears in logs as an isolated Agent B tool invocation with no visible causal link to the upstream injection.

Standard defenses such as real-time content filters on streaming endpoints are insufficient because multi-agent streaming handoffs occur at sub-second intervals across processes, and centralized stream inspection introduces latency that disrupts latency-sensitive workflows while still failing to inspect the cross-agent boundary where tokens transition from one agent's output buffer to another's input context.

**Multi-agent distinction:** In single-agent streaming all partial-stream states are visible to one monitoring process and the entire output can be buffered locally without coordination overhead; in multi-agent pipelines each inter-agent streaming handoff is a separate observability event requiring cross-process correlation, creating temporal gaps where compromised early tokens have already influenced downstream agent behavior before any single stream is fully captured and available for inspection.
