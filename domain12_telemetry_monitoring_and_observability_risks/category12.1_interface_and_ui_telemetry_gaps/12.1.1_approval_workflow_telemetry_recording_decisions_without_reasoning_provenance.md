# 12.1.1 Approval Workflow Telemetry Recording Decisions Without Reasoning Provenance [NoFW]

Monitoring captures the binary approve/reject outcome of workflows without recording the reasoning, context, or agent state that informed the decision.

Approval workflow interfaces exploit the architectural property that outcome logging and reasoning capture are treated as separate concerns: multi-agent approval pipelines aggregate recommendations from specialized sub-agents (risk assessment, policy compliance, fraud detection), but only the final composite decision is persisted. An attacker who compromises one contributing agent can inflate its confidence output so the displayed aggregate score misleads the human reviewer into approving a harmful action; the audit log records "approved" without capturing which agent contributed what score or how aggregation was performed. For example, in a financial authorization pipeline, a compromised fraud-detection agent reports 95% confidence on a fraudulent transaction while a policy-compliance agent correctly reports 60% concern; the blended display score of 85% prompts approval, but post-incident investigators can only see "human approved at 85% confidence" with no record of the per-agent contributions that produced that score.

Standard defenses such as mandatory human approval gates and outcome audit logs are insufficient because they record that oversight occurred, not the distributed reasoning state that informed the decision; a poisoned contributing agent's manipulation is structurally undetectable in a log that captures only the composite output.

**Multi-agent distinction:** In a single-agent system the complete reasoning chain exists within one process and can be instrumented at source; in multi-agent approval pipelines each contributing agent's score arrives independently, is consumed by an aggregation step, and is discarded after the composite is computed—making any individual agent's manipulation invisible in the final audit record and cross-agent provenance reconstruction structurally impossible without dedicated distributed reasoning telemetry.
